# Voyager Panel

The Voyager panel opens right on the page: turn the current site's features on and off, drag sliders with a live preview, manage site access and run cloud sync without leaving the chat. It opens on every site Voyager runs on.

## Open and close

<GuideOp>

The panel has several ways in; use whichever is closest.

- **Floating button**: hover Voyager's floating button and click **Voyager panel** when it pops out. On plugin sites such as Claude and ChatGPT, with Prompt Manager off, clicking the floating button itself opens the panel.
- **Shortcut**: press ⌥V on a Mac or Alt+V on Windows and Linux; press it again to close.
- **Slash menu**: type `/` in the composer and pick **Voyager panel…** at the end of the list.
- **Close**: press Esc or click outside the panel. Drag the top bar to move it; each site remembers the spot, and a double-click on the top bar centers it again.

</GuideOp>

<GuideNote>

**Use vv instead**: on Gemini, the popup's **Keyboard Shortcuts** card lets you record another key for **Voyager panel**. Turn on **Use vv instead (outside text fields)** to open the panel by pressing v twice outside a text field, in place of ⌥V / Alt+V.

</GuideNote>

## Features

<GuideOp>

The **Features** tab lists Voyager's features for the current site, and every change saves at once.

- **Switches**: features are grouped by topic, one per row; a feature's slider or choice sits on the same row and greys out while it is off.
- **Sliders**: the page follows as you drag, and the value saves when you let go.
- **Search**: the magnifier in the top bar filters features by name.
- **Another site**: click the site icon in the top bar to show another site's features; changes still save there, but the open page doesn't preview them.
- **Full settings**: the last button in the top bar opens every setting in the Voyager popup.

</GuideOp>

## Sites

<GuideOp>

The **Sites** tab matches the popup's [Site access](/en/guide/settings#site-access) card.

- **Supported sites**: Gemini and AI Studio are marked **Built in**; every other site has a switch that asks the browser for access, with how many features are on there or **Not enabled** underneath.
- **Other websites · Prompts only**: websites you add run only Prompt Manager; add or remove them here.
- **See its features**: click a site to open its **Features** tab.

</GuideOp>

## Cloud sync

<GuideOp>

The cloud icon in the top bar opens **Cloud Sync**, which syncs through Google Drive without a trip to the popup.

- **Choose sites**: **Shared** (prompts, settings, plugins) and each site have a row; switch a row off and this device skips it when syncing.
- **Status**: each row shows **Synced**, **Newer here**, **Newer in cloud** or **Not uploaded**.
- **More**: the menu holds **Upload all**, **Merge all from cloud**, **Restore previous version** and **Disconnect Google Drive**.

See [Cloud Sync](/en/guide/cloud-sync#sync-from-the-panel) for details.

</GuideOp>

## Hide the floating button

<GuideOp>

You can do without the floating button and still open the panel from the keyboard.

- **Hide**: hover the floating button and click **Hide** when it pops out. The message names the shortcut that opens the panel; **Undo** brings the button straight back.
- **Bring it back**: press ⌥V / Alt+V to open the panel, and the floating button returns too.
- **Switch**: the **Floating button** row under **Entry**, at the top of the panel's **Features** tab, also shows or hides it.

</GuideOp>
