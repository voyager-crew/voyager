# 欢迎登船

恭喜。你的工作流刚刚升舱了。
Voyager 不只是工具，它是种习惯。给我 5 分钟，带你上手。

## 1. 就位

还没装？去 [安装指南](/guide/installation)。
装好了？刷新 Gemini 页面。变化立竿见影。

也在用 Claude、ChatGPT、DeepSeek 或 Kimi？打开 Voyager 弹窗，进入 **插件**，为该网站开启想要的插件。第一次浏览器会请求访问该网站的权限；如果没出现任何内容，刷新一下标签页。全部插件见[插件目录](/guide/plugins)。

## 2. 穿梭

聊个长的。比如聊聊汉字演变史，或者量子力学。
看右边。
**那串点，就是你的导航图。**

- **指**：瞥一眼那会儿说了啥。
- **点**：瞬间穿越回去。
- **按**：长按（约 0.5 秒）**加星**，给大脑打个书签——下次直接跳回高光时刻。

别再滚轮滚到手酸。思维多快，你就多快。

## 3. 归档

看左边的聊天列表。
**文件夹来了。**

拎起一个聊天，拖进去，松手。
丝般顺滑。嵌套、重命名，随你心意。把脑子里的杂乱清空，只留清爽。

## 4. 珍藏

写了个绝妙的提示词？别让它滑走。
点输入框旁边的悬浮 **Voyager 球**（可以拖到任何位置），打开提示词管理器。
存下来，打个标签。

下次要用？
点一下这个球，搜一搜，插入。
这不是聊天，这是在沉淀你的数字资产。

## 5. 掌舵

鼠标移到这个球上，点弹出的 **Voyager 面板**，或者直接按 ⌥V / Alt+V。
不离开对话，就能开关这个网站的功能、拖滑块实时预览、云同步。
