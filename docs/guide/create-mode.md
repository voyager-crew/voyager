# 创造模式

用一句话说出你想让网站变成什么样，这个网站自己的 AI 会把它写成插件，Voyager 检查后帮你装上。不用写代码，也不用离开当前对话。Gemini、AI Studio、ChatGPT、Claude、DeepSeek 和 Kimi 上都能用。

创造模式有两个入口：网页里 [Voyager 面板](./panel.md) 的 **创造** 分页，和 Voyager 弹窗里的 **我的创造** 卡片。做出来的是只存在你浏览器里的本地插件。想自己写插件或交给编程 Agent，见 [编写自己的插件](./write-a-plugin.md)。

## 在页面上创造

<GuideOp>

最快的做法就在插件要用的那个 AI 网站上：打开 Voyager 面板，选 **创造**。

</GuideOp>

<GuideSteps>
<GuideStep>

在 **想改什么？** 下面写一句话，例如「让我的消息窄一点，并隐藏侧边栏」，然后点 **在此页创造**。

</GuideStep>
<GuideStep>

Voyager 在这个网站新建一个对话，把请求填进输入框。检查一遍，再自己发送：Voyager 从不替你按发送。输入框里已经有内容时，Voyager 不会动它，并提示你先发送或清空。

</GuideStep>
<GuideStep>

AI 读完 Voyager 为这个网站准备的说明页，回复一个 JSON 代码块。代码块下方会出现 Voyager 的 **预览并安装**。

</GuideStep>
<GuideStep>

点它，面板打开审阅：插件在哪些网站生效、每一处改动、完整的 CSS，以及 **请先留意** 的地方。点 **安装并开启**，插件立即生效，随时可以在 **功能** 分页里关掉。

</GuideStep>
</GuideSteps>

<GuideOp>

想再改，直接在同一个对话里告诉 AI。

- **新版本**：新回复下方出现 **预览更新**，审阅后点 **更新并开启**；旧的代码块标为 **较早的版本**。
- **已装过**：已经装上的那一版显示 **已安装**。
- **只认创造对话**：Voyager 只在你的消息里带有 Voyager 创造页链接的对话里读取回复，**在此页创造** 填入的请求总会带上它。其他对话的回复下方什么都不会出现，可以改用下面弹窗里的做法。

</GuideOp>

## 附上页面结构

<GuideOp>

**创造** 分页里有一个开关：**附上这个页面的结构（不含任何文字），让 AI 按页面的实际情况来写**。它默认打开，让 AI 照着页面真实的样子写，而不是凭猜测。

- **附上什么**：Voyager 能认出的页面元素和数量，加上最近一条回复和你最近一条消息周围的元素层级。
- **不附什么**：页面上的任何文字、链接、对话内容，以及像 ID、邮箱、长数字这类看起来是数据的属性值。
- **查看附上的内容**：展开它，看到的就是会附上的原文，一字不差。页面变了它也跟着重读。
- **关掉**：关掉开关，请求里就只有你那句话。

</GuideOp>

## Gemini 上的模型提示

<GuideOp>

在 Gemini 上，Voyager 会先看新对话将用哪个模型。如果是 Flash 或 Flash-Lite 这类较轻的模型，**创造** 分页顶部会提示它通常写不出插件。

- **建议**：提示会写明可以在 Gemini 的模型菜单里换成哪个更强的模型，或者把需求交给本地编程 Agent（按钮 **复制给本地 Agent** 就在提示里）。
- **重新检查**：在 Gemini 里换好模型后，点 **重新检查**；回到面板时 Voyager 也会再看一次。
- **默认模型**：如果你用了 [默认模型](./default-model.md)，Voyager 按新对话会用的那个默认模型来判断。
- **不拦你**：这只是提醒，**在此页创造** 照样能点。

</GuideOp>

## 回复装不上时

<GuideOp>

AI 的回复不一定每次都合格。装不上的回复下方会写明原因，例如「它没写明用在哪个网站」或「其中有一项改动不被允许」。

- **让它修复**：点回复下方的 **让它修复**，Voyager 把问题清单接在输入框已有内容后面，由你来发送。
- **修好之后**：AI 回复修好的版本时，下方会再出现 **预览并安装**。
- **审阅时**：如果在面板审阅里才发现问题，Voyager 不会装任何东西，并列出问题。

</GuideOp>

## 装好之后

<GuideOp>

装好的创造都在 **我的创造** 里。面板里它在 **功能** 分页的 **我的创造** 一组；在弹窗里，Gemini 和 AI Studio 上它是一张设置卡片，默认紧挨在 **云同步** 下面，位置可以调整，弹窗顶部的 **跳到** 目录能直接跳过去；ChatGPT、Claude、DeepSeek 和 Kimi 上它在插件列表下方。

- **开关**：每个创造一行，和其他功能一样开关。
- **移除**：点垃圾桶图标，确认后从这个浏览器移除，无法撤销。
- **导出**：在弹窗的 **我的创造** 列表里对它选 **导出**，到另一个浏览器里导入这个 JSON 文件。
- **提议收录**：如果它对大家都有用，可以提议收进官方插件目录，流程见 [插件贡献说明](./plugin-contribution.md)。

</GuideOp>

### 自动检查

<GuideOp>

面板打开时，Voyager 会看看 **我的创造** 里的每个创造在当前页面上有没有起作用。

- **没匹配到**：一个改外观的创造已开启，但页面上没有任何它要改的元素，它那一行会写 **已开启，但这个页面上没有它能匹配的内容**。悬停、聚焦这类状态和只调用内置功能的创造不算在内。
- **页面卡死**：一个会运行代码的创造让页面停止响应时，Voyager 已经把它关掉，那一行会写明原因。
- **请 AI 修复**：这两种情况旁边都有 **请 AI 修复**。Voyager 在这个网站新建对话，填入它在页面上看到的情况和插件当前安装的版本（页面结构开关打开时连结构一起附上），面板随之关闭，由你检查后发送。

</GuideOp>

## 给 Voyager 换配色

<GuideOp>

创造也能给网页上的 Voyager 界面换色，同样只要一句话，比如「把 Voyager 的面板和时间轴换成 Nord 配色」。AI 会在一条 `:root` 规则里设置 Voyager 公开的颜色变量，浅色和深色主题都生效。

- **跟着换的**：面板、菜单、对话框、提示和通知的背景、文字、边框和悬停色；按钮、选中和焦点的强调色；删除用的危险色。
- **时间轴**：时间轴的轨道、未选中的圆点和刻度，以及左侧滑块的轨道，有自己的一个颜色。
- **保持原样的**：Voyager 直接画在网站页面上的文字、边框和悬停色继续跟网站走，免得浅色文字落在网站的浅色背景上看不清。Voyager 弹窗不受影响。

</GuideOp>

<GuideNote>

**Nord 示例**：上面那句话通常会得到这样的 CSS。没设置的变量保持 Voyager 原来的颜色。

```css
:root {
  --gv-theme-surface: #2e3440;
  --gv-theme-hover: #3b4252;
  --gv-theme-text: #eceff4;
  --gv-theme-text-muted: #d8dee9;
  --gv-theme-border: #4c566a;
  --gv-theme-accent: #88c0d0;
  --gv-theme-accent-fg: #2e3440;
  --gv-theme-danger: #bf616a;
  --gv-theme-timeline: #81a1c1;
}
```

全部变量：`--gv-theme-surface`（背景）、`-hover`（悬停行）、`-text`（文字）、`-text-muted`（次要文字、图标）、`-border`（边框）、`-accent`（按钮、选中、焦点）、`-accent-fg`（强调色上的文字）、`-accent-hue`（强调色的 OKLCH 色相，一个数字）、`-danger`（删除）、`-timeline`（网站背景上的轨道和圆点）。

</GuideNote>

## 不用面板：在弹窗里创造

<GuideOp>

不想新开对话，或者想在别的对话、别的 AI 上让它写，可以从弹窗的 **我的创造** 开始。插件列表末尾的 **自己创造一个** 会直接带你到输入框。

</GuideOp>

<GuideSteps>
<GuideStep>

在 **想改什么？** 下面写一句话。下方的 **网站** 默认是当前标签页的网站；插件要用在别的网站上时，改一下即可。

</GuideStep>
<GuideStep>

点 **复制到当前对话**，把消息粘贴到该网站的 AI 对话里。AI 会先读 Voyager 为该网站准备的说明页（例如 `https://voyager.nagi.fun/create/claude.md`），然后只回复一个 JSON 代码块。AI 需要能打开链接。

</GuideStep>
<GuideStep>

把完整回复粘贴到 **粘贴 AI 的回复**，点 **检查回复**。

</GuideStep>
<GuideStep>

Voyager 用大白话说明这个插件改了什么。点 **导入**，再到插件列表里打开它；在 Gemini 和 AI Studio 上，它的开关就在卡片下方。这样导入的插件默认是关闭的。

</GuideStep>
</GuideSteps>

<GuideOp>

这条路上 Voyager 自己不发送任何东西：消息由你粘贴过去，回复也由你带回来。

</GuideOp>

## 会运行代码的创造

<GuideOp>

CSS 和页面改动做不到的需求，比如统计你发了几条消息、点一下就做点什么，AI 可以写一个运行 JavaScript 的创造。Voyager 通过 Chrome 的用户脚本运行它，只在它列出的网站上运行，而且要等你读过代码之后。审阅时，这类创造带有 **运行代码** 标记。

</GuideOp>

### 打开它

<GuideOp>

- **先读代码**：审阅会列出它运行的网站，并完整显示源码。它能读到这些页面上的一切，包括你的对话，Voyager 也拦不住它把读到的内容发到别处，所以只安装你信得过的代码。
- **安装并开启**：开启的正是你读过的这份代码。AI 之后给的新版本会保持关闭，等你重新审阅；这个开关也不会同步到你的其他设备。
- **一次性开关**：Chrome 要你允许之后，扩展才能运行这类代码。点 **打开 Voyager 详情页**，在那里打开 **允许用户脚本**（Allow User Scripts；Chrome 138 之前是 `chrome://extensions` 顶部的 **开发者模式**），回来再点 **我已开启**。
- **浏览器**：桌面版 Chrome 或 Edge 133 及以上。在 Safari、Firefox 和手机上，它会保留但处于暂停状态；可以让 AI 改成只改外观的版本。

</GuideOp>

### 随时可控

<GuideOp>

在 **我的创造** 里，每个会运行代码的创造都会显示 **已开启，仅限这台设备**、**已关闭** 或 **已暂停** 及原因。

- **全部停止**：在 **我的创造** 末尾（弹窗里的卡片，或面板的 **功能** 分页）点 **停止所有运行代码的创造**，会一次停下全部；点 **恢复** 重新启用。
- **已打开的页面**：已经打开的页面会继续运行它们，直到重新加载。点 **刷新这个页面** 就能重新加载当前标签页。
- **页面卡死**：如果这些创造运行后页面失去响应，Voyager 会关掉它们，并在页面下次加载时用通知写明是哪几个。修好之后，在 **我的创造** 里重新审阅，再打开。

</GuideOp>

## 能做到什么，做不到什么

<GuideOp>

大多数创造只改外观和布局，本身不运行代码，关掉时所有改动都会撤销。

- **能做**：改样式、隐藏页面上的部分内容、在设置里加开关和滑块、给 Voyager 换色，在插件网站上还能打开 Voyager 的内置功能（公式复制、时间轴、Mermaid 图表等）。
- **要运行代码**：响应点击、统计、读取页面内容这类需求，需要会运行代码的创造，见上文。
- **谁都做不到**：任何创造都不能在其他网站上运行，也不能改 Voyager 自己的设置。遇到这类需求，AI 会直接说明，并做出最接近、能实现的版本。
- **详细规则**：插件能用哪些字段、导入时检查什么，见 [编写自己的插件](./write-a-plugin.md#插件能做什么)。

</GuideOp>
