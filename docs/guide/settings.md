# 随心所欲

默认的已经很好。但我们要的是完美。
你的地盘，你做主。

## 影院模式

为什么要透过门缝看世界？
把聊天框拉大。

- **对话区域宽度**：先在弹窗里打开 **页面版面** → **对话区域宽度**。它默认关闭，打开后滑块才会出现在这一行下方。打开后，滑块范围是窗口宽度的 30% 到 100%（默认 70%）。写代码、看大表，拉宽视野全开；沉浸阅读，收窄心无旁骛。
- **编辑输入框宽度**：同样先打开 **页面版面** → **编辑输入框宽度**，编辑已发送的消息时，输入框就能拉宽。

## 掌控

点插件图标，进控制台。

- **滚动**：在 **时间线** → **显示时间线** 中选择，`流动` 平滑滑到目标消息，`跳跃` 一下直达。
- **位置**：在 **时间线** → **显示时间线** 中打开 **可拖拽时间线**，时间轴放哪顺手，就放哪。点 **重置时间线位置** 就能放回原处。
- **视觉特效**：在 Gemini / AI Studio 上，打开 **页面版面** → **视觉特效**，再在该行下选择 `飘雪`、`樱花` 或 `雨滴`；关闭该开关即可关闭特效。在其他网站（Claude、ChatGPT、DeepSeek、Kimi 和自定义网站）上，同一行位于该网站的 **插件** 卡片中，Voyager 在该网站上运行后（已开启提示词管理器或该网站的某个插件）就会显示。

## 自定义排序

控制台里的功能区域太多，常用的被埋在下面？

鼠标悬停在任意功能卡片上，右上角会出现 ▲/▼ 按钮。点一下，卡片就会上移或下移。调整后的顺序自动保存，下次打开还是你的布局。

功能按主题分成几张卡片（页面版面、侧栏、时间线、回答内容……），开关打开后，它的选项就显示在开关下方。滚动时，搜索框和下面那排卡片名始终停在顶部，点一个名字就跳到那张卡片。不小心拨错了开关？底部提示里点 **撤销** 即可恢复。

## Voyager 面板

不想每次都开弹窗？鼠标移到悬浮按钮上点 **Voyager 面板**，或按 ⌥V / Alt+V，在网页里直接开关当前网站的功能、拖滑块实时预览。详见 [Voyager 面板](/guide/panel)。

## 网站访问

<GuideOp>

弹窗里的 **网站访问** 卡片列出 Voyager 能运行的所有网站，以及每个网站开了什么。

- **状态**：Gemini 和 AI Studio 标着 **内置**、**全部功能**；其他网站显示 **已授权** 或 **未授权**，下面列出那里已开启的功能。
- **取消授权**：点 **取消授权** 收回 Voyager 对某个网站的访问；底部提示里点 **撤销** 即可恢复。
- **其他网站**：在别的网站上，Voyager 只提供提示词管理器，添加方法见 [灵感库](/guide/prompts#如何启用)。

</GuideOp>

## 在线更新

<GuideOp>

网站改版导致功能失灵时，修复可以通过在线更新送达，不用等商店审核。**在线更新** 开关在 Gemini 和 AI Studio 上是 **通用选项** 下面的一张卡片，在其他网站上位于该网站的 **插件** 卡片底部。

- **检查内容**：向 voyager.nagi.fun 检查插件更新和受支持网站的页面识别修复，只发送网站名称，不发送 Cookie 或页面内容。
- **立即检查更新**：开关旁的刷新按钮马上检查一次；开关关闭时也能用。
- **关闭**：停止自动检查；从下次加载页面起，页面识别规则改用扩展内置的版本，已下载的插件仍可使用。

</GuideOp>

## Safari 应用的语言

在 Mac 上，Voyager 应用的窗口、菜单和通知会使用你在 Voyager 弹窗里选的 **语言**；选阿拉伯语时界面会左右镜像。

## 氛围感

Voyager 不只是在做效率增强，也允许你顺手把页面气质调对。

- **飘雪**：轻柔雪花缓慢飘落，适合安静阅读。
- **樱花**：花瓣自然飘散，页面会更轻盈。
- **雨滴**：电影感雨丝与细微水花，整体更有沉浸感。
- **平滑切换**：关闭特效或切换到另一种效果时，粒子会自然退场，不会突然消失。
