## 指令宝库

这是你的指令宝库。

### 1. 捕获

写出好东西了？点 Voyager 悬浮球（默认在输入框旁边，可以拖到任意位置），打开 **提示词管理器**。
存入库中，落袋为安。

### 2. 归类

打上 `代码`、`邮件`、`学术` 这样的标签（用逗号分隔）。
工具要趁手，也要整洁。

### 3. 调遣

下次要用，别再重敲。
打开库，搜标签，点一下插入。
一键调用，效率翻倍。

## 紧凑列表与备注

提示词攒多了，一屏装不下？面板升级：

### 视图切换

搜索框右侧的 `≡ / ▦` 按钮在**紧凑列表**（默认）和**舒适视图**之间切换。

- **紧凑列表**：每条一行，一屏可见约 10 条；右侧依次是标签 · 展开 · 编辑 · 删除
- **舒适视图**：完整 Markdown 预览，适合提示词较少时使用

### 备注命名

添加或编辑 Prompt 时必须填写表单顶部的 **备注名**，它会作为 Prompt 的短标题。没有备注名的历史 Prompt 仍会保留，但下次编辑时需要补上备注名。

### 悬浮速览

紧凑模式下，鼠标悬停任意条目 **约 250 毫秒** 即可浮窗查看完整内容——替换掉浏览器原生 title（1–3 秒延迟才显示）。

### 斜杠快捷调用

在对话输入框中输入 `/`，再输入 Prompt 备注名的一部分。列表只显示匹配的名称和标签；悬停可预览完整正文，鼠标左键单击或按 `Tab` / `Enter` 即可确认。输入框会把选中的名称显示为高亮 token，发送时则使用完整 Prompt 正文。

## 任何网站皆可用

提示词管理器现在可以在您选择的任何网站上使用，不仅限于 Gemini™ 和 AI Studio。

### 如何启用

在 Claude、ChatGPT、DeepSeek 和 Kimi 上，提示词管理器是该网站 **插件** 卡片里的一行。打开该网站时点开 Voyager 弹窗，打开 **提示词管理器** 即可；如果这是在该网站上开启的第一个功能，浏览器会请求一次该网站的访问权限。

其他网站：

1. 点击浏览器扩展栏的 Voyager 图标。
2. 在 **网站访问** 卡片中找到 **其他网站**。
3. 输入网站地址（例如：`poe.com`）。
4. 点击 **添加网站** 并授予权限。
5. **刷新目标网页**，即可看到悬浮球。

### 常见 AI 网站示例

- `copilot.microsoft.com` - Microsoft Copilot
- `poe.com` - Poe

### 本地应用

本地地址同样可以填 —— 输入 `localhost:3080` 或 `127.0.0.1:3080` 即可。例如 [DeepSeek Harness](/guide/deepseek-harness) 跑在 `localhost:3080`，提示词管理器会像在普通网站上一样挂载。

![在 DeepSeek Harness 中运行的提示词管理器](/assets/prompt-manager-deepseek-harness.png)

::: tip
在自行添加的网站上，**仅**激活提示词管理器功能，时间线、文件夹等其他功能不会加载。Claude、ChatGPT、DeepSeek 和 Kimi 则不同：它们有各自的官方插件，可以在[插件目录](/guide/plugins)中浏览。
:::
