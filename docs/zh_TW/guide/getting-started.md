# 歡迎登船

恭喜。你的工作流剛剛升艙了。
Voyager 不只是工具，它是種習慣。給我 5 分鐘，帶你上手。

## 1. 就位

還沒裝？去 [安裝指南](/zh_TW/guide/installation)。
裝好了？刷新 Gemini 頁面。變化立竿見影。

也在用 Claude、ChatGPT、DeepSeek 或 Kimi？打開 Voyager 彈窗，進入 **外掛**，把那個網站想要的外掛打開。第一次會跳出瀏覽器授權，允許就好；沒看到效果就刷新分頁。全部外掛都在 [外掛目錄](/zh_TW/guide/plugins) 裡。

## 2. 穿梭

聊個長的。比如聊聊漢字演變史，或者量子力學。
看右邊。
**那串點，就是你的導航圖。**

- **指**：瞥一眼那會兒說了啥。
- **點**：瞬間穿越回去。
- **按**：長按（約 0.5 秒）**加星**，給大腦打個書籤——下次直接跳回高光時刻。

別再滾輪滾到手酸。思維多快，你就多快。

## 3. 歸檔

看左邊的聊天列表。
**資料夾來了。**

拎起一個聊天，拖進去，鬆手。
絲般順滑。嵌套、重命名，隨你心意。把腦子裡的雜亂清空，只留清爽。

## 4. 珍藏

寫了個絕妙的提示詞？別讓它滑走。
點輸入框旁的 **Voyager 懸浮球**（想放哪就拖到哪），打開提示詞管理器。
存下來，打個標籤。

下次要用？
點一下懸浮球，搜一搜，插入。
這不是聊天，這是在沉澱你的數位資產。

## 5. 掌舵

滑鼠移到這顆球上，點跳出的 **Voyager 面板**，或者直接按 ⌥V / Alt+V。
不離開對話，就能開關這個網站的功能、拖滑桿即時預覽、雲端同步。
