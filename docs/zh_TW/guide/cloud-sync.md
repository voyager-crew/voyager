# 雲同步

將您的資料夾、靈感庫（Prompts）、星標訊息及支援的設定等數據備份到雲端，在不同設備間保持一致。任何支援的瀏覽器都可以選 Google Drive，Safari 上還可以選 iCloud。數據直接在 Voyager 與您選擇的個人雲端帳戶之間傳輸，Voyager 不營運同步服務器。

## 同步內容

| 資料類型         | 是否同步 | 說明                                                                                    |
| ---------------- | -------- | --------------------------------------------------------------------------------------- |
| 資料夾結構       | 是       | Gemini、AI Studio、ChatGPT、Claude、DeepSeek 與 Kimi 的資料夾、巢狀層級、顏色與對話歸屬 |
| 提示詞庫         | 是       | 所有已儲存的提示詞，包含標籤與資料夾分類                                                |
| 星號標記訊息     | 是       | 來自任何對話的時間軸書籤                                                                |
| 其他網站的時間軸 | 是       | ChatGPT、Claude 與 DeepSeek 上的時間軸星號與層級                                        |
| 擴充功能設定     | 是       | 排序、顏色與輸入行為等跨裝置偏好設定                                                    |
| 外掛設定         | 是       | 安裝與啟用狀態及外掛設定；網站權限仍各自保存在每台裝置上                                |
| 模型回答         | 否       | 星號標記備份只包含使用者的提示詞，不包含模型回答                                        |

**啟用硬隔離（Hard Isolation）** 不再寫入雲端的設定檔；瀏覽器內建的同步（例如 Chrome 同步）仍會在登入同一瀏覽器設定檔的電腦之間同步它。

## 功能特點

- **多端同步**：利用雲端存儲，在多台電腦上同步您的配置。
- **數據安全**：數據存儲在您自己的 Google Drive 空間或私人 iCloud 資料庫中，不經過 Voyager 服務器，確保隱私安全。
- **靈活同步**：支持手動上傳、下載合併數據。

::: info
裝置識別碼、存取權杖、快取、視窗座標與暫時的執行狀態，刻意不會作為個人化設定同步。
:::

## 星標資料與同步限制

上傳雲端備份時，星標訊息會包含您標記的**使用者提示詞全文**（每則最多 16 KiB UTF-8），並儲存到您自己的 Google Drive 或 iCloud；星標備份不儲存模型回答。舊版 v1 備份仍只保留預覽，新版 v2 備份包含提示詞全文及刪除記錄。

刪除記錄保留 180 天。舊版 Voyager 不識別這些記錄，可能顯示或重新上傳已刪除的星標；新版會攔截時間戳未更新的舊副本。明確重新加星或刪除記錄到期後，星標可能恢復。長期離線和裝置時鐘差異也會影響刪除傳播。

同步會合併並檢查寫入結果，最多嘗試三次，但不是跨裝置的原子交易；並行上傳仍可能覆蓋其他裝置的寫入。保留缺失資料的裝置再次同步可修復這種情況，否則無法保證恢復。部分上傳失敗不會撤銷已成功的寫入，請再次同步完成修復。

## 如何使用

1. 打開 Gemini、AI Studio、ChatGPT、Claude、DeepSeek 或 Kimi 頁面，再點擊瀏覽器工具列上的 Voyager 圖標，打開彈窗。**雲端同步** 區域只會在這些網站上顯示，各網站的資料夾分別同步。
2. 找到 **雲端同步** 區域。
3. 在 Safari 上可選擇 **Google Drive** 或 **iCloud**；其他瀏覽器使用 Google Drive。
4. 將 **同步模式** 切換為 **手動**。預設為 **已停用**，切換到手動後才會出現同步按鈕。
5. 在 Safari 上使用 Google Drive 時，點擊 **連接 Google Drive**，透過 Voyager App 登入；其他瀏覽器沒有獨立的登入按鈕，第一次點擊 **上傳到雲端** 或 **從雲端下載合併** 時會跳出 Google 授權視窗。使用 iCloud 時，請確認這台 Mac 已登入 iCloud。
6. 點擊 **上傳到雲端** 將本地數據同步到雲端，或點擊 **從雲端下載合併** 將雲端數據合併到這個瀏覽器。**覆蓋下載** 會先確認，再只取代雲端有且能讀取的數據；雲端缺少或無法辨識的數據保持不變，結果中會列出。完成後可立即復原。

使用 iCloud 時，**刪除 iCloud 備份** 會移除 iCloud 中所有的 Voyager 備份；Mac 上的本地數據保持不變。

### 💡 極速同步

最簡單的方法是點擊左側側邊欄**資料夾區域標題列**上的雲朵圖示，在選單中選擇「上傳到雲端」或「從雲端同步」。

## 同步保護

<GuideFacts>
<GuideFact title="上傳確認">

如果上傳會讓雲端檔案明顯變小（本機完全沒有雲端已有的某類數據，或雲端至少 4 項而本機不到一半），或者 Voyager 讀不懂雲端檔案，會先詢問：**改為從雲端合併**、**仍要上傳** 或 **取消**。只有雲端檔案能讀取時才提供合併。

</GuideFact>
<GuideFact title="覆蓋下載只取代雲端已有的數據">

**覆蓋下載** 會保留雲端缺少或 Voyager 無法辨識的數據類型，並在結果中列出。雲端外掛清單為空時，不會清空您的外掛。

</GuideFact>
<GuideFact title="下載後立即復原">

**從雲端下載合併** 或 **覆蓋下載** 之後，只要設定面板還開著，結果列就有 **復原**。資料夾區域的雲端同步提示也提供復原，約 10 秒，滑鼠停在上面時會一直保留。復原會還原那次下載變更的內容，之後您自己的修改會保留。只能復原最近一次下載。

</GuideFact>
<GuideFact title="Google Drive 中的歷史副本">

上傳取代某個檔案之前，Voyager 會把被取代的版本保存在 Drive 的同一資料夾中，命名為 `<檔名>.backup-<UTC 時間>.json`，例如 `gemini-voyager-folders.backup-2026-10-29-031100.json`。每個檔案保留最近 3 份，更早的會移到 Drive 垃圾桶。iCloud 不保留歷史副本。

</GuideFact>
<GuideFact title="所有裝置都請更新">

開啟 **啟用硬隔離（Hard Isolation）** 後，新版 Voyager 依帳號電子郵件命名各帳號的 Drive 檔案。如果某台裝置仍在使用 Voyager 2.2.1，且最初是在帶編號的網址（gemini.google.com/u/1）上使用該帳號，它在更新之前看不到新版上傳的內容。Chrome 線上應用程式商店的更新通常幾天內送達，Safari 會更久。

</GuideFact>
</GuideFacts>

## 雲端同步與手動備份

| 面向     | 手動備份（匯出/匯入） | 雲端同步                                 |
| -------- | --------------------- | ---------------------------------------- |
| 頻率     | 想到時再做            | 一鍵即可隨時執行                         |
| 資料位置 | 電腦上的本機檔案      | 您的 Google 雲端硬碟或私人 iCloud 資料庫 |
| 跨裝置   | 需要自行傳送檔案      | 登入同一個雲端帳戶的裝置即可取用         |
| 合併方式 | 取代，或需要手動合併  | 智慧合併，不會產生重複項目               |
| 隱私     | 檔案留在您的電腦上    | 儲存在您個人的雲端帳戶中                 |

## 運作方式

1. **提供者**：Google 雲端硬碟使用有限的 `drive.file` 權限，因此 Voyager 只能存取它自己建立的檔案。在 Safari 上，iCloud 使用 App 的私人 CloudKit 資料庫，不會把 Apple ID 權杖提供給 Voyager。
2. **上傳**：點擊 **上傳到雲端** 時，Voyager 會把資料夾、提示詞、星號標記、分叉、時間軸階層、個人化設定與外掛設定，分別寫成獨立的備份檔案，存到所選的提供者。啟用醒目標示雲端同步時，也會包含醒目標示資料。
3. **下載並合併**：在另一台裝置上點擊 **從雲端下載合併** 時，Voyager 會讀取這些檔案，並依資料類型分別合併。新的資料夾與提示詞會加入且不重複，雲端偏好設定會被還原，外掛項目則依外掛 ID 合併。
4. **沒有背景同步**：同步是手動、依需求執行的。沒有您明確操作，Voyager 絕不會進行同步。

切換提供者不會在兩者之間複製資料，也不會同時寫入兩邊。若您希望目前的本機資料也出現在新選的提供者中，切換後請上傳一次。

## 支援平台

Google 雲端硬碟同步可在電腦上的 Chrome、Edge、Firefox 與 Safari 中使用；手機（Firefox for Android）上暫不支援，因為它無法開啟 Google 登入視窗。iCloud 同步僅適用於直接發布的 Safari App，並使用此 Mac 上登入的 iCloud 帳戶。
