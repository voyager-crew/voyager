# 你的數位資產：提示詞庫

磨了半天寫出個神級 Prompt，幫大忙了。
用完就丟？
不，存起來。

## 指令寶庫

這是你的指令寶庫。

### 1. 捕獲

寫出好東西了？點輸入框旁邊的 Voyager 懸浮球（預設在輸入框旁，可以拖到任何位置），打開 **提示詞管理器**。
存入庫中，落袋為安。

### 2. 歸類

打上 `代碼`、`郵件`、`學術` 的標籤（用逗號分隔）。
工具要趁手，也要整潔。

### 3. 調遣

下次要用，別再重敲。
打開庫，搜標籤，點一下插入。
一鍵調用，效率翻倍。

## 緊湊列表與備註

提示詞攢多了，一屏裝不下？面板升級：

### 視圖切換

搜尋框右側的 `≡ / ▦` 按鈕在**緊湊列表**（預設）和**舒適檢視**之間切換。

- **緊湊列表**：每條一行，一屏可見約 10 條；右側依次是標籤 · 展開 · 編輯 · 刪除
- **舒適檢視**：完整 Markdown 預覽，適合提示詞較少時使用

### 備註命名

新增或編輯 Prompt 時必須填寫表單頂部的 **備註名稱**，它會作為 Prompt 的短標題。沒有備註名稱的舊 Prompt 仍會保留，但下次編輯時需要補上名稱。

### 懸浮速覽

緊湊模式下，滑鼠懸停任意條目 **約 250 毫秒** 即可彈出浮窗查看完整內容——替換瀏覽器原生 title（1–3 秒延遲才顯示）。

### 斜線快速插入

在對話輸入框中輸入 `/`，再輸入 Prompt 備註名稱的一部分。列表顯示符合的名稱和標籤，最後還有 **管理提示詞…** 和 **Voyager 面板…** 兩項，分別開啟提示詞管理器和 [Voyager 面板](/zh_TW/guide/panel)；懸停可預覽完整正文，按滑鼠左鍵或 `Tab` / `Enter` 即可確認。輸入框會將選取的名稱顯示為醒目的 token，傳送時則使用完整 Prompt 正文。

![緊湊列表檢視](/assets/gemini-prompt-manager-compact.png)

## 任何網站皆可用

提示詞管理器現在可以在您選擇的任何網站上使用，不僅限於 Gemini™ 和 AI Studio。

### 如何啟用

在 Claude、ChatGPT、DeepSeek 和 Kimi 上，提示詞管理器是該網站 **外掛** 卡片中的一列。在該網站頁面打開 Voyager 彈窗，開啟 **提示詞管理器** 即可；如果這是在該網站上開啟的第一個功能，瀏覽器會要求一次該網站的存取權限。

其他任何網站：

1. 點擊瀏覽器擴充功能欄的 Voyager 圖標。
2. 在 **網站存取** 卡片中找到 **其他網站**。
3. 輸入網站網址（例如：`poe.com`）。
4. 點擊 **新增網站** 並授予權限。
5. **刷新目標網頁**，即可看到懸浮球。

### 常見 AI 網站示例

- `copilot.microsoft.com` - Microsoft Copilot
- `poe.com` - Poe

### 本機應用

本機位址同樣可以填 —— 輸入 `localhost:3080` 或 `127.0.0.1:3080` 即可。例如 [DeepSeek Harness](/zh_TW/guide/deepseek-harness) 執行在 `localhost:3080`，提示詞管理器會像在一般網站上一樣掛載。

![在 DeepSeek Harness 中執行的提示詞管理器](/assets/prompt-manager-deepseek-harness.png)

::: tip
在您自行添加的網站上，**僅**激活提示詞管理器功能。時間軸、資料夾等其他功能不會加載。Claude、ChatGPT、DeepSeek 和 Kimi 不同：它們有各自的官方外掛，可以在[外掛一覽](/zh_TW/guide/plugins)中瀏覽。
:::
