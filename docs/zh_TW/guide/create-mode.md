# 創造模式

用一句話說出你想讓網站變成什麼樣子，這個網站自己的 AI 會把它寫成外掛，Voyager 檢查後幫你裝上。不用寫程式碼，也不用離開目前的對話。Gemini、AI Studio、ChatGPT、Claude、DeepSeek 和 Kimi 上都能用。

創造模式有兩個入口：網頁裡 [Voyager 面板](./panel.md) 的 **創造** 分頁，和 Voyager 彈出視窗裡的 **我的創造** 卡片。做出來的是只存在你瀏覽器裡的本機外掛。想自己寫外掛或交給程式設計 Agent，請見 [撰寫自己的外掛](./write-a-plugin.md)。

## 在頁面上創造

<GuideOp>

最快的做法就在外掛要用的那個 AI 網站上：打開 Voyager 面板，選擇 **創造**。

</GuideOp>

<GuideSteps>
<GuideStep>

在 **想改什麼？** 下面寫一句話，例如「讓我的訊息窄一點，並隱藏側邊欄」，然後點 **在此頁創造**。

</GuideStep>
<GuideStep>

Voyager 會在這個網站新增一個對話，把請求填進輸入框。確認一遍，再自己送出：Voyager 不會替你按送出。輸入框裡已經有內容時，Voyager 不會動它，並提示你先送出或清空。

</GuideStep>
<GuideStep>

AI 讀完 Voyager 為這個網站準備的說明頁，回覆一個 JSON 程式碼區塊。程式碼區塊下方會出現 Voyager 的 **預覽並安裝**。

</GuideStep>
<GuideStep>

點它，面板會開啟審閱：外掛在哪些網站生效、每一處改動、完整的 CSS，以及 **請先留意** 的地方。點 **安裝並開啟**，外掛立即生效，隨時可以在 **功能** 分頁裡關掉。

</GuideStep>
</GuideSteps>

<GuideOp>

想再改，直接在同一個對話裡告訴 AI。

- **新版本**：新回覆下方會出現 **預覽更新**，審閱後點 **更新並開啟**；舊的程式碼區塊標為 **較早的版本**。
- **已裝過**：已經裝上的那一版會顯示 **已安裝**。
- **只認創造對話**：Voyager 只在你的訊息帶有 Voyager 創造頁連結的對話裡讀取回覆，**在此頁創造** 填入的請求總會帶上它。其他對話的回覆下方什麼都不會出現，可以改用下面彈出視窗裡的做法。

</GuideOp>

## 附上頁面結構

<GuideOp>

**創造** 分頁裡有一個開關：**附上這個頁面的結構（不含任何文字），讓 AI 依頁面的實際情況來寫**。它預設開啟，讓 AI 照著頁面真實的樣子寫，而不是用猜的。

- **附上什麼**：Voyager 能認出的頁面元素和數量，加上最近一則回覆和你最近一則訊息周圍的元素層級。
- **不附什麼**：頁面上的任何文字、連結、對話內容，以及像 ID、電子郵件、長數字這類看起來是資料的屬性值。
- **查看附上的內容**：展開它，看到的就是會附上的原文，一字不差。頁面有變化時它也會重新讀取。
- **關掉**：關掉開關，請求裡就只有你那句話。

</GuideOp>

## Gemini 上的模型提示

<GuideOp>

在 Gemini 上，Voyager 會先看新對話會用哪個模型。如果是 Flash 或 Flash-Lite 這類較輕量的模型，**創造** 分頁頂端會提示它通常寫不出外掛。

- **建議**：提示會寫明可以在 Gemini 的模型選單裡換成哪個更強的模型，或是把需求交給本機程式設計 Agent（**複製給本機 Agent** 按鈕就在提示裡）。
- **重新檢查**：在 Gemini 裡換好模型後，點 **重新檢查**；回到面板時 Voyager 也會再看一次。
- **預設模型**：如果你用了 [預設模型](./default-model.md)，Voyager 會依新對話會套用的那個預設模型來判斷。
- **不擋你**：這只是提醒，**在此頁創造** 照樣能點。

</GuideOp>

## 回覆裝不上時

<GuideOp>

AI 的回覆不一定每次都合格。裝不上的回覆下方會寫明原因，例如「它沒寫明用在哪個網站」或「其中有一項改動不被允許」。

- **請它修正**：點回覆下方的 **請它修正**，Voyager 會把問題清單接在輸入框既有內容的後面，由你來送出。
- **修好之後**：AI 回覆修好的版本時，下方會再出現 **預覽並安裝**。
- **審閱時**：如果在面板審閱時才發現問題，Voyager 不會安裝任何東西，並列出問題。

</GuideOp>

## 裝好之後

<GuideOp>

裝好的創造都在 **我的創造** 裡。面板裡它在 **功能** 分頁的 **我的創造** 一組；在彈出視窗裡，Gemini 和 AI Studio 上它是一張設定卡片，預設緊接在 **雲端同步** 下方，位置可以調整，彈出視窗頂端的 **跳至** 目錄能直接跳過去；ChatGPT、Claude、DeepSeek 和 Kimi 上它在外掛清單下方。

- **開關**：每個創造一列，和其他功能一樣開關。
- **移除**：點垃圾桶圖示，確認後就會從這個瀏覽器移除，無法復原。
- **匯出**：在彈出視窗的 **我的創造** 清單裡對它選擇 **匯出**，再到另一個瀏覽器匯入這個 JSON 檔案。
- **提議收錄**：如果它對大家都有幫助，可以提議收進官方外掛目錄，流程請見 [外掛貢獻說明](./plugin-contribution.md)。

</GuideOp>

### 自動檢查

<GuideOp>

面板開啟時，Voyager 會看看 **我的創造** 裡的每個創造在目前頁面上有沒有發揮作用。

- **沒有對應的內容**：一個改外觀的創造已開啟，但頁面上沒有任何它要改的元素，它那一列會顯示 **已開啟，但這個頁面上沒有它能對應的內容**。懸停、聚焦這類狀態，以及只呼叫內建功能的創造，都不算在內。
- **頁面卡住**：一個會執行程式碼的創造讓頁面失去回應時，Voyager 已經把它關掉，那一列會寫明原因。
- **請 AI 修正**：這兩種情況旁邊都有 **請 AI 修正**。Voyager 會在這個網站新增對話，填入它在頁面上看到的情況和外掛目前安裝的版本（頁面結構開關開啟時連結構一起附上），面板隨之關閉，由你確認後送出。

</GuideOp>

## 替 Voyager 換配色

<GuideOp>

創造也能替網頁上的 Voyager 介面換色，同樣只要一句話，例如「把 Voyager 的面板和時間軸換成 Nord 配色」。AI 會在一條 `:root` 規則裡設定 Voyager 公開的顏色變數，淺色和深色主題都會生效。

- **跟著換的**：面板、選單、對話框、提示和通知的背景、文字、邊框和懸停色；按鈕、選取和焦點的強調色；刪除用的危險色。
- **時間軸**：時間軸的軌道、未選取的圓點和刻度，以及左側滑桿的軌道，有自己的一個顏色。
- **維持原樣的**：Voyager 直接畫在網站頁面上的文字、邊框和懸停色會繼續跟著網站走，免得淺色文字落在網站的淺色背景上看不清楚。Voyager 彈出視窗不受影響。

</GuideOp>

<GuideNote>

**Nord 範例**：上面那句話通常會得到這樣的 CSS。沒設定的變數會保留 Voyager 原本的顏色。

```css
:root {
  --gv-theme-surface: #2e3440;
  --gv-theme-hover: #3b4252;
  --gv-theme-text: #eceff4;
  --gv-theme-text-muted: #d8dee9;
  --gv-theme-border: #4c566a;
  --gv-theme-accent: #88c0d0;
  --gv-theme-accent-fg: #2e3440;
  --gv-theme-danger: #bf616a;
  --gv-theme-timeline: #81a1c1;
}
```

全部變數：`--gv-theme-surface`（背景）、`-hover`（懸停列）、`-text`（文字）、`-text-muted`（次要文字、圖示）、`-border`（邊框）、`-accent`（按鈕、選取、焦點）、`-accent-fg`（強調色上的文字）、`-accent-hue`（強調色的 OKLCH 色相，一個數字）、`-danger`（刪除）、`-timeline`（網站背景上的軌道和圓點）。

</GuideNote>

## 不用面板：在彈出視窗裡創造

<GuideOp>

不想新開對話，或想在別的對話、別的 AI 上讓它寫，可以從彈出視窗的 **我的創造** 開始。外掛清單末尾的 **自己創造一個** 會直接帶你到輸入框。

</GuideOp>

<GuideSteps>
<GuideStep>

在 **想改什麼？** 下面寫一句話。下方的 **網站** 預設是目前分頁的網站；外掛要用在別的網站時，改一下即可。

</GuideStep>
<GuideStep>

點 **複製到目前對話**，把訊息貼到該網站的 AI 對話裡。AI 會先讀 Voyager 為該網站準備的說明頁（例如 `https://voyager.nagi.fun/create/claude.md`），然後只回覆一個 JSON 程式碼區塊。AI 必須能打開連結。

</GuideStep>
<GuideStep>

把完整回覆貼到 **貼上 AI 的回覆**，點 **檢查回覆**。

</GuideStep>
<GuideStep>

Voyager 會用白話說明這個外掛改了什麼。點 **匯入**，再到外掛清單裡把它開啟；在 Gemini 和 AI Studio 上，它的開關就在卡片下方。用這種方式匯入的外掛預設是關閉的。

</GuideStep>
</GuideSteps>

<GuideOp>

這條路上 Voyager 自己不會送出任何東西：訊息由你貼過去，回覆也由你帶回來。

</GuideOp>

## 會執行程式碼的創造

<GuideOp>

CSS 和頁面修改做不到的需求，例如統計你送出了幾則訊息、點一下就做點什麼，AI 可以寫一個執行 JavaScript 的創造。Voyager 透過 Chrome 的使用者指令碼執行它，只在它列出的網站上執行，而且要等你讀過程式碼之後。審閱時，這類創造會帶有 **執行程式碼** 標記。

</GuideOp>

### 開啟它

<GuideOp>

- **先讀程式碼**：審閱會列出它執行的網站，並完整顯示原始碼。它能讀到這些頁面上的一切，包括你的對話，Voyager 也擋不住它把讀到的內容傳到別處，所以只安裝你信得過的程式碼。
- **安裝並開啟**：開啟的正是你讀過的這份程式碼。之後它的程式碼或網站有變動，就會先暫停，等你重新審閱；這個開關也不會同步到你的其他裝置。
- **一次性開關**：Chrome 要你允許之後，擴充功能才能執行這類程式碼。點 **開啟 Voyager 詳細資料頁面**，在那裡開啟 **允許使用者指令碼**（Allow User Scripts；Chrome 138 之前是 `chrome://extensions` 頂端的 **開發人員模式**），回來再點 **我已開啟**。
- **瀏覽器**：桌面版 Chrome 或 Edge 133 以上。在 Safari、Firefox 和手機上，它會保留但處於暫停狀態；可以請 AI 改成只改外觀的版本。

</GuideOp>

### 隨時掌控

<GuideOp>

在 **我的創造** 裡，每個會執行程式碼的創造都會顯示 **已開啟，僅限這台裝置**、**已關閉** 或 **已暫停** 及原因。

- **全部停止**：在 **我的創造** 末尾（彈出視窗裡的卡片，或面板的 **功能** 分頁）點 **停止所有執行程式碼的創造**，會一次停下全部；點 **恢復** 重新啟用。
- **已開啟的頁面**：已經開啟的頁面會繼續執行它們，直到重新載入。點 **重新整理這個頁面** 就能重新載入目前的分頁。
- **頁面卡住**：如果這些創造執行後頁面失去回應，Voyager 會關閉它們，並在頁面下次載入時用通知寫明是哪幾個。修好之後，在 **我的創造** 裡重新審閱，再開啟。

</GuideOp>

## 能做到什麼，做不到什麼

<GuideOp>

大多數創造只改外觀和版面，本身不執行程式碼，關閉時所有修改都會還原。

- **能做**：改樣式、隱藏頁面上的部分內容、在設定裡加開關和滑桿、替 Voyager 換色，在外掛網站上還能啟用 Voyager 的內建功能（公式複製、時間軸、Mermaid 圖表等）。
- **要執行程式碼**：回應點擊、統計、讀取頁面內容這類需求，需要會執行程式碼的創造，見上文。
- **誰都做不到**：任何創造都不能在其他網站上執行，也不能改 Voyager 自己的設定。遇到這類需求，AI 會直接說明，並做出最接近、又真的能實現的版本。
- **詳細規則**：外掛能用哪些欄位、匯入時檢查什麼，請見 [撰寫自己的外掛](./write-a-plugin.md#外掛能做什麼)。

</GuideOp>
