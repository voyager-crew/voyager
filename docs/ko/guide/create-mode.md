# 창작 모드

사이트를 어떻게 바꾸고 싶은지 한 문장으로 말하세요. 그 사이트의 AI가 이를 플러그인으로 작성하고, Voyager가 검사한 뒤 설치해 줍니다. 코드를 쓸 필요도, 지금 있는 채팅을 떠날 필요도 없습니다. Gemini, AI Studio, ChatGPT, Claude, DeepSeek, Kimi에서 쓸 수 있습니다.

창작 모드의 입구는 두 곳입니다. 페이지 위에서 여는 [Voyager 패널](./panel.md)의 **만들기** 탭과, Voyager 팝업의 **내 창작물** 카드입니다. 만들어지는 것은 내 브라우저에만 있는 로컬 플러그인입니다. 플러그인을 직접 작성하거나 코딩 에이전트에게 맡기려면 [직접 플러그인 만들기](./write-a-plugin.md)를 보세요.

## 페이지에서 만들기

<GuideOp>

가장 빠른 방법은 플러그인을 쓸 AI 사이트에서 바로 만드는 것입니다. 그 사이트에서 Voyager 패널을 열고 **만들기**를 고르세요.

</GuideOp>

<GuideSteps>
<GuideStep>

**무엇을 바꿀까요?** 아래에 "내 메시지 폭을 좁히고 사이드바를 숨겨 줘" 같은 한 문장을 쓰고 **이 페이지에서 만들기**를 고르세요.

</GuideStep>
<GuideStep>

Voyager가 그 사이트에서 새 채팅을 열고 요청을 입력창에 넣습니다. 확인한 뒤 직접 보내세요. Voyager는 보내기를 누르지 않습니다. 입력창에 이미 내용이 있으면 Voyager는 그대로 두고, 먼저 보내거나 지워 달라고 알려 줍니다.

</GuideStep>
<GuideStep>

AI가 그 사이트용 Voyager 페이지를 읽고 JSON 코드 블록 하나로 답합니다. 블록 아래에 Voyager가 **미리 보고 설치**를 붙입니다.

</GuideStep>
<GuideStep>

그것을 고르면 패널이 검토 화면을 엽니다. 플러그인이 동작하는 사이트, 각 변경, 전체 CSS, 그리고 **먼저 확인하세요** 아래의 내용이 나옵니다. **설치하고 켜기**를 고르면 바로 적용되며, 언제든 **기능** 탭에서 끌 수 있습니다.

</GuideStep>
</GuideSteps>

<GuideOp>

플러그인을 바꾸려면 같은 채팅에서 AI에게 말하세요.

- **새 버전**: 새 답변 아래에 **업데이트 미리 보기**가 나오고, 이어서 **업데이트하고 켜기**를 고르면 됩니다. 이전 블록에는 **이전 버전**이 표시됩니다.
- **이미 설치한 버전**: 설치한 버전에는 **설치됨**이 표시됩니다.
- **만들기 채팅에서만**: Voyager는 내 메시지에 Voyager 만들기 페이지 링크가 있는 채팅에서만 답변을 읽습니다. **이 페이지에서 만들기**가 넣는 요청에는 항상 들어 있습니다. 다른 채팅에서는 답변 아래에 아무것도 나오지 않으니 아래 팝업 방법을 쓰세요.

</GuideOp>

## 페이지 구조 덧붙이기

<GuideOp>

**만들기** 탭에는 스위치가 하나 있습니다. 바로 **이 페이지의 구조를 텍스트 없이 덧붙여 AI가 실제 페이지에 맞게 작성하도록 하기**입니다. 기본으로 켜져 있어서, AI가 짐작하지 않고 실제 페이지에 맞춰 작성합니다.

- **덧붙이는 것**: Voyager가 알아보는 페이지 요소와 그 개수, 그리고 최근 답변과 내 최근 메시지 주변의 요소 트리.
- **빼는 것**: 페이지의 모든 텍스트, 링크, 채팅 내용, 그리고 ID, 이메일, 긴 숫자처럼 데이터로 보이는 속성값.
- **덧붙는 내용 보기**: 펼치면 실제로 덧붙을 텍스트를 그대로 읽을 수 있습니다. 페이지가 바뀌면 다시 읽어 옵니다.
- **끄기**: 스위치를 끄면 요청에는 내 문장만 들어갑니다.

</GuideOp>

## Gemini의 모델 알림

<GuideOp>

Gemini에서는 Voyager가 먼저 새 채팅이 어떤 모델을 쓸지 확인합니다. Flash나 Flash-Lite 같은 가벼운 모델이라면 **만들기** 탭 위쪽에 그 모델로는 보통 플러그인을 작성하기 어렵다는 알림이 나옵니다.

- **제안**: 알림에는 Gemini 모델 메뉴에서 고를 만한 더 강한 모델 이름이 나옵니다. 요청을 로컬 코딩 에이전트에게 넘길 수도 있습니다(알림 안에 **로컬 에이전트용으로 복사**가 있습니다).
- **다시 확인**: Gemini에서 모델을 바꾼 뒤 **다시 확인**을 고르세요. 패널로 돌아올 때도 Voyager가 다시 확인합니다.
- **기본 모델**: [기본 모델](./default-model.md)을 쓰고 있다면 Voyager는 새 채팅에 적용될 기본 모델을 기준으로 판단합니다.
- **막지는 않음**: 알림일 뿐입니다. **이 페이지에서 만들기**는 그대로 쓸 수 있습니다.

</GuideOp>

## 답변을 설치할 수 없을 때

<GuideOp>

모든 답변이 제대로 나오지는 않습니다. Voyager가 설치할 수 없는 답변 아래에는 "어느 사이트에 적용할지 적혀 있지 않습니다"나 "변경 사항 중 하나가 허용되지 않습니다"처럼 그 이유가 쉬운 말로 나옵니다.

- **AI에게 수정 요청**: 답변 아래의 **AI에게 수정 요청**을 고르세요. Voyager가 문제 목록을 입력창에 이미 쓴 내용 뒤에 넣어 주니, 보내는 것은 직접 하세요.
- **고친 뒤**: AI가 고친 버전으로 답하면 그 아래에 **미리 보고 설치**가 나옵니다.
- **검토 중**: 패널의 검토 화면에서야 문제가 드러나면 Voyager는 아무것도 설치하지 않고 문제를 나열합니다.

</GuideOp>

## 설치한 뒤

<GuideOp>

설치한 것은 모두 **내 창작물**에 있습니다. 패널에서는 **기능** 탭의 한 그룹입니다. 팝업에서는 Gemini와 AI Studio의 경우 설정 카드 중 하나로, 옮기지 않았다면 **클라우드 동기화** 바로 아래에 있고 팝업 상단의 **바로 가기**에서도 이동할 수 있습니다. ChatGPT, Claude, DeepSeek, Kimi에서는 플러그인 목록 아래에 있습니다.

- **스위치**: 창작물마다 한 줄이 있고, 다른 기능처럼 켜고 끕니다.
- **제거**: 휴지통 아이콘을 누르고 확인하면 이 브라우저에서 제거됩니다. 되돌릴 수 없습니다.
- **내보내기**: 팝업의 **내 창작물** 목록에서 그 창작물의 **내보내기**를 선택한 뒤, 다른 브라우저에서 JSON 파일을 가져오세요.
- **공유하기**: 모두에게 도움이 될 만하다면 공식 카탈로그에 넣자고 제안할 수 있습니다. 그 과정은 [플러그인 기여 가이드](./plugin-contribution.md)에서 설명합니다.

</GuideOp>

### 자동 점검

<GuideOp>

패널을 열면 Voyager가 **내 창작물**의 각 창작물이 현재 페이지에서 무언가를 하고 있는지 살펴봅니다.

- **일치하는 요소 없음**: 모양을 바꾸는 창작물이 켜져 있지만, 그것이 바꾸는 요소가 이 페이지에 하나도 없는 경우입니다. 그 줄에는 **켜져 있지만 이 페이지에서 일치하는 요소가 없습니다**라고 표시됩니다. 호버와 포커스 상태, 그리고 내장 기능만 호출하는 창작물은 세지 않습니다.
- **멈춘 페이지**: 코드를 실행하는 창작물 때문에 페이지가 응답하지 않게 되면 Voyager가 이미 그 창작물을 껐고, 그 줄에 이유가 나옵니다.
- **수정 요청하기**: 두 경우 모두 **수정 요청하기**가 나옵니다. Voyager는 이 사이트에서 새 채팅을 열고, 페이지에서 본 것과 설치된 플러그인을 채워 넣습니다(페이지 구조 스위치가 켜져 있으면 페이지 구조도 함께 넣습니다). 패널이 닫히니 내용을 읽고 보내세요.

</GuideOp>

## Voyager 색 바꾸기

<GuideOp>

창작물로 페이지 위의 Voyager UI 색도 바꿀 수 있습니다. 이번에도 "Voyager 패널과 타임라인을 Nord 팔레트로 바꿔 줘" 같은 한 문장이면 됩니다. AI는 Voyager의 공개 색상 변수를 `:root` 규칙 하나에 설정하며, 라이트와 다크 테마 모두에 똑같이 적용됩니다.

- **팔레트를 따르는 것**: 패널, 메뉴, 대화상자, 툴팁, 토스트의 배경, 글자, 테두리, 호버 색. 버튼, 선택, 포커스의 강조색. 삭제에 쓰는 위험 색.
- **타임라인**: 레일, 선택되지 않은 점과 눈금, 왼쪽 슬라이더의 트랙은 따로 색 하나를 씁니다.
- **계속 사이트를 따르는 것**: Voyager가 사이트 페이지에 바로 그리는 글자, 테두리, 호버 색은 사이트 색을 따릅니다. 그래서 밝은 글자가 사이트의 밝은 배경 위에 놓이는 일이 없습니다. Voyager 팝업은 영향을 받지 않습니다.

</GuideOp>

<GuideNote>

**Nord 예시**: 위 문장을 보내면 보통 이런 CSS가 나옵니다. 설정하지 않은 변수는 Voyager 원래 색을 유지합니다.

```css
:root {
  --gv-theme-surface: #2e3440;
  --gv-theme-hover: #3b4252;
  --gv-theme-text: #eceff4;
  --gv-theme-text-muted: #d8dee9;
  --gv-theme-border: #4c566a;
  --gv-theme-accent: #88c0d0;
  --gv-theme-accent-fg: #2e3440;
  --gv-theme-danger: #bf616a;
  --gv-theme-timeline: #81a1c1;
}
```

전체 변수: `--gv-theme-surface`(배경), `-hover`(호버한 행), `-text`(글자), `-text-muted`(보조 글자, 아이콘), `-border`(테두리), `-accent`(버튼, 선택, 포커스), `-accent-fg`(강조색 위의 글자), `-accent-hue`(강조색의 OKLCH 색상각, 숫자), `-danger`(삭제), `-timeline`(사이트 배경 위의 레일과 점).

</GuideNote>

## 패널 없이: 팝업에서 만들기

<GuideOp>

새 채팅을 열고 싶지 않거나, 다른 채팅이나 다른 AI에게 작성을 맡기고 싶다면 팝업의 **내 창작물**에서 시작하세요. 플러그인 목록 끝의 **직접 만들기**를 누르면 첫 입력란으로 이동합니다.

</GuideOp>

<GuideSteps>
<GuideStep>

**무엇을 바꿀까요?** 아래에 한 문장을 쓰세요. 그 아래 **사이트**는 지금 열린 탭의 사이트로 시작합니다. 다른 사이트용 플러그인이라면 바꾸세요.

</GuideStep>
<GuideStep>

**이 채팅용으로 복사**를 선택하고 그 사이트의 AI 채팅에 메시지를 붙여 넣습니다. AI는 그 사이트용 Voyager 페이지(예: `https://voyager.nagi.fun/create/claude.md`)를 읽고 JSON 코드 블록 하나로 답합니다. AI가 링크를 열 수 있어야 합니다.

</GuideStep>
<GuideStep>

답변 전체를 **AI 답변 붙여넣기** 칸에 붙여 넣고 **답변 검사**를 선택합니다.

</GuideStep>
<GuideStep>

Voyager가 이 플러그인이 무엇을 바꾸는지 쉬운 말로 보여 줍니다. **가져오기**를 선택한 다음 플러그인 목록에서 켜세요. Gemini와 AI Studio에서는 스위치가 카드 바로 아래에 나타납니다. 이렇게 가져온 플러그인은 꺼진 상태로 시작합니다.

</GuideStep>
</GuideSteps>

<GuideOp>

이 방법에서는 Voyager가 스스로 아무것도 보내지 않습니다. 메시지를 붙여 넣는 것도, 답변을 가져오는 것도 사용자가 직접 합니다.

</GuideOp>

## 코드를 실행하는 창작물

<GuideOp>

보낸 메시지 수를 세거나 클릭에 반응하는 것처럼 CSS와 페이지 변경으로 할 수 없는 요청이라면, AI가 JavaScript를 실행하는 창작물을 쓸 수 있습니다. Voyager는 이를 Chrome의 사용자 스크립트로, 창작물이 지정한 사이트에서만, 그리고 내가 코드를 읽은 뒤에만 실행합니다. 검토 화면에서 이런 창작물에는 **코드 실행** 배지가 붙습니다.

</GuideOp>

### 켜기

<GuideOp>

- **읽기**: 검토 화면에 실행되는 사이트와 전체 소스 코드가 나옵니다. 이 창작물은 해당 페이지의 모든 내용을, 내 채팅까지 포함해 읽을 수 있습니다. 읽은 내용을 다른 곳으로 보내는 것을 Voyager가 막을 수 없으니 믿을 수 있는 코드만 설치하세요.
- **설치하고 켜기**: 내가 읽은 바로 그 코드만 켜집니다. 나중에 코드나 사이트가 바뀌면 다시 검토할 때까지 일시 중지되며, 이 스위치는 다른 기기로 동기화되지 않습니다.
- **한 번만 하는 설정**: Chrome에서는 허용해야만 확장 프로그램이 이런 코드를 실행할 수 있습니다. **Voyager 세부정보 페이지 열기**를 누르고 그곳에서 **사용자 스크립트 허용**(Allow User Scripts, Chrome 138 이전에는 `chrome://extensions` 상단의 **개발자 모드**)을 켠 뒤 돌아와 **켰어요**를 누르세요.
- **브라우저**: 데스크톱 Chrome 또는 Edge 133 이상. Safari, Firefox, 휴대폰에서는 설치된 채로 일시 중지됩니다. 페이지 모양만 바꾸는 버전을 AI에게 요청하세요.

</GuideOp>

### 계속 관리하기

<GuideOp>

**내 창작물**에서 코드를 실행하는 각 창작물은 **켜짐, 이 기기에서만**, **꺼짐**, 또는 이유와 함께 **일시 중지됨**으로 표시됩니다.

- **모두 중지**: **내 창작물** 맨 아래(팝업 카드 또는 패널의 **기능** 탭)에서 **코드를 실행하는 창작물 모두 멈추기**를 누르면 한 번에 모두 멈추고, **다시 시작**으로 되돌립니다.
- **열려 있는 페이지**: 이미 열려 있는 페이지는 새로고침할 때까지 계속 실행합니다. **이 페이지 새로고침**으로 현재 탭을 새로고침할 수 있습니다.
- **멈췄을 때**: 이런 창작물이 실행된 뒤 페이지가 응답하지 않으면 Voyager가 해당 창작물을 끄고, 다음에 페이지를 열 때 알림으로 이름을 알려 줍니다. 고친 뒤 **내 창작물**에서 다시 검토하고 켜세요.

</GuideOp>

## 할 수 있는 일과 할 수 없는 일

<GuideOp>

대부분의 창작물은 페이지의 모양과 레이아웃만 바꾸고, 스스로 코드를 실행하지 않으며, 끄면 모든 변경을 되돌립니다.

- **할 수 있는 일**: 페이지 스타일 바꾸기, 일부 숨기기, 설정에 스위치와 슬라이더 추가하기, Voyager 색 바꾸기. 플러그인 사이트에서는 Voyager 내장 기능(수식 복사, 타임라인, Mermaid 다이어그램 등)을 켤 수도 있습니다.
- **코드가 필요한 일**: 클릭에 반응하기, 개수 세기, 페이지 읽기는 위에서 설명한 코드를 실행하는 창작물이 맡습니다.
- **어떤 창작물도 할 수 없는 일**: 다른 사이트에서 실행되기, Voyager 자체 설정 바꾸기. 이런 요청이면 AI가 그렇다고 말하고, 실제로 가능한 가장 가까운 형태로 만듭니다.
- **전체 규칙**: 플러그인이 쓸 수 있는 필드와 가져올 때 검사하는 내용은 [직접 플러그인 만들기](./write-a-plugin.md#플러그인이-할-수-있는-일)에 있습니다.
