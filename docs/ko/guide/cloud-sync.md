# 클라우드 동기화

Voyager 클라우드 동기화는 폴더, 프롬프트 라이브러리, 별표 메시지, 지원되는 설정을 백업합니다. 지원되는 모든 브라우저에서 Google Drive를 선택할 수 있고, Safari에서는 iCloud도 선택할 수 있습니다. 데이터는 Voyager와 사용자가 선택한 개인 클라우드 계정 사이를 직접 오가며, Voyager는 동기화 서버를 운영하지 않습니다.

## 동기화되는 데이터

| 데이터 유형            | 동기화 | 세부 사항                                                                             |
| ---------------------- | ------ | ------------------------------------------------------------------------------------- |
| 폴더 구조              | 예     | Gemini, AI Studio, ChatGPT, Claude, DeepSeek, Kimi의 폴더, 중첩 구조, 색상, 대화 할당 |
| 프롬프트 라이브러리    | 예     | 태그와 폴더 구성이 포함된 저장된 모든 프롬프트                                        |
| 별표 메시지            | 예     | 모든 대화의 타임라인 북마크                                                           |
| 다른 사이트의 타임라인 | 예     | ChatGPT, Claude, DeepSeek의 타임라인 별표와 레벨                                      |
| 확장 프로그램 설정     | 예     | 정렬, 색상, 입력 동작 같은 기기 간 공유 환경설정                                      |
| 플러그인 구성          | 예     | 설치/활성화 상태와 플러그인 설정. 사이트 권한은 기기별로 유지됩니다                   |
| 모델 답변              | 아니요 | 별표 백업에는 사용자의 프롬프트가 포함되며, 모델 답변은 포함되지 않습니다             |

**Enable Hard Isolation**은 더 이상 클라우드 설정 파일에 포함되지 않습니다. 브라우저 자체 동기화(예: Chrome 동기화)는 같은 브라우저 프로필로 로그인한 컴퓨터 사이에서 계속 이 설정을 동기화합니다.

## 별표 데이터와 동기화 제한

클라우드 업로드에는 **별표로 표시한 사용자 프롬프트의 전체 텍스트**(프롬프트당 UTF-8 최대 16 KiB)가 포함되며, 본인의 Google Drive 또는 iCloud에 저장됩니다. 별표 백업에는 모델 답변이 저장되지 않습니다. 기존 v1 백업은 미리보기만 유지하고, 새 v2 백업은 프롬프트 텍스트와 삭제 기록을 포함합니다.

삭제 기록은 180일 동안 유지됩니다. 이전 Voyager 버전은 이를 무시하여 삭제된 별표를 다시 표시하거나 업로드할 수 있지만, 새 버전은 타임스탬프가 같은 오래된 복사본을 차단합니다. 더 최근 시점에 다시 별표를 표시하거나 삭제 기록이 만료되면 별표가 복원될 수 있습니다. 장기간 오프라인 상태와 기기 시계 차이도 삭제 전파에 영향을 줍니다.

동기화는 데이터를 병합하고 쓰기 결과를 확인하며 최대 세 번 시도하지만, 기기 간 원자적 트랜잭션은 아닙니다. 동시 업로드가 다른 기기의 쓰기를 덮어쓸 수 있습니다. 누락된 데이터를 유지한 기기가 나중에 동기화하면 복구할 수 있지만, 다시 동기화하지 않으면 복구를 보장할 수 없습니다. 일부 업로드가 실패해도 성공한 쓰기는 유지됩니다. 다시 동기화하여 복구를 완료하세요.

## 주요 기능

- **다중 기기 동기화**: 여러 컴퓨터 간에 설정을 동기화 상태로 유지합니다.
- **데이터 프라이버시**: 데이터가 본인의 Google Drive 또는 비공개 iCloud 데이터베이스에 직접 저장되므로 Voyager 서버 없이 프라이버시가 보장됩니다.
- **유연한 동기화**: 수동 업로드 및 데이터 다운로드/병합을 지원합니다.

::: info
기기 식별자, 액세스 토큰, 캐시, 뷰포트 좌표, 임시 런타임 상태는 개인화 설정으로 의도적으로 동기화되지 않습니다.
:::

## 사용 방법

1. Gemini, AI Studio, ChatGPT, Claude, DeepSeek 또는 Kimi 탭을 연 뒤 브라우저 툴바의 Voyager 아이콘을 클릭하여 팝업을 엽니다. **클라우드 동기화** 섹션은 이 사이트들에서만 표시되며, 폴더는 사이트별로 따로 동기화됩니다.
2. **클라우드 동기화 (Cloud Sync)** 섹션을 찾습니다.
3. Safari에서는 **Google Drive** 또는 **iCloud**를 선택합니다. 다른 브라우저는 Google Drive를 사용합니다.
4. **동기화 모드**를 **수동**으로 바꿉니다. 기본값은 **비활성화**이며, 동기화 버튼은 수동 모드에서만 나타납니다.
5. Safari에서 Google Drive를 사용하는 경우 **Google Drive 연결**을 클릭해 Voyager 앱에서 로그인합니다. 다른 브라우저에는 별도의 로그인 버튼이 없으며, 처음 **업로드** 또는 **다운로드 및 병합**을 클릭할 때 Google 승인 창이 열립니다. iCloud의 경우 Mac이 iCloud에 로그인되어 있는지 확인합니다.
6. 로컬 데이터를 클라우드로 보내려면 **업로드**를 클릭하고, 클라우드 데이터를 이 브라우저에 병합하려면 **다운로드 및 병합**을 클릭합니다. **덮어쓰기**는 먼저 확인한 뒤, 클라우드에 있고 Voyager가 읽을 수 있는 데이터만 교체합니다. 클라우드에 없거나 읽을 수 없는 데이터는 그대로 남고, 결과에 표시됩니다. 직후에는 실행 취소할 수 있습니다.

iCloud를 사용하는 경우 **iCloud 백업 삭제**를 누르면 iCloud에 있는 모든 Voyager 백업이 삭제됩니다. Mac의 로컬 데이터는 그대로 유지됩니다.

### 💡 빠른 동기화

가장 쉬운 방법은 왼쪽 사이드바의 폴더 영역 헤더에 있는 클라우드 아이콘을 클릭한 뒤 메뉴에서 **클라우드에 업로드** 또는 **클라우드에서 동기화**를 선택하는 것입니다.

**보안 권장 사항: 이중 보호**  
클라우드 동기화는 매우 편리하지만, 정기적으로 **로컬 파일**을 사용하여 핵심 데이터를 백업하는 것을 강력히 권장합니다.

1. **폴더**: 폴더 영역의 메뉴를 열고 **폴더 가져오기/내보내기**를 선택한 다음 **폴더 내보내기**를 선택하여 모든 폴더와 대화 할당을 저장합니다.
2. **프롬프트**: 프롬프트 관리자에서 **내보내기**를 클릭하여 프롬프트 라이브러리를 저장합니다.
   :::

## 동기화 보호

<GuideFacts>
<GuideFact title="업로드 확인">

업로드하면 클라우드 파일이 크게 줄어드는 경우(클라우드에 있는 어떤 데이터가 이 기기에는 하나도 없거나, 클라우드에 4개 이상 있는데 이 기기에는 절반도 안 되는 경우) 또는 Voyager가 클라우드 파일을 읽을 수 없는 경우, 먼저 **대신 클라우드에서 병합**, **그래도 업로드**, **취소** 중에서 고르게 합니다. 병합은 클라우드 파일을 읽을 수 있을 때만 제공됩니다.

</GuideFact>
<GuideFact title="덮어쓰기는 있는 데이터만 교체">

**덮어쓰기**는 클라우드에 없거나 Voyager가 읽을 수 없는 종류의 데이터를 그대로 두고 결과에 표시합니다. 클라우드의 플러그인 목록이 비어 있어도 내 플러그인이 지워지지 않습니다.

</GuideFact>
<GuideFact title="다운로드 직후 실행 취소">

**다운로드 및 병합** 또는 **덮어쓰기** 후에는 팝업이 열려 있는 동안 결과 줄에 **실행 취소**가 표시됩니다. 폴더 영역의 클라우드 알림에도 약 10초 동안 표시되며, 포인터를 올려 두는 동안에는 사라지지 않습니다. 실행 취소하면 그 다운로드가 바꾼 내용이 복원되고, 이후에 직접 바꾼 내용은 유지됩니다. 가장 최근 다운로드만 실행 취소할 수 있습니다.

</GuideFact>
<GuideFact title="Google Drive의 기록 사본">

업로드가 파일을 교체하기 전에, Voyager는 교체되는 버전을 같은 Drive 폴더에 `<파일>.backup-<UTC 시간>.json` 형식으로 남깁니다. 예: `gemini-voyager-folders.backup-2026-10-29-031100.json`. 파일마다 최근 3개를 남기고, 더 오래된 사본은 Drive 휴지통으로 옮깁니다. iCloud에는 기록 사본이 남지 않습니다.

</GuideFact>
<GuideFact title="모든 기기를 업데이트하세요">

**Enable Hard Isolation**을 켜면 현재 Voyager는 각 계정의 Drive 파일 이름을 계정 이메일로 정합니다. 아직 Voyager 2.2.1을 쓰는 기기가 처음에 번호가 붙은 주소(gemini.google.com/u/1)에서 그 계정을 사용했다면, 업데이트하기 전까지 새 버전이 업로드한 내용을 볼 수 없습니다. Chrome 웹 스토어 업데이트는 며칠 안에 도착하지만 Safari는 더 오래 걸립니다.

</GuideFact>
</GuideFacts>

## 클라우드 동기화와 수동 백업 비교

| 항목         | 수동 백업 (내보내기/가져오기) | 클라우드 동기화                                     |
| ------------ | ----------------------------- | --------------------------------------------------- |
| 빈도         | 생각날 때마다                 | 클릭 한 번으로 필요할 때 실행                       |
| 데이터 위치  | 컴퓨터의 로컬 파일            | 본인의 Google Drive 또는 비공개 iCloud 데이터베이스 |
| 기기 간 사용 | 파일을 옮겨야 함              | 선택한 클라우드 계정에 로그인한 기기에서 사용 가능  |
| 병합 방식    | 교체하거나 수동 병합이 필요함 | 중복 없이 지능적으로 병합                           |
| 프라이버시   | 파일이 내 컴퓨터에 남음       | 개인 클라우드 계정에 저장됨                         |

## 작동 원리

1. **제공자**: Google Drive는 제한된 `drive.file` 권한을 사용하므로 Voyager는 자신이 만든 파일에만 접근할 수 있습니다. Safari에서 iCloud는 앱의 비공개 CloudKit 데이터베이스를 사용하며, Apple ID 토큰을 Voyager에 노출하지 않습니다.
2. **업로드**: **업로드**를 클릭하면 Voyager는 폴더, 프롬프트, 별표, 포크, 타임라인 계층 구조, 개인화 설정, 플러그인 구성을 각각 별도의 백업 파일로 선택한 제공자에 저장합니다. 하이라이트 클라우드 동기화를 켜면 하이라이트 데이터도 포함됩니다.
3. **다운로드 및 병합**: 다른 기기에서 **다운로드 및 병합**을 클릭하면 Voyager는 이 파일들을 읽고 데이터 유형별로 병합합니다. 새 폴더와 프롬프트는 중복 없이 추가되고, 클라우드 환경설정은 복원되며, 플러그인 항목은 플러그인 ID 기준으로 병합됩니다.
4. **백그라운드 동기화 없음**: 동기화는 수동으로 필요할 때만 실행됩니다. Voyager는 사용자가 명시적으로 실행하지 않으면 동기화하지 않습니다.

제공자를 바꿔도 데이터가 제공자 사이에 복사되지 않으며, 두 제공자에 동시에 쓰지도 않습니다. 제공자를 바꾼 뒤 현재 로컬 데이터를 새로 선택한 제공자에 저장하려면 한 번 업로드하세요.

## 지원 플랫폼

Google Drive 동기화는 컴퓨터의 Chrome, Edge, Firefox, Safari에서 작동합니다. 휴대폰(Firefox for Android)에서는 Google 로그인 창을 열 수 없어 아직 사용할 수 없습니다. iCloud 동기화는 직접 배포되는 Safari 앱에서만 사용할 수 있으며, Mac에 로그인된 iCloud 계정을 사용합니다.
