# 완전한 자유

Voyager 내보내기를 사용하면 Gemini, ChatGPT, Claude, DeepSeek, Kimi의 모든 대화를 Markdown, PDF, JSON 또는 이미지 파일로 다운로드할 수 있습니다. 코드 블록, 이미지, 서식을 포함한 전체 채팅 내용을 추출하므로, 나눴던 모든 AI 대화의 영구적이고 휴대 가능한 사본을 가질 수 있습니다.

데이터에 갇히는 것은 적입니다.
우리는 당신이 만든 것이라면 당신이 소유해야 한다고 믿습니다.

## 형식 비교

| 항목        | Markdown                   | PDF                  | JSON                 | 이미지            |
| ----------- | -------------------------- | -------------------- | -------------------- | ----------------- |
| 적합한 용도 | 노트 앱 (Obsidian, Notion) | 공유와 인쇄          | 개발자, 데이터 분석  | 모바일에서 공유   |
| 이미지      | 포함됨                     | 완전히 포함됨        | Base64 인코딩        | 제자리에 렌더링   |
| 코드 블록   | 구문 강조와 함께 보존      | 시각적으로 렌더링    | 원시 텍스트 보존     | 시각적으로 렌더링 |
| 파일 크기   | 가장 작음                  | 가장 큼              | 중간                 | 큼                |
| 검색 가능   | 일반 텍스트                | PDF 리더의 검색 기능 | 프로그래밍 방식 접근 | 불가              |

## 모든 것을 내보내기

Voyager를 사용하면 데이터를 클라우드에서 꺼내어 당신의 손안으로 가져올 수 있습니다.

### 형식

- **Markdown**: Obsidian 저장소나 Notion을 위한 형식입니다. 이미지가 포함된 깨끗하고 서식 있는 텍스트입니다.
- **PDF**: 공유나 인쇄를 위한 형식입니다. 이미지가 포함된 아름다운 레이아웃을 제공합니다.
- **JSON**: 원시 데이터입니다. 자신의 기록을 바탕으로 무언가를 구축하려는 개발자를 위한 형식입니다.
- **이미지**: 하나로 길게 이어진 PNG입니다. 휴대폰에서 공유하기에 좋습니다. 좁은, 보통, 넓은 레이아웃 중에서 고를 수 있습니다.

### 내보내는 방법

1. **내보내기** 버튼을 클릭하세요(ChatGPT, Claude, DeepSeek, Kimi 및 현재 Gemini 레이아웃). 기본 위치는 페이지 오른쪽 위이며, 원하는 곳으로 끌어 옮길 수 있습니다. 사이트마다 위치를 기억하고, 기본 위치 근처에 놓으면 제자리로 돌아갑니다. Gemini에서는 대화나 답변의 ⋮ 메뉴에서 **대화 기록 내보내기**를 선택할 수도 있습니다. 이전 Gemini 레이아웃에서는 Gemini 로고 위에 마우스를 올리면 **내보내기 아이콘**이 나타납니다.
2. 형식을 선택하세요.
3. 끝입니다.

Claude, DeepSeek, Kimi에서는 내보내기가 기본적으로 꺼져 있는 플러그인입니다. 먼저 팝업의 **플러그인**에서 켜세요. 긴 대화는 Voyager가 스크롤하며 전체를 읽고, 다 읽으면 모든 메시지가 선택된 상태로 시작하니 필요 없는 것만 해제하세요. 처음과 끝을 모두 확인하지 못하면 내보내기가 불완전할 수 있다고 경고합니다. ChatGPT에서 전체 기록을 읽지 못하면 그렇다고 알리고, 위로 스크롤해 이전 메시지를 불러온 후 다시 시도하라고 안내합니다. 다른 채팅으로 이동하면 내보내기가 중단되며, Claude에서는 새 답변 생성이 시작되어도 중단됩니다.

ChatGPT 대화에 업로드한 파일은 내보내기에 `📎 파일 이름` 한 줄로 표시됩니다.

이것은 당신의 데이터입니다. 원하는 대로 사용하세요.

### Safari PDF 내보내기 참고 사항

Safari에서 PDF를 내보내는 과정은 조금 다릅니다(수동 인쇄 필요):

1. **내보내기(Export)** 버튼을 클릭하고 PDF 형식을 선택합니다.
2. **1초 정도 기다립니다** (페이지가 인쇄 스타일을 준비할 시간을 줍니다).
3. `Command + P`를 눌러 인쇄 대화상자를 엽니다.
4. 인쇄 대화상자에서 **"Save to PDF"**(또는 "PDF로 저장")를 선택합니다.

## Deep Research 내보내기

Gemini의 Deep Research 모드는 출처, 생각 단계, 인용이 담긴 구조화된 보고서를 만듭니다. Voyager는 이런 세션을 모든 메타데이터를 그대로 유지한 채 내보낼 수 있습니다.

1. 완료된 Deep Research 대화를 엽니다.
2. 보고서의 **공유 및 내보내기** 메뉴를 열고 **보고서 저장**을 선택합니다.
3. 형식을 선택합니다.
4. 내보내기 결과에는 출처 링크가 포함된 최종 보고서가 들어 있습니다. 생각 과정까지 저장하려면 [Deep Research 내보내기](/ko/guide/deep-research)를 참고하세요.

추론 과정과 출처 표기를 보존해야 하는 학술 연구, 경쟁 분석, 기술 문서 작업에 유용합니다.

## 내보내기를 쓰는 경우

- **지식 보관**: 중요한 대화가 채팅 기록 속에 묻히기 전에 저장해 두세요.
- **팀 공유**: Gemini를 쓰지 않는 동료에게 디버깅 세션을 PDF로 내보내 공유하세요.
- **지식 베이스 구축**: 대화를 Markdown으로 내보내 Obsidian이나 Notion에서 정리하세요.
- **데이터 분석**: JSON 내보내기를 활용해 대화 패턴을 프로그래밍 방식으로 분석하거나 구조화된 데이터를 추출하세요.
- **컴플라이언스와 감사**: 감사 추적을 위해 AI가 도움을 준 결정의 기록을 남겨 두세요.

## 지원 플랫폼

내보내기는 Chrome, Edge, Firefox, Safari, Opera, Brave에서 Gemini와 ChatGPT를 지원합니다. Claude, DeepSeek, Kimi 내보내기는 플러그인이며 기본적으로 꺼져 있습니다. **플러그인**에서 켤 수 있습니다. Safari에서 PDF 내보내기는 내보내기 버튼을 클릭한 뒤 수동으로 인쇄(Command+P)하는 단계를 사용하며, Markdown과 JSON 내보내기에는 여전히 이미지가 포함됩니다.
