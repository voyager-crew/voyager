# 개인정보 처리방침

최종 업데이트: 2026년 10월 26일

## 서론

Voyager는 지원되는 AI 채팅 작업 공간을 정리하고 기능을 향상하는 로컬 우선(local-first) 브라우저 확장 프로그램입니다. 사용자가 요청한 기능을 제공하는 데 필요한 범위에서만 제한적으로 데이터를 처리합니다. Voyager는 대화, 프롬프트, 브라우징 활동, 이미지, 계정 식별자를 받는 백엔드를 운영하지 않으며, 광고 또는 분석 추적기를 사용하지 않습니다.

## 처리되는 데이터

사용하는 기능에 따라 Voyager는 다음 데이터를 처리할 수 있습니다.

- **웹사이트 콘텐츠와 개인 커뮤니케이션**: 폴더, 탐색, 내보내기, 프롬프트 관리, 리서치, 인터페이스 기능에 사용되는 대화 텍스트, 프롬프트, 초안, 이미지, 링크 및 기타 지원 페이지의 콘텐츠.
- **계정 식별자**: 지원되는 Google 서비스는 로그인한 이메일 주소를 노출할 수 있습니다. Voyager는 이를 로컬 계정 식별자로 변환하여 계정별 데이터를 분리합니다. Voyager는 원본 이메일 주소를 당사로 보내지 않습니다.
- **웹 기록과 사용자 활동**: 지원 사이트의 URL, 대화 경로, 그리고 탐색, 단축키, 사용량 표시, 응답 완료 알림 및 기타 요청된 기능에 필요한 제한적인 페이지, 상호작용, 네트워크 이벤트. 이 데이터는 프로파일링이나 광고에 사용되지 않습니다.
- **인증 정보**: 사용자가 Google Drive 동기화를 명시적으로 켠 경우에만 사용되는 `drive.file` 범위의 OAuth2 토큰.
- **확장 프로그램 데이터와 설정**: 폴더, 프롬프트 템플릿, 초안, 별표 메시지, 사용량 스냅샷, 플러그인 상태, 인터페이스 환경설정.

이 데이터는 `chrome.storage.local`에 로컬로 저장되며, 지원되는 설정은 `chrome.storage.sync`에 저장됩니다. 일부 기능은 지원 사이트가 사용자 기기에 두는 자체 `localStorage`도 사용해 폴더 데이터의 백업 사본과 타임라인 캐시를 저장합니다. 잠깐 쓰이는 전달 기록은 세션 저장소에 둡니다. Research Pack 전달은 브라우저 메모리에 있는 확장 프로그램의 `storage.session`을 사용하고, ChatGPT 임시 채팅 전달은 페이지의 `sessionStorage`에 탭 토큰만 저장하며 대화 내용은 최대 60초 동안 `chrome.storage.local`에 보관됩니다. 사용자가 아래에 설명된 전송을 직접 실행하지 않는 한 사용자의 기기 또는 브라우저 동기화 계정에 남아 있습니다.

## 사용자가 요청한 전송

- **Google 드라이브 동기화 (선택 사항)**: Google 드라이브 동기화를 명시적으로 활성화하면 Chrome, Edge 및 Firefox는 브라우저 Identity API를 사용하고 Safari 직접 설치 앱은 네이티브 Google Sign-In을 사용하며 자격 증명을 macOS 키체인에 저장합니다. 두 경로 모두 제한된 `drive.file` 범위만 요청하고 사용자 기기와 **사용자 자신의 Google 드라이브** 사이에서 직접 데이터를 전송합니다. OAuth 토큰은 Voyager 서버로 전송되지 않습니다. Chromium 브라우저에서 브라우저가 토큰을 직접 발급하지 못하는 경우(예: Brave, 또는 해당 로그인 방식이 실패한 경우) Google은 로그인 결과를 `https://voyager.nagi.fun/oauth/callback/`의 정적 중계 페이지로 돌려보내고, 이 페이지의 스크립트가 브라우저 안에서 확장 프로그램에 전달합니다. 토큰은 URL fragment에 담기며 브라우저는 이를 서버로 보내지 않습니다. 다른 웹 페이지와 마찬가지로 정적 호스트는 요청한 IP 주소와 브라우저 User-Agent를 볼 수 있습니다. Firefox는 브라우저가 요청이 나가기 전에 가로채는 루프백 리디렉션(`http://127.0.0.1/mozoauth2/…`)을 사용하고, PKCE로 Google과 직접 인증 코드를 교환합니다.
- **Safari의 iCloud 동기화 (선택 사항)**: 선택한 백업 데이터가 네이티브 Safari 확장 프로그램에 의해 사용자의 iCloud 계정 내 비공개 CloudKit 데이터베이스로 직접 전송됩니다. Voyager는 사용자의 Apple ID나 iCloud 인증 토큰을 받지 않으며, 개발자도 그 비공개 데이터베이스의 레코드에 접근할 수 없습니다.
- **내보내기와 이미지**: 사용자가 내보내기를 요청하면 Voyager는 사용자의 기존 페이지 호스팅 소스에서 이미지를 가져올 수 있고, 생성된 인터페이스 콘텐츠를 캡처하는 데 필요한 임시 접근을 요청할 수 있습니다. 결과 파일은 사용자를 위해 만들어지며 Voyager 서버에 업로드되지 않습니다.
- **Context Sync (선택 사항)**: 사용자가 동기화를 누르면 Voyager는 캡처한 대화 컨텍스트를 사용자 컴퓨터의 로컬 서버 `http://127.0.0.1:<포트>/sync`(기본 포트 3030, 변경 가능)로 보냅니다. 기능이 켜져 있고 팝업이 열려 있는 동안에는 로컬 서버에 연결할 수 있는지 표시하기 위해 이 주소도 확인합니다. 이 데이터는 Voyager를 통해 기기 밖으로 나가지 않습니다.
- **Research Pack "ChatGPT / Claude에서 계속"**: 사용자가 대상을 고르면 Voyager는 선택한 사이트(ChatGPT 또는 Claude)에서 새 채팅을 엽니다. 그 사이트에서 Voyager가 실행 중이면 팩은 브라우저 메모리의 `storage.session`을 통해 전달되고, 해당 탭이 한 번만 가져가 전송하지 않은 채 입력창에 넣습니다. 이 기록은 60초 후 만료됩니다. 그렇지 않으면 팩이 클립보드에 복사되어 사용자가 직접 붙여 넣습니다. 팩은 URL에 담겨 전달되지 않습니다.
- **ChatGPT 임시 채팅 전달**: 사용자가 ChatGPT 임시 채팅을 이어 가기로 하면 Voyager는 Markdown 백업을 사용자 기기에 다운로드하고, 임시 모드를 끈 다음, 대화를 일반 ChatGPT 채팅의 입력창에 전송하지 않은 채 넣습니다. 대화 내용은 ChatGPT와 사용자 기기에만 남습니다.
- **공개 프로젝트 리소스**: Voyager는 공개 릴리스, 공지 또는 문서 리소스를 요청할 수 있습니다. 이 요청에는 대화나 프롬프트 콘텐츠가 포함되지 않습니다.
- **온라인 카탈로그 업데이트**: “온라인 업데이트”는 기본으로 켜져 있습니다. gemini.google.com 또는 플러그인을 하나 이상 켠 다른 지원 사이트에서 페이지를 열면 Voyager가 HTTPS로 `https://voyager.nagi.fun/catalog/hosts/<사이트 호스트 이름>.json`을 가져올 수 있습니다. 팝업을 열면 로컬 캐시만 읽으며, 버튼으로 수동 확인을 요청할 수 있습니다. 자동 확인은 마지막 시도부터 선택한 간격(기본 6시간, 1시간·6시간·24시간·수동 전용 중 선택)을 따르며, 실패하면 재시도를 늦춥니다. 켜져 있을 때는 수동 확인으로 간격을 건너뛸 수 있습니다. 끄면 자동 및 수동 카탈로그 요청이 모두 중지됩니다. 스위치와 간격은 브라우저 동기화 및 설정 백업에 포함되고, 다운로드한 카탈로그는 기기에 저장됩니다. 같은 경로로 대화, 사이드바, 입력, 메뉴, 내보내기, 이미지 기능 등에 쓰이는 Gemini 페이지 인식 수정도 제공할 수 있습니다. Gemini 공식 플러그인, CSS, 계정과 콘텐츠 식별 규칙, 클릭 동작은 확장 프로그램에 포함된 것을 사용합니다. Gemini Enterprise와 AI Studio는 포함된 데이터만 사용합니다. Gemini의 새 수정, 수정 철회, 업데이트 끄기는 직접 페이지를 새로고침한 후 반영됩니다. 열린 페이지는 현재 데이터를 유지하며 자동으로 새로고침하지 않습니다. 유효한 수정이 없으면 포함된 데이터를 사용합니다. 카탈로그 요청은 일반 GET이며 쿠키, 계정이나 확장 프로그램 식별자, 페이지나 대화 내용을 보내지 않습니다. 서버는 IP 주소, User-Agent, URL의 사이트 호스트 이름 등 일반 연결 정보를 볼 수 있습니다. CSS와 JSON은 사용 전에 검증하며 원격 JavaScript나 WebAssembly는 실행하지 않습니다. 공지와 선택 사항인 클라우드 동기화는 각각 별도 설정을 따릅니다. voyager.nagi.fun은 Cloudflare 프록시 뒤의 정적 호스팅입니다. Voyager 프로젝트는 이 요청을 기록하거나 보관하지 않으며 호스팅 제공자가 자체 개인정보 처리방침에 따라 연결 정보를 처리합니다.

Voyager는 사용자 데이터를 판매하지 않으며, 광고, 신용 평가 또는 확장 프로그램의 사용자 기능과 무관한 목적으로 데이터를 전송하지 않습니다.

## 권한

- **Storage (저장소)**: 확장 프로그램 데이터와 환경설정을 로컬에 저장하고, 지원되는 경우 브라우저 동기화를 통해 저장합니다. Chrome, Edge, Firefox는 기본 브라우저 할당량 때문에 로컬 데이터가 잘리지 않도록 `unlimitedStorage`도 부여받으며, Voyager는 자체 저장 한도를 계속 적용합니다. Safari에서는 선택 사항입니다.
- **Identity (인증)**: 사용자가 명시적으로 실행한 후 선택적 Google Drive 동기화를 인증하는 데 사용됩니다. Safari 버전은 이 권한을 요청하지 않으며, Safari의 Google Drive 및 iCloud 동기화는 Voyager macOS 앱을 통해 이루어집니다.
- **Scripting (스크립트 주입)**: 지원되는 사이트에 확장 프로그램에 포함된 스크립트만 주입합니다. 원격 JavaScript나 WebAssembly는 실행하지 않습니다.
- **Active tab 및 declarative content**: 사용자가 연 지원 사이트를 식별하고 해당 사이트에 맞는 제어 기능을 표시합니다. Declarative content는 Chrome과 Edge에서만 사용됩니다.
- **Alarms**: 공개 공지를 주기적으로 확인하고, 만료된 전달 기록 정리와 지연 작업 실행을 위한 백그라운드 타이머를 실행합니다.
- **Notifications (선택 사항)**: 사용자가 응답 완료 알림 또는 원격 공지의 시스템 알림을 켤 때만 요청됩니다. Safari 버전은 이 권한을 요청하지 않으며, 응답 완료 알림은 Voyager macOS 앱이 표시합니다.
- **Native messaging (Safari 전용)**: Google Drive 및 iCloud 동기화와 응답 완료 알림을 위해 Safari 확장 프로그램을 Voyager macOS 앱에 연결합니다.
- **Host permissions (호스트 권한)**: 설치 시 Gemini, Gemini Enterprise, AI Studio에 대해 부여되며, 사용자가 요청한 Google Drive 및 이미지 작업에 필요한 Google 도메인도 포함됩니다.
- **Optional host permissions (선택적 호스트 권한)**: Claude, ChatGPT, DeepSeek 및 사용자 지정 사이트는 사용자가 해당 사이트에 대해 Voyager 또는 플러그인을 켜고 브라우저의 권한 요청을 승인한 후에만 접근합니다. 생성된 인터페이스 콘텐츠를 캡처하는 내보내기를 선택하면 `<all_urls>`를 잠시 요청할 수 있습니다. 거부하더라도 내보내기는 해당 캡처 없이 계속됩니다.

## 보관과 사용자 제어

로컬 및 브라우저 동기화 데이터는 사용자가 삭제하거나, 확장 프로그램 저장소를 지우거나, 확장 프로그램을 제거할 때까지 남아 있습니다. Voyager가 지원 사이트 자체의 `localStorage`에 저장한 사본(폴더 백업과 타임라인 캐시)은 확장 프로그램을 제거해도 삭제되지 않으므로, 브라우저에서 해당 사이트의 데이터를 지워야 합니다. 클라우드 백업은 사용자가 선택한 Google Drive 또는 iCloud 계정에서 직접 삭제할 때까지 그 계정에 남아 있습니다. 사용자는 Voyager와 브라우저 설정에서 선택 기능을 끄거나, 선택적 사이트 접근 또는 Google 인증을 취소할 수 있습니다.

## Google API 제한적 사용

Voyager가 Google API에서 받은 정보를 사용하고 전송하는 방식은 Limited Use 요구 사항을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 준수합니다.

## 방침 변경

Voyager가 변경됨에 따라 이 개인정보 처리방침을 업데이트할 수 있습니다. 최신 버전과 업데이트 날짜는 이 페이지에 게시됩니다.
