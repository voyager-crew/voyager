# Политика конфиденциальности

Последнее обновление: 26 октября 2026 г.

## Обзор

Voyager — это локальное браузерное расширение для организации и улучшения поддерживаемых рабочих пространств AI-чатов. Оно обрабатывает ограниченный объём пользовательских данных, только чтобы предоставлять функции, которые запрашивает пользователь. Voyager не управляет бэкендом, который получает переписки, промпты, данные о посещённых страницах, изображения или идентификаторы аккаунтов, и не использует рекламные или аналитические трекеры.

## Обрабатываемые данные

В зависимости от того, какими функциями вы пользуетесь, Voyager может обрабатывать:

- **Содержимое сайтов и личная переписка**: текст диалогов, промпты, черновики, изображения, ссылки и другое содержимое поддерживаемых страниц, которое используется для папок, навигации, экспорта, управления промптами, исследований и функций интерфейса.
- **Идентификаторы аккаунта**: поддерживаемая служба Google может раскрывать email адрес вошедшего пользователя. Voyager преобразует его в локальный идентификатор аккаунта, чтобы данные разных аккаунтов оставались разделёнными. Voyager не отправляет нам исходный email адрес.
- **История веб-активности и действия пользователя**: URL поддерживаемых сайтов, маршруты диалогов и ограниченные события страницы, взаимодействий и сети, которые нужны для навигации, горячих клавиш, индикаторов использования, уведомлений о завершении ответа и других запрошенных функций. Эти данные не используются для профилирования или рекламы.
- **Данные аутентификации**: токен OAuth2 с областью `drive.file`, только если пользователь явно включает синхронизацию с Google Диском.
- **Данные и настройки расширения**: папки, шаблоны промптов, черновики, избранные сообщения, снимки использования, состояние плагинов и настройки интерфейса.

Эти данные хранятся локально в `chrome.storage.local` или, для поддерживаемых настроек, в `chrome.storage.sync`. Некоторые функции также используют собственное `localStorage` поддерживаемого сайта на устройстве пользователя — для резервных копий данных папок и для кэша временной шкалы. Кратковременные записи для передачи хранятся в сессионном хранилище: для передачи Research Pack — в `storage.session` расширения в памяти браузера, а для передачи временного чата ChatGPT в `sessionStorage` страницы хранится только токен вкладки, пока сама переписка не более 60 секунд ждёт в `chrome.storage.local`. Они остаются на устройстве пользователя или в синхронизированном аккаунте браузера, если только пользователь явно не выполняет передачу, описанную ниже.

## Передачи, которые запрашивает пользователь

- **Синхронизация с Google Диском (необязательно)**: выбранные данные резервной копии передаются напрямую между устройством пользователя и его собственным Google Диском. Chrome, Edge и Firefox используют API идентификации браузера; прямое приложение Safari использует нативный Google Sign-In и хранит учётные данные в Связке ключей macOS. Оба варианта запрашивают только ограниченную область `drive.file`, а токены OAuth не отправляются на серверы Voyager. В браузерах на Chromium, если браузер не может выдать токен напрямую (например, в Brave или если такой вход не удался), Google возвращает результат входа на статическую страницу-ретранслятор `https://voyager.nagi.fun/oauth/callback/`, скрипт которой передаёт его расширению внутри браузера. Токен находится во фрагменте URL, который браузеры не отправляют на сервер; как и при открытии любой веб-страницы, статический хостинг видит IP-адрес и user agent браузера. Firefox же использует loopback-перенаправление (`http://127.0.0.1/mozoauth2/…`), которое браузер перехватывает до отправки какого-либо запроса, и обменивает код авторизации напрямую с Google с помощью PKCE.
- **Синхронизация через iCloud в Safari (необязательно)**: выбранные данные резервной копии передаются нативным расширением Safari напрямую в закрытую базу данных CloudKit в iCloud пользователя. Voyager не получает Apple ID пользователя и токен аутентификации iCloud, а разработчик не может получить доступ к записям в этой закрытой базе.
- **Экспорт и изображения**: когда пользователь запрашивает экспорт, Voyager может загружать изображения из существующих источников страницы и запрашивать временный доступ, необходимый для захвата сгенерированного содержимого интерфейса. Итоговый файл создаётся для пользователя и не загружается на сервер Voyager.
- **Context Sync (необязательно)**: когда пользователь нажимает синхронизацию, Voyager отправляет захваченный контекст переписки на локальный сервер на собственном компьютере пользователя по адресу `http://127.0.0.1:<порт>/sync` (по умолчанию порт 3030, его можно изменить). Пока функция включена и всплывающее окно открыто, Voyager также опрашивает этот адрес, чтобы показать, доступен ли локальный сервер. Через Voyager эти данные не покидают устройство.
- **Research Pack «Продолжить в ChatGPT / Claude»**: когда пользователь выбирает цель, Voyager открывает новый чат на выбранном сайте (ChatGPT или Claude). Если Voyager там работает, пакет передаётся через `storage.session` в памяти браузера, эта вкладка забирает его один раз и вставляет в поле ввода без отправки; запись истекает через 60 секунд. В противном случае пакет копируется в буфер обмена, и пользователь вставляет его сам. Пакет никогда не передаётся в URL.
- **Передача временного чата ChatGPT**: когда пользователь решает продолжить временный чат ChatGPT, Voyager скачивает резервную копию в Markdown на устройство пользователя, выходит из временного режима и вставляет переписку в поле ввода обычного чата ChatGPT без отправки. Переписка остаётся в ChatGPT и на устройстве пользователя.
- **Публичные ресурсы проекта**: Voyager может запрашивать публичные релизы, объявления или ресурсы документации. Такие запросы не включают содержимое переписок или промптов.
- **Обновления онлайн-каталога**: «Онлайн-обновления» включены по умолчанию. На поддерживаемых страницах Gemini (включая Enterprise), AI Studio, ChatGPT, Claude, DeepSeek и Kimi Voyager может загружать `https://voyager.nagi.fun/catalog/hosts/<хост сайта>.json` по HTTPS при открытии страницы. Открытие окна расширения только читает локальный кеш; кнопка запускает ручную проверку. Автоматические проверки выполняются с выбранным интервалом от последней попытки (по умолчанию 6 часов; 1 час, 6 часов, 24 часа или только вручную); после ошибок ожидание увеличивается. Ручные проверки не зависят от интервала и доступны даже при выключенных онлайн-обновлениях. Выключение останавливает автоматические запросы к каталогу. Плагины и существующие настройки сайта из кеша, включая правила распознавания страниц, остаются доступны. После перезагрузки с выключенными обновлениями эти правила работают по-прежнему; для дополнительных данных распознавания страниц используется встроенная версия. Переключатель и интервал синхронизируются браузером и входят в резервную копию настроек; загруженные каталоги остаются на устройстве. Единый канал передаёт собственные данные распознавания страниц каждого сайта. Онлайн-исправления обновляют распознавание страниц для поддерживаемых функций, включая диалоги, ввод, навигацию, меню, экспорт, изображения и расположение элементов управления Voyager. Официальные плагины и CSS для Gemini и AI Studio, а также правила идентификации, удаления, нажатий и ввода для всех сайтов остаются в составе расширения. Исправления, их отзыв и выключение обновлений применяются после ручной перезагрузки страницы; автоматической перезагрузки нет. При включённых онлайн-обновлениях исправления, влияющие на действия сайта, данные или выбор диалога, требуют независимой проверки по странице; если она не пройдена, вся операция использует встроенные данные. Исправления, которые лишь размещают элементы управления Voyager, используют доверенный официальный каталог; если цель не найдена или место вставки находится в редактируемой области, применяется встроенное расположение. GET-запросы не передают cookie, идентификаторы аккаунта или расширения, содержимое страниц или переписки. Сервер видит IP-адрес, User-Agent и хост сайта в URL. CSS и JSON проверяются до использования; удалённые JavaScript и WebAssembly не выполняются. Объявления и необязательная облачная синхронизация имеют отдельные настройки. voyager.nagi.fun использует статический хостинг за прокси Cloudflare; проект Voyager не записывает и не хранит эти запросы. Провайдеры хостинга обрабатывают метаданные соединения по своим политикам конфиденциальности.

Voyager не продаёт пользовательские данные и не передаёт их для рекламы, оценки кредитоспособности или целей, не связанных с функциями расширения для пользователя.

## Разрешения

- **Storage (хранилище)**: сохраняет данные расширения и настройки локально и, где это поддерживается, через синхронизацию браузера. Chrome, Edge и Firefox также предоставляют `unlimitedStorage`, чтобы локальные данные не обрезались стандартной квотой браузера; собственное ограничение хранилища Voyager при этом сохраняется. В Safari это разрешение необязательное.
- **Identity (идентификация)**: аутентифицирует необязательную синхронизацию с Google Диском после явного действия пользователя. Версия для Safari его не запрашивает: там синхронизация с Google Диском и iCloud идёт через приложение Voyager для macOS.
- **Scripting (скрипты)**: внедряет только скрипты, входящие в состав расширения, на поддерживаемых сайтах; удалённый JavaScript и WebAssembly не выполняются.
- **Active tab и declarative content (активная вкладка и декларативный контент)**: определяет поддерживаемый сайт, который открыл пользователь, и показывает подходящие элементы управления для этого сайта. Declarative content используется только в Chrome и Edge.
- **Alarms (будильники)**: планирует периодические проверки публичных объявлений, а также фоновые таймеры, которые удаляют истёкшие записи передачи и выполняют отложенные задачи.
- **Notifications (уведомления, необязательно)**: запрашивается только тогда, когда пользователь включает уведомления о завершении ответа или системные оповещения для удалённых объявлений. Версия для Safari его не запрашивает; уведомления о завершении ответа там показывает приложение Voyager для macOS.
- **Native messaging (нативный обмен сообщениями, только Safari)**: связывает расширение Safari с приложением Voyager для macOS для синхронизации с Google Диском и iCloud и для уведомлений о завершении ответа.
- **Host permissions (разрешения хоста)**: предоставляются при установке для Gemini, Gemini Enterprise и AI Studio, а также для доменов Google, нужных для операций с Google Диском и изображениями по запросу пользователя.
- **Optional host permissions (необязательные разрешения хоста)**: доступ к Claude, ChatGPT, DeepSeek и пользовательским сайтам предоставляется только после того, как пользователь включает Voyager или плагин для этого сайта и подтверждает запрос браузера. `<all_urls>` также может запрашиваться временно, когда пользователь выбирает экспорт, захватывающий сгенерированное содержимое интерфейса; если доступ отклонён, экспорт продолжается без этого захвата.

## Хранение и контроль пользователя

Локальные данные и данные синхронизации браузера хранятся до тех пор, пока пользователь их не удалит, не очистит хранилище расширения или не удалит расширение. Копии, которые Voyager хранит в `localStorage` самого поддерживаемого сайта (резервные копии папок и кэш таймлайна), при удалении расширения не стираются; чтобы убрать их, очистите данные этого сайта в браузере. Облачные резервные копии остаются в выбранном пользователем аккаунте Google Диска или iCloud, пока пользователь не удалит их из этого аккаунта. Пользователи могут отключить необязательные функции и отозвать доступ к необязательным сайтам или авторизацию Google через настройки Voyager и браузера.

## Ограниченное использование данных Google API

Использование и передача информации, полученной через API Google, в Voyager соответствуют Политике пользовательских данных Chrome Web Store, включая требования об ограниченном использовании.
