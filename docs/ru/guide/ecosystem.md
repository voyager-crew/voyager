# Экосистема

Следующие проекты вдохновлены Voyager или построены на его основе, предлагая аналогичные улучшения для других платформ.

- **[DeepSeek Voyager](https://github.com/Azurboy/deepseek-voyager)** — Форк Voyager, адаптированный для DeepSeek.
- **[claude-nexus](https://github.com/Qiuner/claude-nexus)** — Расширение для улучшения Claude.ai, вдохновлённое Voyager: навигация по таймлайну, управление папками, библиотека промптов и многое другое, с полной совместимостью импорта/экспорта промптов с Voyager!
- **[Better_Doubao](https://github.com/Rex16200513/Better_Doubao)** — Продвинутое расширение браузера, улучшающее Doubao с помощью расширенной навигации, организации и функций продуктивности.
- **[DeepSeek Enhancer](https://github.com/dlshuangchenyue1210/DeepSeek-Enhancer)** — Вдохновлённое Voyager расширение для веб-версии DeepSeek: многоуровневые папки, экспорт истории чатов, копирование формул, резервное копирование данных и другое.
- **[Voyager Lite](https://github.com/Carleo10032/voyager-lite)** — Неофициальная облегчённая версия на основе Voyager: навигация по таймлайну и фоновые эффекты для ChatGPT, Claude, Gemini и Grok.
