# Облачная синхронизация

Voyager Cloud Sync создаёт резервную копию ваших папок, библиотеки промптов, избранных сообщений и поддерживаемых настроек. В любом поддерживаемом браузере можно выбрать Google Диск, а в Safari — iCloud. Данные передаются напрямую между Voyager и выбранным личным облачным аккаунтом; Voyager не управляет сервером синхронизации.

## Что синхронизируется

| Тип данных                | Синхронизируется | Подробности                                                                                                  |
| ------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------ |
| Структура папок           | Да               | Папки Gemini, AI Studio, ChatGPT, Claude, DeepSeek и Kimi: вложенность, цвета и назначения разговоров        |
| Библиотека промптов       | Да               | Все сохранённые промпты с тегами и организацией по папкам                                                    |
| Избранные сообщения       | Да               | Закладки таймлайна из любых разговоров                                                                       |
| Таймлайн на других сайтах | Да               | Избранное и уровни таймлайна в ChatGPT, Claude и DeepSeek                                                    |
| Настройки расширения      | Да               | Общие для устройств настройки, например сортировка, цвета и поведение ввода                                  |
| Конфигурация плагинов     | Да               | Состояние установки и включения, а также настройки плагинов; разрешения сайтов остаются на каждом устройстве |
| Ответы модели             | Нет              | Резервные копии избранного содержат промпты пользователя, а не ответы модели                                 |

**Enable Hard Isolation** больше не попадает в облачный файл настроек. Собственная синхронизация браузера (например, синхронизация Chrome) по-прежнему переносит этот параметр между компьютерами с одним профилем браузера.

## Данные избранного и ограничения синхронизации

В облако загружается **полный текст пользовательских промптов, отмеченных звездой** (до 16 KiB UTF-8 на промпт), в ваш собственный Google Диск или iCloud. Резервные копии избранного не хранят ответы модели. Копия v1 содержит только превью; новая v2 включает текст промптов и записи об удалении.

Записи об удалении хранятся 180 дней. Старые версии Voyager игнорируют их и могут снова показывать или загружать удалённое избранное; новые блокируют старые копии с неизменной отметкой времени. Новое добавление с более поздней отметкой или истечение срока записи может восстановить звезду. Долгая работа без сети и различия часов устройств также влияют на распространение удалений.

Синхронизация объединяет данные и проверяет записи, делая не более трёх попыток, но не является атомарной транзакцией между устройствами: одновременные загрузки могут перезаписать чужие изменения. Позднейшая синхронизация устройства, сохранившего недостающие данные, может восстановить их; без неё восстановление не гарантируется. При частичном сбое принятые записи сохраняются; повторите синхронизацию для завершения восстановления.

## Возможности

- **Синхронизация между устройствами**: Синхронизируйте свои конфигурации на нескольких компьютерах.
- **Конфиденциальность данных**: Данные хранятся непосредственно в вашем Google Диске или закрытой базе iCloud, что обеспечивает конфиденциальность без сервера Voyager.
- **Гибкая синхронизация**: Поддержка ручной загрузки и скачивания/объединения данных.

::: info
Идентификаторы устройств, токены доступа, кэши, координаты области просмотра и временное состояние выполнения намеренно не синхронизируются как персональные настройки.
:::

## Как использовать

1. Откройте вкладку Gemini, AI Studio, ChatGPT, Claude, DeepSeek или Kimi и нажмите значок Voyager на панели инструментов браузера, чтобы открыть всплывающее окно. Раздел **Облачная синхронизация** появляется только на этих сайтах, а папки каждого сайта синхронизируются отдельно.
2. Найдите раздел **Облачная синхронизация**.
3. В Safari выберите **Google Диск** или **iCloud**. Остальные браузеры используют Google Диск.
4. Переключите **Режим синхронизации** на **Вручную**. По умолчанию стоит **Отключено**, а кнопки синхронизации появляются только в ручном режиме.
5. Для Google Диска в Safari нажмите **Подключить Google Диск**, чтобы войти через приложение Voyager. В остальных браузерах отдельной кнопки входа нет: окно авторизации Google откроется при первом нажатии **Загрузить** или **Синхронизация**. Для iCloud убедитесь, что на Mac выполнен вход в iCloud.
6. Нажмите **Загрузить**, чтобы синхронизировать локальные данные с облаком, или **Синхронизация**, чтобы перенести облачные данные в этот браузер. **Перезаписать** сначала спрашивает подтверждение, а затем заменяет только те данные, которые есть в облаке и которые Voyager может прочитать; всё, чего в облаке нет или что не удаётся прочитать, остаётся как есть, и результат это перечисляет. Сразу после этого можно отменить.

При использовании iCloud **Удалить резервную копию iCloud** удаляет все резервные копии Voyager из iCloud; локальные данные на Mac остаются без изменений.

### 💡 Быстрая синхронизация

Самый простой способ — нажать значок облака в заголовке области папок в левой боковой панели и выбрать в меню **«Загрузить в облако»** или **«Синхронизировать из облака»**.

Хотя облачная синхронизация обеспечивает большое удобство, мы настоятельно рекомендуем вам также периодически создавать резервные копии основных данных с помощью **локальных файлов**.

1. **Папки**: откройте меню области папок, выберите **Импорт/Экспорт папок**, затем **Экспорт папок**, чтобы сохранить все папки и назначения разговоров.
2. **Промпты**: в Менеджере промптов нажмите **Экспорт**, чтобы сохранить библиотеку промптов.

## Защита синхронизации

<GuideFacts>
<GuideFact title="Подтверждение загрузки">

Если загрузка сильно уменьшит облачный файл (на этом устройстве совсем нет данных, которые есть в облаке, или меньше половины, когда в облаке их не меньше 4) или Voyager не может прочитать облачный файл, он сначала спрашивает: **Объединить из облака**, **Всё равно загрузить** или **Отмена**. Объединение предлагается, только если облачный файл читается.

</GuideFact>
<GuideFact title="Перезапись заменяет только то, что есть">

**Перезаписать** сохраняет все типы данных, которых нет в облаке или которые Voyager не может прочитать, и перечисляет их в результате. Пустой список плагинов в облаке никогда не удаляет ваши плагины.

</GuideFact>
<GuideFact title="Отмена сразу после скачивания">

После **Синхронизация** или **Перезаписать** строка результата во всплывающем окне предлагает **Отменить**, пока окно открыто. Облачное уведомление в области папок предлагает это примерно 10 секунд и ждёт, пока на нём указатель. Отмена возвращает то, что изменило это скачивание, и сохраняет то, что вы изменили позже. Отменить можно только последнее скачивание.

</GuideFact>
<GuideFact title="Копии истории в Google Drive">

Прежде чем загрузка заменит файл, Voyager сохраняет заменяемую версию рядом с ним в своей папке на Drive как `<файл>.backup-<время UTC>.json`, например `gemini-voyager-folders.backup-2026-10-29-031100.json`. Для каждого файла хранятся 3 последние копии, более старые переносятся в корзину Drive. iCloud копии истории не хранит.

</GuideFact>
<GuideFact title="Обновите все устройства">

Когда включено **Enable Hard Isolation**, текущий Voyager называет файлы Drive каждого аккаунта по его электронной почте. Устройство, которое всё ещё на Voyager 2.2.1 и впервые увидело аккаунт по адресу с номером (gemini.google.com/u/1), не увидит то, что загружают новые версии, пока не обновится. Обновления из Chrome Web Store приходят за несколько дней; в Safari это занимает больше времени.

</GuideFact>
</GuideFacts>

## Облачная синхронизация и ручное резервное копирование

| Аспект             | Ручное резервное копирование (экспорт/импорт) | Облачная синхронизация                            |
| ------------------ | --------------------------------------------- | ------------------------------------------------- |
| Частота            | Когда вспомните                               | По запросу, одним нажатием                        |
| Расположение       | Локальный файл на компьютере                  | Ваш Google Диск или закрытая база iCloud          |
| Между устройствами | Нужно переносить файлы                        | Устройства, вошедшие в выбранный облачный аккаунт |
| Объединение        | Заменяет данные или требует ручного слияния   | Умное объединение без дублирования                |
| Конфиденциальность | Файл остаётся на вашем компьютере             | Хранится в личном облачном аккаунте               |

## Как это работает

1. **Провайдер**: Google Диск использует ограниченное разрешение `drive.file`, поэтому Voyager может получать доступ только к файлам, которые создал сам. В Safari iCloud использует закрытую базу CloudKit приложения и не передаёт Voyager токен Apple ID.
2. **Загрузка**: когда вы нажимаете **Загрузить**, Voyager записывает у выбранного провайдера отдельные файлы резервных копий для папок, промптов, избранного, форков, иерархии таймлайна, персональных настроек и конфигурации плагинов. Данные выделений включаются, если синхронизация выделений включена.
3. **Синхронизация и объединение**: когда вы нажимаете **Синхронизация** на другом устройстве, Voyager читает эти файлы и объединяет их по типам данных. Новые папки и промпты добавляются без дублирования, облачные настройки восстанавливаются, а записи плагинов объединяются по ID плагина.
4. **Без фоновой синхронизации**: синхронизация выполняется вручную, по запросу. Voyager никогда не синхронизирует данные без вашего явного действия.

Переключение провайдера не копирует данные между ними и не записывает их одновременно в оба. Если после переключения нужно перенести текущие локальные данные в новый выбранный провайдер, выполните загрузку один раз.

## Поддерживаемые платформы

Синхронизация с Google Диском работает в Chrome, Edge, Firefox и Safari на компьютере. На телефоне (Firefox для Android) она недоступна: там не открывается окно входа в Google. Синхронизация через iCloud доступна только в приложении Safari, распространяемом напрямую, и использует аккаунт iCloud, выполненный на Mac.
