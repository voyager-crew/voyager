# クラウド同期

フォルダ、プロンプトライブラリ、スター付きメッセージ、対応している設定を Google ドライブ（Safari では iCloud も選択可）に同期して、デバイス間で一貫した体験を維持します。データは Voyager と、ご自身が選んだクラウドアカウントの間で直接やり取りされます。Voyager は同期サーバーを運営していません。

## 同期されるデータ

| データの種類           | 同期   | 詳細                                                                                          |
| ---------------------- | ------ | --------------------------------------------------------------------------------------------- |
| フォルダ構造           | はい   | Gemini、AI Studio、ChatGPT、Claude、DeepSeek、Kimi のフォルダ、入れ子構造、色、会話の割り当て |
| プロンプトライブラリ   | はい   | タグとフォルダ構成を含む保存済みのすべてのプロンプト                                          |
| スター付きメッセージ   | はい   | どの会話からでも付けられるタイムラインのブックマーク                                          |
| 他サイトのタイムライン | はい   | ChatGPT、Claude、DeepSeek のタイムラインのスターと階層                                        |
| 拡張機能の設定         | はい   | 並べ替え、色、入力動作など、デバイス間で共有する環境設定                                      |
| プラグインの設定       | はい   | インストールと有効化の状態、プラグインの設定。サイトごとの権限はデバイスごとに保持されます    |
| モデルの回答           | いいえ | スターのバックアップにはユーザーのプロンプトが含まれ、モデルの回答は含まれません              |

**Enable Hard Isolation** は、クラウドの設定ファイルには含まれなくなりました。ブラウザ自体の同期（Chrome の同期など）は、同じブラウザプロファイルでログインしているパソコン間で引き続きこの設定を同期します。

## スターのデータと同期の制限

クラウドへのアップロードには、**スターを付けたユーザープロンプトの全文**（1 件あたり UTF-8 で最大 16 KiB）が含まれ、ご自身の Google ドライブまたは iCloud に保存されます。スターのバックアップにモデルの回答は保存されません。従来の v1 バックアップはプレビューのみ、新しい v2 バックアップはプロンプト本文と削除記録を含みます。

削除記録は 180 日間保持されます。古い Voyager は記録を認識せず、削除済みのスターを再表示・再アップロードする場合があります。新しいバージョンはタイムスタンプが変わっていない古いコピーを除外します。より新しい時刻で再度スターを付けた場合や削除記録の期限が切れた場合は、スターが復元されることがあります。長期間のオフラインやデバイス間の時計のずれも削除の反映に影響します。

同期はデータをマージして書き込みを検証し、最大 3 回試行します。ただし、デバイス間のアトミックなトランザクションではなく、同時アップロードで他の書き込みを上書きする可能性があります。欠落したデータを保持するデバイスが後で同期すれば修復できますが、再同期しなければ復旧は保証されません。一部のアップロードが失敗しても成功済みの書き込みは残ります。再同期して修復を完了してください。

## 機能の特徴

- **マルチデバイス同期**: 複数のコンピュータで設定を同期させます。
- **データのプライバシー**: データはご自身の Google ドライブ ストレージ、または非公開の iCloud データベースに直接保存されるため、Voyager のサーバーを介さずプライバシーが確保されます。
- **柔軟な同期**: 手動でのアップロードおよびデータのダウンロード・マージをサポートしています。

::: info
デバイス識別子、アクセストークン、キャッシュ、ビューポートの座標、一時的な実行状態は、個人設定として意図的に同期されません。
:::

## 使用方法

1. Gemini、AI Studio、ChatGPT、Claude、DeepSeek、Kimi のいずれかのタブを開き、ブラウザのツールバーにある Voyager のアイコンをクリックして、ポップアップを開きます。**クラウド同期**セクションはこれらのサイトでのみ表示され、フォルダはサイトごとに別々に同期されます。
2. **クラウド同期**セクションを見つけます。
3. Safari では **Google ドライブ**または **iCloud** を選びます。ほかのブラウザでは Google ドライブを使用します。
4. **同期モード**を**手動**に切り替えます。初期状態は**無効**で、同期ボタンは手動モードでのみ表示されます。
5. Safari で Google ドライブを使う場合は、**Google ドライブに接続**をクリックし、Voyager アプリでサインインします。ほかのブラウザには専用のサインインボタンはなく、初めて**ドライブへ保存**または**ドライブからマージ**をクリックしたときに Google の認証画面が開きます。iCloud の場合は、Mac が iCloud にサインインしていることを確認します。
6. **ドライブへ保存**をクリックしてローカルデータをクラウドに同期するか、**ドライブからマージ**をクリックしてクラウドデータをこのブラウザに取り込みます。**上書き**は先に確認したうえで、クラウドにあり Voyager が読み取れるデータだけを置き換えます。クラウドにないデータや読み取れないデータはそのまま残り、結果に一覧表示されます。直後なら元に戻せます。

iCloud を使っている場合、**iCloud バックアップを削除**は iCloud 上のすべての Voyager バックアップを削除します。Mac 上のローカルデータはそのまま残ります。

### 💡 クイック同期

最も簡単な方法は、左側のサイドバーの**フォルダエリアのヘッダー**にあるクラウドアイコンをクリックし、メニューから「クラウドにアップロード」または「クラウドから同期」を選ぶことです。

<GuideShot src="/assets/cloud-sync.png" alt="クラウド同期クイックボタン" :width="440" />

::: warning
**安全上の推奨事項：二重保護**\
クラウド同期は非常に便利ですが、データの万全を期すため、定期的に**ローカルファイル形式**でコアデータを手動バックアップすることを強くお勧めします。

1. **フォルダ**: フォルダエリアのメニューを開き、**フォルダのインポート/エクスポート**を選んでから、**フォルダをエクスポート**をクリックすると、すべてのフォルダと会話の割り当てを保存できます。
2. **プロンプト**: プロンプトマネージャーで **エクスポート**をクリックして、プロンプトライブラリを保存します。
   :::

## 同期の安全策

<GuideFacts>
<GuideFact title="アップロード前の確認">

アップロードでクラウドのファイルが大きく減る場合（クラウドにあるデータがこの端末に1件もない、またはクラウドに4件以上あるのにこの端末では半分未満）や、Voyager がクラウドのファイルを読み取れない場合は、先に **代わりにクラウドからマージ**、**それでもアップロード**、**キャンセル** のどれにするかを確認します。マージはクラウドのファイルを読み取れるときだけ選べます。

</GuideFact>
<GuideFact title="上書きはクラウドにあるものだけを置き換える">

**上書き**は、クラウドにない種類のデータや Voyager が読み取れないデータを残し、結果に一覧表示します。クラウドのプラグイン一覧が空でも、手元のプラグインが消えることはありません。

</GuideFact>
<GuideFact title="ダウンロード直後に元に戻す">

**ドライブからマージ**または**上書き**のあと、ポップアップを開いている間は結果の行に **元に戻す** が表示されます。フォルダエリアのクラウド通知にも約10秒間表示され、ポインタを重ねている間は消えません。元に戻すと、そのダウンロードで変わった内容が復元され、その後に自分で変更した内容は残ります。元に戻せるのは最新のダウンロードだけです。

</GuideFact>
<GuideFact title="Google ドライブの履歴コピー">

アップロードでファイルを置き換える前に、Voyager は置き換えられる版を同じドライブフォルダに `<ファイル名>.backup-<UTC 時刻>.json` として残します（例：`gemini-voyager-folders.backup-2026-10-29-031100.json`）。ファイルごとに最新の3件を残し、それより古いものはドライブのゴミ箱に移します。iCloud には履歴コピーは残りません。

</GuideFact>
<GuideFact title="すべての端末を更新してください">

**Enable Hard Isolation** をオンにしている場合、現在の Voyager は各アカウントのドライブファイルにアカウントのメールアドレスを使って名前を付けます。Voyager 2.2.1 のままの端末で、最初に番号付きのアドレス（gemini.google.com/u/1）でそのアカウントを使っていた場合、更新するまで新しいバージョンがアップロードした内容は見えません。Chrome ウェブストアの更新は数日以内に届きますが、Safari はもっと時間がかかります。

</GuideFact>
</GuideFacts>

## クラウド同期と手動バックアップの比較

| 観点             | 手動バックアップ（エクスポート/インポート） | クラウド同期                                               |
| ---------------- | ------------------------------------------- | ---------------------------------------------------------- |
| 頻度             | 思い出したときに行う                        | ワンクリックでいつでも行える                               |
| データの保存先   | ご自身のコンピュータ上のローカルファイル    | ご自身の Google ドライブまたは非公開の iCloud データベース |
| デバイス間の利用 | ファイルの受け渡しが必要                    | 選択したクラウドアカウントにサインインしたデバイス同士     |
| マージの動作     | 置き換えか、手動でのマージが必要            | 重複させずに賢くマージ                                     |
| プライバシー     | ファイルはご自身のマシン上に残る            | ご自身の個人クラウドアカウントに保存                       |

## 仕組み

1. **プロバイダー**: Google ドライブは制限付きの `drive.file` 権限を使うため、Voyager が作成したファイルにしかアクセスできません。Safari の iCloud はアプリ専用の非公開 CloudKit データベースを使い、Apple ID のトークンを Voyager に渡しません。
2. **アップロード**: **ドライブへ保存**をクリックすると、Voyager はフォルダ、プロンプト、スター、分岐、タイムラインの階層、個人設定、プラグインの設定を、それぞれ別のバックアップファイルとして選択したプロバイダーに書き込みます。ハイライトのクラウド同期が有効な場合は、ハイライトのデータも含まれます。
3. **ダウンロードとマージ**: 別のデバイスで **ドライブからマージ**をクリックすると、Voyager はそれらのファイルを読み込み、データの種類ごとにマージします。新しいフォルダとプロンプトは重複せずに追加され、クラウドの環境設定が復元され、プラグインのエントリはプラグイン ID ごとにマージされます。
4. **バックグラウンドでの同期はありません**: 同期は手動で、必要なときだけ行われます。Voyager がご自身の明示的な操作なしに同期することはありません。

プロバイダーを切り替えても、データが両方のプロバイダー間でコピーされることはなく、両方に書き込まれることもありません。切り替えたあとに現在のローカルデータを新しいプロバイダーにも保存したい場合は、一度アップロードしてください。

## 対応プラットフォーム

Google ドライブの同期は、パソコンの Chrome、Edge、Firefox、Safari で利用できます。スマートフォン（Firefox for Android）では Google のログイン画面を開けないため、まだ使えません。iCloud の同期は、直接配布される Safari アプリでのみ利用でき、Mac にサインインしている iCloud アカウントを使います。
