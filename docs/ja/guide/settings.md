# 思うがままに

デフォルトも優れていますが、私たちは完璧を求めます。
あなたの環境は、あなた好みに整えましょう。

## シネマモード

ドアの隙間から世界を覗く必要はありません。
チャットボックスを広げましょう。

- **チャットの幅**: まずポップアップで **ページレイアウト** → **チャットの幅** をオンにします。デフォルトはオフで、オンにすると行の下にスライダーが表示されます。オンにすると、ウィンドウの 30%〜100% をスライダーで調整できます（デフォルトは 70%）。コードや大きな表には広く、読書に没頭するなら狭く。
- **入力欄の幅**: こちらも先に **ページレイアウト** → **入力欄の幅** をオンにすると、送信済みメッセージを編集するときの入力欄を広げられます。

## コントロール

拡張機能のアイコンをクリックして、コントロールパネルへ。

- **スクロール**: **タイムライン** → **タイムラインを表示** で選べます。`フロー` でメッセージまで滑らかに、`ジャンプ` で一瞬で。
- **配置**: タイムラインは右利き用？ 左利き用？ **タイムライン** → **タイムラインを表示** で **ドラッグ可能なタイムライン** をオンにして、使いやすい場所に。**タイムラインの位置をリセット** で元に戻せます。
- **視覚効果**: Gemini と AI Studio では、**ページレイアウト** → **視覚効果** をオンにして、その行の下で `雪`、`桜`、`雨` から選びます。オフにするとエフェクトも止まります。ほかのサイト(Claude、ChatGPT、DeepSeek、Kimi、カスタムサイト)では、同じ行がそのサイトの **プラグイン** カードに表示されます。Voyager がそのサイトで動作している(プロンプトマネージャー、またはそのサイトで有効にしたプラグインがある)場合に表示されます。

## カスタム並び替え

ポップアップの設定項目が多すぎて、よく使うものが下に埋もれていませんか？

設定カードにマウスを合わせると、右上に ▲/▼ ボタンが表示されます。クリックでカードを上下に移動でき、並び順は自動保存されます。

機能はテーマごとのカード（ページレイアウト、サイドバー、タイムライン、回答の表示など）に分かれていて、オンにするとそのオプションがスイッチのすぐ下に表示されます。スクロールしても検索欄とその下のカード名の列は上部に残り、名前をクリックするとそのカードへ移動します。スイッチを切り替え間違えたら、下に出るメッセージの **元に戻す** を押してください。

## Voyager パネル

毎回ポップアップを開くのが面倒なら、フローティングボタンにマウスを合わせて **Voyager パネル** をクリックするか、⌥V / Alt+V を押してください。ページの上で、いま開いているサイトの機能をオン・オフでき、スライダーもその場でプレビューできます。詳しくは [Voyager パネル](/ja/guide/panel) をご覧ください。

## サイトへのアクセス

<GuideOp>

ポップアップの **サイトへのアクセス** カードには、Voyager が動作できるすべてのサイトと、それぞれでオンになっている機能が並びます。

- **状態**: Gemini と AI Studio には **組み込み** と **すべての機能** が表示されます。ほかのサイトは **許可済み** か **未許可** で、その下にオンになっている機能が表示されます。
- **アクセスを解除**: **アクセスを解除** をクリックすると、そのサイトへの Voyager のアクセスを取り消します。下に出るメッセージの **元に戻す** で元に戻せます。
- **その他のウェブサイト**: それ以外のサイトでは、Voyager はプロンプトマネージャーだけを提供します。追加方法は [プロンプト](/ja/guide/prompts#有効にする方法) をご覧ください。

</GuideOp>

## オンライン更新

<GuideOp>

サイトのリニューアルで機能が動かなくなったとき、修正はストア審査を待たずにオンライン更新で届けられます。**オンライン更新** のスイッチは、Gemini と AI Studio では **一般オプション** の下のカード、ほかのサイトではそのサイトの **プラグイン** カードの一番下にあります。

- **確認する内容**: voyager.nagi.fun に、プラグインの更新と対応サイトのページ認識の修正を確認します。送るのはサイト名だけで、Cookie やページの内容は送りません。
- **今すぐ更新を確認**: スイッチの横の更新ボタンで、その場で 1 回確認します。スイッチがオフでも使えます。
- **オフ**: 自動確認が止まります。次にページを読み込んだときから、ページ認識ルールは拡張機能に組み込まれた版に戻り、ダウンロード済みのプラグインは引き続き使えます。

</GuideOp>

## Safari アプリの言語

Mac の Voyager アプリのウインドウ、メニュー、通知は、Voyager のポップアップで選んだ **言語** で表示されます。アラビア語を選ぶとレイアウトが左右反転します。

## アトモスフィア

Voyager は効率化だけでなく、ページの気分を変えることもできます。

- **雪**: やわらかな雪の結晶がゆっくり舞い落ちる、穏やかな冬の雰囲気。
- **桜**: 花びらが自然に舞い散る、軽やかな春の雰囲気。
- **雨**: 斜めの雨筋と微かな水しぶきが映画的な臨場感を演出。
- **スムーズな切り替え**: エフェクトをオフにしたり切り替えたりすると、パーティクルは自然に退場。
