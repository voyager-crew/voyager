# 作成モード

サイトをどう変えたいかを一文で書きます。そのサイト自身の AI がそれをプラグインとして書き、Voyager がチェックしてインストールします。コードは不要で、いまのチャットから離れる必要もありません。Gemini、AI Studio、ChatGPT、Claude、DeepSeek、Kimi で使えます。

作成モードの入口は 2 つあります。ページ上の [Voyager パネル](./panel.md)の **作成** タブと、Voyager ポップアップの **マイ作品** カードです。できあがるのは、自分のブラウザの中だけにあるローカルプラグインです。プラグインを自分で書きたいときや、コーディングエージェントに任せたいときは、[自分でプラグインを作る](./write-a-plugin.md)を見てください。

## ページ上で作成する

<GuideOp>

いちばん手早いのは、プラグインを使いたい AI サイトの上で作る方法です。そこで Voyager パネルを開き、**作成** を選びます。

</GuideOp>

<GuideSteps>
<GuideStep>

**何を変えますか？** の欄に一文を書きます（例：「自分のメッセージの幅を狭くして、サイドバーを隠す」）。続けて **このページで作成** を選びます。

</GuideStep>
<GuideStep>

Voyager がそのサイトで新しいチャットを開き、依頼を入力欄に入れます。確認してからご自身で送信してください。Voyager が送信ボタンを押すことはありません。入力欄にすでに文字がある場合、Voyager はそれに手を付けず、先に送信するか消すよう伝えます。

</GuideStep>
<GuideStep>

AI がそのサイト用の Voyager のページを読み、JSON のコードブロックを 1 つ返します。ブロックの下に、Voyager が **確認してインストール** を表示します。

</GuideStep>
<GuideStep>

それを選ぶと、パネルが確認画面を開きます。プラグインが動くサイト、各変更、CSS の全文、そして **確認しておくこと** の内容が並びます。**インストールしてオン** を選ぶと、すぐに反映されます。**機能** タブでいつでもオフにできます。

</GuideStep>
</GuideSteps>

<GuideOp>

プラグインを変えたいときは、同じチャットで AI に伝えます。

- **新しいバージョン**: 新しい返信の下に **更新を確認** が出るので、選んでから **更新してオン** を選びます。古いブロックは **以前の版** と表示されます。
- **インストール済みの版**: インストールした版には **インストール済み** と表示されます。
- **作成用のチャットだけ**: Voyager が返信を読むのは、あなたのメッセージに Voyager の作成ページへのリンクがあるチャットだけです。**このページで作成** が入れる依頼には必ず含まれます。それ以外のチャットでは返信の下に何も出ないので、下のポップアップでの方法を使ってください。

</GuideOp>

## ページ構造を添える

<GuideOp>

**作成** タブにはスイッチが 1 つあります。**このページの構造をテキストなしで添えて、AI が実際のページに合わせて書けるようにする** です。最初からオンになっているので、AI は推測ではなく、実際のページに合わせて書けます。

- **添えるもの**: Voyager が認識できるページ要素とその数、そして最新の返信と自分の最新メッセージのまわりの要素ツリー。
- **添えないもの**: ページ上のテキスト、リンク、チャットの内容、そして ID、メールアドレス、長い数字のようにデータに見える属性値。
- **添える内容を見る**: 開くと、実際に添えられるテキストをそのまま読めます。ページが変わると読み直します。
- **オフ**: スイッチをオフにすると、依頼に入るのは自分の一文だけになります。

</GuideOp>

## Gemini でのモデルの通知

<GuideOp>

Gemini では、Voyager はまず新しいチャットでどのモデルが使われるかを確かめます。Flash や Flash-Lite のような軽いモデルなら、**作成** タブの上部に、そのモデルではたいていプラグインを書けないという通知が出ます。

- **おすすめ**: 通知には、Gemini のモデルメニューで選べるもっと強いモデルの名前が出ます。ローカルのコーディングエージェントに依頼を渡すこともできます（通知の中に **ローカルエージェント用にコピー** があります）。
- **もう一度確認**: Gemini でモデルを切り替えたら、**もう一度確認** を選びます。パネルに戻ってきたときも、Voyager がもう一度確かめます。
- **デフォルトモデル**: [デフォルトモデル](./default-model.md)を使っている場合、Voyager は新しいチャットに適用されるデフォルトをもとに判断します。
- **作成は止めない**: ただの通知です。**このページで作成** はそのまま使えます。

</GuideOp>

## 返信をインストールできないとき

<GuideOp>

AI の返信がいつもうまくいくとは限りません。Voyager がインストールできない返信の下には、その理由がわかりやすい言葉で表示されます（例：「どのサイトで使うかが書かれていません」「変更の一部が許可されていません」）。

- **AI に修正を頼む**: 返信の下の **AI に修正を頼む** を選びます。Voyager が問題点の一覧を入力欄の、すでに入力した内容の後ろに入れるので、ご自身で送信してください。
- **直ったら**: AI が修正版を返すと、その下に **確認してインストール** が出ます。
- **確認画面で見つかったとき**: パネルの確認画面で初めて問題が見つかった場合、Voyager は何もインストールせず、問題点を一覧にします。

</GuideOp>

## インストールしたあと

<GuideOp>

インストールしたものは、すべて **マイ作品** にあります。パネルでは **機能** タブの中のグループです。ポップアップでは、Gemini と AI Studio なら設定カードの 1 つで、動かさなければ **クラウド同期** のすぐ下にあり、ポップアップ上部の **移動先** からも移動できます。ChatGPT、Claude、DeepSeek、Kimi ではプラグイン一覧の下にあります。

- **スイッチ**: 作品ごとに 1 行あり、ほかの機能と同じようにオン・オフできます。
- **削除**: ゴミ箱アイコンを選んで確認すると、このブラウザから削除されます。元には戻せません。
- **エクスポート**: ポップアップの **マイ作品** の一覧でその作品の **エクスポート** を選び、別のブラウザで JSON ファイルをインポートします。
- **共有する**: みんなの役に立ちそうなら、公式カタログへの収録を提案できます。その流れは[プラグイン貢献ガイド](./plugin-contribution.md)で説明しています。

</GuideOp>

### 自動チェック

<GuideOp>

パネルを開くと、Voyager は **マイ作品** の各作品が、いまのページで何かしているかを確かめます。

- **当てはまる要素がない**: 見た目を変える作品がオンなのに、それが変える要素がこのページに 1 つもない場合です。その行には **オンですが、このページに当てはまる要素がありません** と表示されます。ホバーやフォーカスの状態と、組み込み機能を呼ぶだけの作品は数に入りません。
- **ページが固まった**: コードを実行する作品のせいでページが応答しなくなった場合、Voyager はすでにそれをオフにしていて、その行に理由が表示されます。
- **修正を頼む**: どちらの場合も **修正を頼む** が出ます。Voyager はこのサイトで新しいチャットを開き、ページで見た内容とインストールされているプラグインを入れます（ページ構造のスイッチがオンなら、ページ構造も入れます）。パネルは閉じるので、内容を読んでから送信してください。

</GuideOp>

## Voyager の配色を変える

<GuideOp>

作品は、ページ上にある Voyager 自身の UI の色を変えることもできます。これも一文で頼めます（例：「Voyager のパネルとタイムラインを Nord 配色にする」）。AI は Voyager の公開カラー変数を 1 つの `:root` ルールで設定し、ライトでもダークでも同じように反映されます。

- **配色に合わせて変わるもの**: パネル、メニュー、ダイアログ、ツールチップ、トーストの背景、文字、枠線、ホバー色。ボタン、選択、フォーカスのアクセントカラー。削除に使う警告色。
- **タイムライン**: レール、選択されていないドットと目盛り、左側のスライダーのトラックには、専用の色が 1 つあります。
- **サイトに合わせたままのもの**: Voyager がサイトのページに直接描く文字、枠線、ホバー色は、サイトの色に従います。そのため、サイトの明るい背景に明るい文字が乗ることはありません。Voyager ポップアップは影響を受けません。

</GuideOp>

<GuideNote>

**Nord の例**: 上の一文からは、たいていこのような CSS ができます。設定しなかった変数は Voyager 本来の色のままです。

```css
:root {
  --gv-theme-surface: #2e3440;
  --gv-theme-hover: #3b4252;
  --gv-theme-text: #eceff4;
  --gv-theme-text-muted: #d8dee9;
  --gv-theme-border: #4c566a;
  --gv-theme-accent: #88c0d0;
  --gv-theme-accent-fg: #2e3440;
  --gv-theme-danger: #bf616a;
  --gv-theme-timeline: #81a1c1;
}
```

すべての変数: `--gv-theme-surface`（背景）、`-hover`（ホバーした行）、`-text`（文字）、`-text-muted`（補助的な文字、アイコン）、`-border`（枠線）、`-accent`（ボタン、選択、フォーカス）、`-accent-fg`（アクセントカラー上の文字）、`-accent-hue`（アクセントカラーの OKLCH 色相。数値）、`-danger`（削除）、`-timeline`（サイトの背景上のレールとドット）。

</GuideNote>

## パネルを使わずに：ポップアップから作成する

<GuideOp>

新しいチャットを開きたくないときや、別のチャットや別の AI に書かせたいときは、ポップアップの **マイ作品** から始めます。プラグイン一覧の最後にある **自分で作る** を押すと、最初の入力欄へ移動します。

</GuideOp>

<GuideSteps>
<GuideStep>

**何を変えますか？** の欄に一文を書きます。その下の **サイト** には、いま開いているタブのサイトが最初から選ばれています。別のサイト向けなら切り替えてください。

</GuideStep>
<GuideStep>

**このチャット用にコピー** を選び、そのサイトの AI チャットにメッセージを貼り付けます。AI はそのサイト向けの Voyager のページ（例：`https://voyager.nagi.fun/create/claude.md`）を読み、JSON のコードブロック 1 つで回答します。AI がリンクを開ける必要があります。

</GuideStep>
<GuideStep>

回答を丸ごと **AI の回答を貼り付け** に貼り付け、**回答をチェック** を選びます。

</GuideStep>
<GuideStep>

そのプラグインで何が変わるのかを、Voyager がわかりやすい言葉で説明します。**インポート** を選んだら、プラグイン一覧でオンにしてください。Gemini と AI Studio では、スイッチはカードのすぐ下に出ます。この方法でインポートしたプラグインは、最初はオフになっています。

</GuideStep>
</GuideSteps>

<GuideOp>

この方法では、Voyager が自分から何かを送ることはありません。メッセージを貼り付けるのも、回答を持ち帰るのもあなた自身です。

</GuideOp>

## コードを実行する作品

<GuideOp>

メッセージ数を数える、クリックに反応するなど、CSS とページの変更ではできない依頼には、AI が JavaScript を実行する作品を書けます。Voyager はそれを Chrome のユーザー スクリプトとして、作品が指定したサイトでだけ、あなたがコードを読んだあとにだけ実行します。確認画面では、こうした作品に **コードを実行** バッジが付きます。

</GuideOp>

### オンにする

<GuideOp>

- **読む**: 確認画面には、動作するサイトとソースコード全文が表示されます。作品はそのページ上のすべてを読むことができ、チャットの内容も例外ではありません。読んだ内容をよそへ送ることを Voyager は止められないので、信頼できるコードだけをインストールしてください。
- **インストールしてオン**: オンになるのは、あなたが読んだコードそのものです。あとでコードや対象サイトが変わると、もう一度確認するまで一時停止します。このスイッチがほかのデバイスに同期されることはありません。
- **最初の一度だけの設定**: Chrome では、許可しないと拡張機能はこうしたコードを実行できません。**Voyager の詳細ページを開く** を選び、そこで **ユーザー スクリプトを許可**（Allow User Scripts。Chrome 138 より前は `chrome://extensions` 上部の **デベロッパー モード**）をオンにしてから戻り、**オンにしました** を選びます。
- **ブラウザ**: デスクトップ版の Chrome または Edge 133 以降。Safari、Firefox、スマートフォンでは、インストールされたまま一時停止になります。見た目だけを変えるバージョンを AI に頼んでください。

</GuideOp>

### 管理する

<GuideOp>

**マイ作品** では、コードを実行する作品それぞれに **オン（このデバイスのみ）**、**オフ**、または理由付きの **一時停止中** が表示されます。

- **すべて停止**: **マイ作品** の末尾（ポップアップのカード、またはパネルの **機能** タブ）で **コードを実行する作品をすべて停止** を選ぶと、すべてが一度に止まります。**再開** で元に戻ります。
- **開いているページ**: すでに開いているページは、再読み込みするまで実行を続けます。**このページを再読み込み** で今のタブを再読み込みできます。
- **固まったとき**: こうした作品が動いたあとにページが応答しなくなると、Voyager はそれらをオフにし、次にページを読み込んだときに通知で名前を示します。直したら **マイ作品** でもう一度確認して、オンに戻してください。

</GuideOp>

## できること、できないこと

<GuideOp>

ほとんどの作品はページの見た目とレイアウトを変えるだけで、自身でコードを実行せず、オフにすればすべての変更を元に戻します。

- **できること**: ページのスタイルを変える、一部を隠す、設定にスイッチやスライダーを加える、Voyager の配色を変える。プラグインサイトでは、Voyager の組み込み機能（数式コピー、タイムライン、Mermaid 図など）をオンにすることもできます。
- **コードが必要なこと**: クリックへの反応、数を数えること、ページの読み取りには、上で説明したコードを実行する作品が必要です。
- **どの作品にもできないこと**: ほかのサイトでの動作と、Voyager 自身の設定の変更です。こうした依頼には、AI がそのことを伝え、実現できるいちばん近い形で作ります。
- **詳しいルール**: プラグインが使えるフィールドと、インポート時にチェックされる内容は、[自分でプラグインを作る](./write-a-plugin.md#プラグインにできること)にあります。

</GuideOp>
