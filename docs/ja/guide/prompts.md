# あなたのデジタル資産：プロンプトヴォルト

苦労して書き上げた神がかったプロンプト。大いに役立ちましたね。
使い終わったら捨てますか？
いいえ、保存しましょう。

## プロンプトヴォルト

これは、あなたのヴォルトです。

### 1. 保存

いいプロンプトができましたか？ Voyager のフローティングボール（デフォルトでは入力欄の横にあり、好きな場所へドラッグできます）をクリックして、**プロンプトマネージャー** を開きましょう。
ヴォルトに保存して、しっかり自分のものに。

### 2. 分類

`コード`、`メール`、`学術` などのタグを付けましょう（カンマで区切ります）。
道具は、使いやすく整えられてこそ意味があります。

### 3. 呼び出し

次回使いたい時、もう打ち直す必要はありません。
ヴォルトを開き、タグで検索し、ワンクリックで挿入。
一瞬で呼び出し、効率を倍増させましょう。

## コンパクトリストと名前ラベル

プロンプトが増えてパネルに収まりきらなくなったとき、パネルが進化します：

### ビュー切替

検索バーの右端にある `≡ / ▦` ボタンで **コンパクトリスト**（既定）と **快適表示** を切り替えます。

- **コンパクトリスト**：1 行 1 プロンプト、一度に約 10 件表示。右側にタグ・展開・編集・削除
- **快適表示**：Markdown プレビューを丸ごと、プロンプトが少ないときに最適

### 必須の名前

プロンプトの追加または編集時は、フォーム先頭の **名前** 欄への入力が必須です。名前のない既存プロンプトはそのまま保持されますが、次回の編集時に名前を追加する必要があります。

### 高速ホバープレビュー

コンパクトモードでは、任意の行に **約 250ms** ホバーするだけで完全な内容がフローティングツールチップに表示されます——ブラウザ標準の `title` 属性（表示まで 1〜3 秒）より段違いに素早い。

### スラッシュですばやく挿入

チャット入力欄で `/` に続けてプロンプト名の一部を入力します。一覧には一致する名前とタグだけが表示され、項目にホバーすると本文全体を確認できます。左クリックまたは `Tab` / `Enter` で選択すると、入力欄には名前が強調トークンとして表示され、送信時には完全なプロンプト本文が使われます。

![コンパクトリスト表示](/assets/gemini-prompt-manager-compact.png)

## あらゆるサイトで利用可能

プロンプトマネージャーは、Gemini™ と AI Studio に限らず、あなたが選択したあらゆるウェブサイトで使用できるようになりました。

### 有効にする方法

Claude、ChatGPT、DeepSeek、Kimi では、プロンプトマネージャーはそのサイトの **プラグイン** カードにある 1 行です。サイトを開いた状態で Voyager のポップアップを開き、**プロンプトマネージャー** をオンにします。そのサイトで最初にオンにする機能であれば、ブラウザがサイトへのアクセス許可を一度だけ求めます。

それ以外のサイトでは：

1. ブラウザのツールバーにある Voyager アイコンをクリックします。
2. **サイトへのアクセス** カードで **その他のウェブサイト** を探します。
3. ウェブサイトのアドレスを入力します（例：`poe.com`）。
4. **ウェブサイトを追加** をクリックして権限を許可します。
5. **対象のページを再読み込み** すると、フローティングボタンが表示されます。

### 人気の AI サイトの例

- `copilot.microsoft.com` - Microsoft Copilot
- `poe.com` - Poe

### ローカルアプリ

ローカルアドレスも使えます —— `localhost:3080` や `127.0.0.1:3080` を同じように入力するだけです。例えば [DeepSeek Harness](/ja/guide/deepseek-harness) は `localhost:3080` で動作し、プロンプトマネージャーは通常のサイトと同じようにマウントされます。

![DeepSeek Harness 内で動作するプロンプトマネージャー](/assets/prompt-manager-deepseek-harness.png)

::: tip
自分で追加したウェブサイトでは、**プロンプトマネージャー機能のみ** が有効になります。タイムラインやフォルダなどの機能は読み込まれません。Claude、ChatGPT、DeepSeek、Kimi は別で、それぞれ専用の公式プラグインがあり、[プラグイン一覧](/ja/guide/plugins) で確認できます。
:::
