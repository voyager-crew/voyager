# エコシステム

以下のプロジェクトは Voyager にインスパイアされた、または Voyager をベースに構築されたもので、他のプラットフォームにも同様の機能強化をもたらしています。

- **[DeepSeek Voyager](https://github.com/Azurboy/deepseek-voyager)** — Voyager を DeepSeek 向けに移植したプロジェクト。
- **[claude-nexus](https://github.com/Qiuner/claude-nexus)** — Voyager に着想を得た Claude.ai 向け拡張機能。タイムラインナビゲーション、フォルダ管理、プロンプトライブラリなどを備え、Voyager のプロンプトのインポート／エクスポートと完全互換です！
- **[Better_Doubao](https://github.com/Rex16200513/Better_Doubao)** — Doubao を強化するブラウザ拡張機能。ナビゲーション、整理、生産性機能を向上させます。
- **[DeepSeek Enhancer](https://github.com/dlshuangchenyue1210/DeepSeek-Enhancer)** — Voyager に触発された DeepSeek ウェブ版向けの拡張機能。多階層フォルダー、チャット履歴のエクスポート、数式コピー、データバックアップなどの機能を提供します。
- **[Voyager Lite](https://github.com/Carleo10032/voyager-lite)** — Voyager から派生した非公式の軽量版。ChatGPT、Claude、Gemini、Grok でのタイムラインナビゲーションと背景エフェクトに特化しています。
