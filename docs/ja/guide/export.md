# 完全な自由

Voyager のエクスポートを使うと、Gemini、ChatGPT、Claude、DeepSeek、Kimi の会話を Markdown、PDF、JSON、画像のいずれかの形式でダウンロードできます。コードブロック、画像、書式を含むチャットの全内容を取り出し、すべての AI 会話を、いつでも持ち運べる永続的なコピーとして残せます。

データに鍵をかけられるのは、最悪の体験です。
私たちの信条はシンプルです：あなたが創ったものは、あなたのものです。

## 形式の比較

| 項目           | Markdown                         | PDF                | JSON                   | 画像                   |
| -------------- | -------------------------------- | ------------------ | ---------------------- | ---------------------- |
| 向いている用途 | ノートアプリ（Obsidian、Notion） | 共有と印刷         | 開発者、データ分析     | スマートフォンでの共有 |
| 画像           | 埋め込み                         | すべて含む         | Base64 エンコード      | その位置に描画         |
| コードブロック | 構文付きで保持                   | 見た目どおりに描画 | 生のテキストとして保持 | 見た目どおりに描画     |
| ファイルサイズ | 最も小さい                       | 最も大きい         | 中くらい               | 大きい                 |
| 検索           | プレーンテキスト                 | PDF リーダーで検索 | プログラムからアクセス | 不可                   |

## すべてを持ち出す

Voyager は、データをクラウドからあなたの手元へと引き戻す手助けをします。

### 選べるフォーマット

- **Markdown**：Obsidian や Notion へ。画像も埋め込める、クリーンで扱いやすい形式です。
- **PDF**：共有や印刷に。画像も含まれた美しいレイアウト。
- **JSON**：開発者向け。生のデータ、使い方はあなた次第。
- **画像**：1 枚の長い PNG。スマートフォンでの共有にぴったりです。幅は狭い・中くらい・広いから選べます。

### エクスポート方法

1. **エクスポート** ボタンをクリックします（ChatGPT、Claude、DeepSeek、Kimi と現行の Gemini レイアウト）。初期位置はページ右上で、好きな場所へドラッグでき、位置はサイトごとに記憶されます。初期位置の近くで離すと元の位置に戻ります。Gemini では、会話や回答の ⋮ メニューから**会話履歴をエクスポート**を選ぶこともできます。従来の Gemini レイアウトでは、Gemini ロゴにマウスを合わせると**エクスポートアイコン**が表示されます。
2. フォーマットを選びます。
3. 持ち出します。

Claude、DeepSeek、Kimi では、エクスポートは初期状態でオフのプラグインです。先にポップアップの**プラグイン**でオンにしてください。長い会話は Voyager がスクロールしながら全体を読み取り、読み終えるとすべてのメッセージが選択された状態になります。不要なものはチェックを外してください。冒頭と末尾の両方を確認できなかった場合は、エクスポートが不完全な可能性があると警告します。ChatGPT で履歴をすべて読み込めなかった場合は、上にスクロールして以前のメッセージを読み込んでから再試行するよう案内します。別のチャットに移るとエクスポートは中止され、Claude では新しい回答の生成が始まった場合も中止されます。

ChatGPT の会話でアップロードしたファイルは、エクスポート内に `📎 ファイル名` の行として記載されます。

あなたのデータは、あなたの意のままに。

### Safari PDF エクスポートに関する注意

Safari で PDF をエクスポートする手順は少し異なります（手動印刷が必要です）：

1. **エクスポート**ボタンをクリックし、PDF 形式を選択します。
2. **1秒ほど待ちます**（ページが印刷スタイルの準備をするため）。
3. `Command + P` を押して印刷ダイアログを開きます。
4. 印刷ダイアログで **"Save to PDF"**（または「PDFとして保存」）を選択します。

## Deep Research のエクスポート

Gemini の Deep Research モードは、出典、思考のステップ、引用を含む構造化されたレポートを作ります。Voyager は、そのセッションをメタデータを保ったままエクスポートできます。

1. 完了した Deep Research の会話を開きます。
2. レポートの **共有とエクスポート** メニューを開き、**レポートを保存** を選びます。
3. 形式を選びます。
4. エクスポートには、出典リンク付きの最終レポートが含まれます。思考過程も保存したい場合は、[Deep Research のエクスポート](/ja/guide/deep-research) を参照してください。

推論の流れと出典の帰属を残しておく必要がある、学術研究、競合分析、技術文書の作成に役立ちます。

## エクスポートするタイミング

- **知識のアーカイブ**: 大切な会話が、チャット履歴の奥に埋もれてしまう前に保存します。
- **チームでの共有**: デバッグのセッションを PDF でエクスポートし、Gemini を使っていない同僚と共有します。
- **ナレッジベースの構築**: 会話を Markdown でエクスポートし、Obsidian や Notion で整理します。
- **データ分析**: JSON のエクスポートを使って、会話のパターンをプログラムで分析したり、構造化されたデータを抽出したりします。
- **コンプライアンスと監査**: 監査証跡のために、AI の支援を受けた判断の記録を残します。

## 対応プラットフォーム

エクスポートは、Gemini と ChatGPT で、Chrome、Edge、Firefox、Safari、Opera、Brave の各ブラウザで利用できます。Claude、DeepSeek、Kimi のエクスポートはプラグインで、初期状態ではオフです。**プラグイン**でオンにできます。Safari での PDF エクスポートは、エクスポートをクリックした後に手動で印刷する手順が必要です（Command+P）。Markdown と JSON のエクスポートには引き続き画像が含まれます。
