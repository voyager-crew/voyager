# プライバシーポリシー

最終更新日：2026年10月26日

## 概要

Voyager は、対応している AI チャットのワークスペースを整理・拡張するための、ローカルファーストのブラウザ拡張機能です。ユーザーが要求した機能を提供するためにのみ、限られたユーザーデータを処理します。Voyager は、会話、プロンプト、閲覧履歴、画像、アカウント識別子を受け取るバックエンドを運営しておらず、広告やアナリティクスのトラッカーも使用しません。

## 処理されるデータ

利用する機能によって、Voyager は次のデータを処理することがあります。

- **ウェブサイトの内容と個人的なやり取り**: フォルダ、ナビゲーション、エクスポート、プロンプト管理、リサーチ、インターフェース機能に使われる、会話のテキスト、プロンプト、下書き、画像、リンク、その他の対応ページの内容。
- **アカウント識別子**: 対応している Google サービスは、サインイン中のメールアドレスを公開することがあります。Voyager はそれをローカルのアカウント識別子に変換し、異なるアカウントのデータが混ざらないようにします。生のメールアドレスが Voyager に送信されることはありません。
- **閲覧履歴とユーザーの操作**: ナビゲーション、ショートカット、利用状況の表示、応答完了の通知、その他の要求された機能に必要な、対応サイトの URL、会話のルート、限られたページ・操作・ネットワークのイベント。このデータはプロファイリングや広告には使用されません。
- **認証情報**: `drive.file` スコープの OAuth2 トークン。ユーザーが Google ドライブ同期を明示的に有効にした場合にのみ使われます。
- **拡張機能のデータと設定**: フォルダ、プロンプトテンプレート、下書き、スター付きメッセージ、利用状況のスナップショット、プラグインの状態、インターフェースの設定。

このデータは、`chrome.storage.local` にローカルで保存されます。対応している設定については `chrome.storage.sync` に保存されることもあります。一部の機能は、対応サイト自身がユーザーのデバイス上に持つ `localStorage` も使い、フォルダデータのバックアップコピーとタイムラインのキャッシュを保存します。短時間だけ使う引き継ぎ用のレコードはセッションストレージに置かれます。Research Pack の引き継ぎではブラウザのメモリ上にある拡張機能の `storage.session` を使い、ChatGPT の一時チャットの引き継ぎではページの `sessionStorage` にタブ用トークンだけを保存し、会話の内容は最長 60 秒間 `chrome.storage.local` に置かれます。ユーザーが後述する転送を明示的に利用しない限り、データはユーザーのデバイスまたはブラウザの同期アカウント内に残ります。

## ユーザーが要求する転送

- **Google ドライブ同期（任意）**: Google ドライブ同期を明示的に有効にした場合、Chrome・Edge・Firefox ではブラウザの Identity API、Safari 直装版ではネイティブ Google Sign-In を使用し、認証情報は macOS キーチェーンに保存されます。どちらも `drive.file` スコープのみを要求し、選択したバックアップデータは端末と**ユーザー自身の Google ドライブ**の間で直接転送されます。OAuth トークンが Voyager のサーバーへ送信されることはありません。Chromium 系ブラウザでブラウザが直接トークンを発行できない場合（Brave や、その方法でのサインインに失敗した場合など）、Google はサインイン結果を `https://voyager.nagi.fun/oauth/callback/` の静的な中継ページへ返し、そのページのスクリプトがブラウザ内で拡張機能へ受け渡します。トークンは URL フラグメントに含まれ、ブラウザはこれをサーバーへ送信しません。一般的な Web ページと同じく、静的ホストにはリクエスト元の IP アドレスとブラウザの User-Agent が見えます。Firefox ではループバックリダイレクト（`http://127.0.0.1/mozoauth2/…`）を使い、ブラウザがリクエスト送信前にこれを捕捉します。認可コードは PKCE を使って Google と直接交換されます。
- **Safari の iCloud 同期（任意）**: 選択したバックアップデータは、ネイティブの Safari 拡張機能によって、ユーザーの iCloud アカウント内の非公開 CloudKit データベースへ直接転送されます。Voyager は、ユーザーの Apple ID や iCloud の認証トークンを受け取らず、開発者もその非公開データベースのレコードにはアクセスできません。
- **エクスポートと画像**: ユーザーがエクスポートを要求すると、Voyager は既存のページがホストしている画像元から画像を取得することがあり、生成されたインターフェースの内容を取り込むために一時的なアクセスを要求することもあります。作成されたファイルはユーザーのためのものであり、Voyager のサーバーにはアップロードされません。
- **Context Sync（任意）**: ユーザーが同期を押すと、Voyager は取得した会話のコンテキストを、ユーザー自身のコンピューター上のローカルサーバー `http://127.0.0.1:<ポート>/sync`（既定のポートは 3030、変更可能）へ送信します。機能が有効でポップアップが開いている間は、ローカルサーバーに接続できるかを表示するためにこのアドレスも確認します。このデータが Voyager を通じてデバイスの外に出ることはありません。
- **Research Pack の「ChatGPT / Claude で続ける」**: ユーザーが送り先を選ぶと、Voyager は選んだサイト（ChatGPT または Claude）で新しいチャットを開きます。そのサイトで Voyager が動作している場合、パックはブラウザのメモリ上の `storage.session` を通じて受け渡され、そのタブが 1 回だけ受け取り、送信せずに入力欄へ入れます。このレコードは 60 秒で期限切れになります。それ以外の場合、パックはクリップボードにコピーされ、ユーザーが貼り付けます。パックが URL に含まれることはありません。
- **ChatGPT 一時チャットの引き継ぎ**: ユーザーが ChatGPT の一時チャットを続けることを選ぶと、Voyager は Markdown のバックアップをユーザーのデバイスにダウンロードし、一時モードを終了して、会話を通常の ChatGPT チャットの入力欄に送信せずに入れます。会話の内容は ChatGPT とユーザーのデバイス上にのみ残ります。
- **公開プロジェクトのリソース**: Voyager は、公開リリース、お知らせ、ドキュメントのリソースを要求することがあります。これらのリクエストには、会話やプロンプトの内容は含まれません。
- **オンラインカタログの更新**：「オンライン更新」は初期設定でオンです。対応する Gemini（Enterprise を含む）、AI Studio、ChatGPT、Claude、DeepSeek、Kimi のページでは、ページを開くと、Voyager が `https://voyager.nagi.fun/catalog/hosts/<サイトのホスト名>.json` を HTTPS で取得することがあります。ポップアップを開いてもローカルキャッシュを読むだけで、ボタンから手動確認を実行できます。自動確認は前回の試行から設定した間隔（既定は 6 時間。1 時間・6 時間・24 時間・手動のみ）で行い、失敗時は再試行までの時間を延ばします。手動確認は間隔を待たずに実行でき、オンライン更新がオフでも利用できます。オフにすると自動のカタログリクエストを停止します。キャッシュ内のプラグインと既存のサイト設定は、ページ認識ルールを含め引き続き使えます。更新をオフにして再読み込みしても、これらのルールは従来どおりに動作します。追加のページ認識データには同梱版を使います。スイッチと間隔はブラウザ同期と設定バックアップの対象で、取得したカタログは端末内に保存します。この 1 つの経路で、各サイト専用のページ認識データを配信します。オンライン修正は、会話、入力、ナビゲーション、メニュー、エクスポート、画像、Voyager のコントロールの配置など、対応機能で使うページ認識を対象とします。Gemini と AI Studio の公式プラグインと CSS、および全サイトの識別ルール、削除操作、クリックや入力の処理は引き続き同梱します。修正、修正の撤回、更新のオフへの切り替えは、手動でページを再読み込みした後に反映します。自動再読み込みは行いません。オンライン更新がオンのとき、サイトの操作、データ、対象の会話に関わる修正はページ上の独立した情報で検証し、確認できなければ操作全体で同梱データを使います。Voyager のコントロールの配置だけに使う修正は公式カタログを信頼します。対象が見つからない場合や、設置先が編集可能な領域内にある場合は、同梱の配置に戻ります。カタログの取得は通常の GET で、Cookie、アカウントや拡張機能の識別子、ページや会話の内容は送りません。サーバーには IP アドレス、User-Agent、URL 内のサイトのホスト名などの接続情報が見えます。CSS と JSON は使用前に検証し、リモートの JavaScript や WebAssembly は実行しません。お知らせと任意のクラウド同期はそれぞれ別の設定です。voyager.nagi.fun は Cloudflare プロキシ配下の静的ホスティングで、Voyager プロジェクトはこれらのリクエストを記録・保存しません。接続情報はホスティング事業者が各自のプライバシーポリシーに従って扱います。

Voyager はユーザーのデータを販売せず、広告、信用評価、または拡張機能のユーザー向け機能と無関係な目的のために転送することもありません。

## 権限

- **Storage（ストレージ）**: 拡張機能のデータと環境設定をローカルに保存し、対応している場合はブラウザの同期経由でも保存します。Chrome、Edge、Firefox は `unlimitedStorage` も付与されるため、既定のブラウザ容量上限でローカルデータが切り捨てられることはありません。ただし Voyager 自身の容量制限は引き続き適用されます。Safari では、この権限は任意です。
- **Identity（認証）**: ユーザーが明示的に操作した後に、任意の Google ドライブ同期の認証を行います。Safari 版はこの権限を要求しません。Safari での Google ドライブ同期と iCloud 同期は Voyager の macOS アプリを通じて行われます。
- **Scripting（スクリプト注入）**: 対応サイトに、拡張機能に同梱されたスクリプトだけを注入します。リモートの JavaScript や WebAssembly は実行しません。
- **Active tab と宣言的コンテンツ**: ユーザーが開いた対応サイトを特定し、そのサイトに適した操作項目を表示します。宣言的コンテンツは Chrome と Edge でのみ使われます。
- **Alarms（アラーム）**: 公開されているお知らせを定期的に確認し、期限切れの引き継ぎレコードの削除や遅延タスクの実行のためにバックグラウンドのタイマーを動かします。
- **通知（任意）**: 応答完了の通知、またはリモートお知らせのシステム通知をユーザーがオンにした場合にのみ要求します。Safari 版はこの権限を要求せず、応答完了の通知は Voyager の macOS アプリが表示します。
- **Native messaging（Safari のみ）**: Google ドライブ同期、iCloud 同期、応答完了の通知のために、Safari 拡張機能を Voyager の macOS アプリに接続します。
- **ホスト権限**: Gemini、Gemini Enterprise、AI Studio についてはインストール時に付与され、さらにユーザーが要求する Google ドライブと画像の操作に必要な Google のドメインも含まれます。
- **任意のホスト権限**: Claude、ChatGPT、DeepSeek、およびカスタムサイトには、ユーザーがそのサイトで Voyager またはプラグインを有効にし、ブラウザの権限の確認に承認した後にだけアクセスします。生成されたインターフェースの内容を取り込むエクスポートをユーザーが選んだ場合は、`<all_urls>` の権限を一時的に要求することもあります。拒否された場合、その取り込みを除いてエクスポートを続行します。

## 保持とユーザーによる管理

ローカルとブラウザ同期のデータは、ユーザーが削除するか、拡張機能のストレージを消去するか、拡張機能をアンインストールするまで残ります。Voyager が対応サイト自身の `localStorage` に保存するコピー（フォルダのバックアップとタイムラインのキャッシュ）はアンインストールしても削除されません。削除するには、ブラウザでそのサイトのデータを消去してください。クラウドのバックアップは、ユーザーがその Google ドライブまたは iCloud アカウントから削除するまで、そのアカウントに残ります。ユーザーは Voyager とブラウザの設定から、任意の機能を無効にしたり、任意のサイトへのアクセスや Google の認可を取り消したりできます。

## Google API の限定的利用

Voyager による Google API から受け取った情報の利用と転送は、限定的利用の要件を含む Chrome ウェブストアのユーザーデータポリシーに従います。

## ポリシーの変更

プライバシーポリシーは随時更新される可能性があります。変更があった場合は、このページに新しいプライバシーポリシーを掲載することで通知します。
