# Política de Privacidade

Última atualização: 25 de outubro de 2026

## Visão geral

O Voyager é uma extensão de navegador que funciona primeiro no seu dispositivo (local-first), feita para organizar e aprimorar os espaços de conversa com IA compatíveis. Ele processa uma quantidade limitada de dados do usuário, apenas para oferecer os recursos que você solicita. O Voyager não mantém um backend que recebe conversas, prompts, atividade de navegação, imagens ou identificadores de conta, e não usa rastreadores de publicidade nem de análise.

## Dados processados

Dependendo dos recursos que você usa, o Voyager pode processar:

- **Conteúdo de sites e comunicações pessoais**: texto de conversas, prompts, rascunhos, imagens, links e outros conteúdos das páginas compatíveis, usados para pastas, navegação, exportação, gerenciamento de prompts, pesquisa e recursos de interface.
- **Identificadores de conta**: um serviço compatível do Google pode expor o endereço de e-mail da conta conectada. O Voyager o converte em um identificador local da conta, para que os dados de contas diferentes continuem separados. O Voyager não envia o endereço de e-mail original para nenhum servidor.
- **Histórico da web e atividade do usuário**: URLs de sites compatíveis, rotas de conversas e eventos limitados de página, interação e rede necessários para navegação, atalhos, indicadores de uso, notificações de conclusão de resposta e outros recursos solicitados. Esses dados não são usados para criar perfis nem para publicidade.
- **Informações de autenticação**: um token OAuth2 com o escopo `drive.file`, somente quando você ativa explicitamente a sincronização com o Google Drive.
- **Dados e configurações da extensão**: pastas, modelos de prompts, rascunhos, mensagens favoritas, registros de uso, estado dos plugins e preferências de interface.

Esses dados são armazenados localmente em `chrome.storage.local` ou, para as configurações compatíveis, em `chrome.storage.sync`. Alguns recursos também usam o `localStorage` do próprio site compatível, no seu dispositivo, para cópias de segurança dos dados de pastas e para caches da linha do tempo. Registros de transferência de curta duração usam armazenamento de sessão: o `storage.session` da extensão, na memória do navegador, para a transferência do Research Pack e, na transferência de chats temporários do ChatGPT, um token de aba no `sessionStorage` da página, enquanto a transcrição aguarda no máximo 60 segundos em `chrome.storage.local`. Eles permanecem no seu dispositivo ou na conta de sincronização do navegador, a menos que você use explicitamente uma das transferências descritas abaixo.

## Transferências solicitadas pelo usuário

- **Sincronização com o Google Drive (opcional)**: se ativar a sincronização com o Google Drive, Chrome, Edge e Firefox utilizam a API de identidade do navegador; a aplicação Safari de distribuição direta utiliza o Google Sign-In nativo e guarda as credenciais no Porta-chaves do macOS. Ambos os caminhos solicitam apenas o scope limitado `drive.file` e transferem os dados de cópia de segurança selecionados diretamente entre o seu dispositivo e **o seu próprio Google Drive**. Os tokens OAuth não são enviados para nenhum servidor Voyager. Em navegadores Chromium, quando o navegador não consegue emitir um token diretamente (por exemplo, no Brave ou quando esse login falha), o Google devolve o resultado do login para uma página de retransmissão estática em `https://voyager.nagi.fun/oauth/callback/`, cujo script o encaminha para a extensão dentro do navegador. O token fica no fragmento da URL, que os navegadores não enviam ao servidor; como em qualquer página web, o alojamento estático vê o endereço IP e o user agent do navegador que fez o pedido. O Firefox usa, em vez disso, um redirecionamento de loopback (`http://127.0.0.1/mozoauth2/…`) que o navegador interceta antes de qualquer pedido sair, e troca o código de autorização diretamente com o Google usando PKCE.
- **Sincronização com o iCloud no Safari (opcional)**: os dados de backup selecionados são transferidos pela extensão nativa do Safari diretamente para o seu banco de dados privado do CloudKit, na sua conta do iCloud. O Voyager não recebe o seu Apple ID nem um token de autenticação do iCloud, e o desenvolvedor não tem acesso aos registros desse banco privado.
- **Exportações e imagens**: quando você pede uma exportação, o Voyager pode buscar imagens das fontes já hospedadas na própria página e pode solicitar o acesso temporário necessário para capturar o conteúdo de interface gerado. O arquivo resultante é criado para você; ele não é enviado para nenhum servidor do Voyager.
- **Context Sync (opcional)**: quando você clica em sincronizar, o Voyager envia o contexto da conversa capturado para um servidor local no seu próprio computador, em `http://127.0.0.1:<porta>/sync` (porta 3030 por padrão, configurável). Enquanto o recurso está ativado e o popup aberto, ele também consulta esse endereço para mostrar se o servidor local está acessível. Esses dados não saem do dispositivo por meio do Voyager.
- **Research Pack «Continuar no ChatGPT / Claude»**: quando você escolhe um destino, o Voyager abre um novo chat no site selecionado (ChatGPT ou Claude). Se o Voyager estiver ativo lá, o pacote é entregue pelo `storage.session` em memória do navegador, recolhido uma única vez por essa aba e colocado na caixa de texto sem ser enviado; o registro expira após 60 segundos. Caso contrário, o pacote é copiado para a área de transferência para você colar. O pacote nunca viaja em uma URL.
- **Transferência de chats temporários do ChatGPT**: quando você decide continuar um chat temporário do ChatGPT, o Voyager baixa uma cópia de segurança em Markdown para o seu dispositivo, sai do modo temporário e coloca a conversa na caixa de texto de um chat normal do ChatGPT sem enviá-la. A transcrição fica no ChatGPT e no seu dispositivo.
- **Recursos públicos do projeto**: o Voyager pode solicitar recursos públicos de lançamento, comunicados ou documentação. Essas solicitações não incluem conteúdo de conversas ou prompts.
- **Atualizações online do catálogo de plugins**: num site onde tenha ativado pelo menos um plugin, o Voyager pode pedir por HTTPS o ficheiro de catálogo desse site em `https://voyager.nagi.fun/catalog/hosts/<host do site>.json`, por exemplo `https://voyager.nagi.fun/catalog/hosts/chat.deepseek.com.json`. A verificação só acontece ao abrir uma página desse tipo ou ao abrir a janela da extensão nessa página, e apenas se a última verificação for mais antiga do que o intervalo que escolheu (6 horas por predefinição; 1 hora, 6 horas, 24 horas ou apenas manual). O Gemini e o AI Studio mantêm os plugins oficiais incluídos na extensão e nunca solicitam o catálogo de plugins. O pedido é um GET simples que não envia cookies, identificadores de conta ou da extensão, nem conteúdo da página ou da conversa; tal como em qualquer pedido web, o servidor vê o endereço IP de origem e o user agent do navegador, além do nome de host do site no caminho do URL. Nos sites com plugins, a janela da extensão oferece um interruptor «Atualizações online de plugins» e o seletor de intervalo; ambas as definições ficam guardadas no armazenamento sincronizado do navegador e são incluídas na cópia de segurança das definições. Com o interruptor desligado, o Voyager não faz nenhum pedido do catálogo de plugins a voyager.nagi.fun a não ser que carregue em «Verificar atualizações de plugins agora». Se o pedido falhar ou o site não tiver ficheiro de catálogo, mantém-se em uso o instantâneo de plugins incluído na extensão. Um catálogo obtido contém apenas CSS e JSON, que são validados e sanitizados antes de serem usados; nunca é transferido nem executado JavaScript. Esta verificação é separada da verificação de anúncios, que tem a sua própria definição. voyager.nagi.fun é um alojamento estático atrás de um proxy Cloudflare; o projeto Voyager não regista nem conserva estes pedidos, e os metadados de ligação (endereço IP, User-Agent) são tratados pelos fornecedores de alojamento segundo as suas próprias políticas de privacidade.
- **Correções online para a detecção de páginas do Gemini (opcionais, desativadas por padrão)**: somente após ativar este interruptor independente nas opções gerais, o Voyager pode obter `https://voyager.nagi.fun/catalog/gemini-selectors/v3/hosts/gemini.google.com.json`. O arquivo contém apenas regras validadas para localizar as mensagens da conversa, as entradas e os títulos da barra lateral, as áreas de exibição de pastas, os controles do menu de modelos, os menus de conversa e exportação, a área de clique do botão de abrir e fechar a barra lateral e suas áreas sensíveis ao cursor, o conteúdo das mensagens para exportação e ramificações, as imagens de contexto, as ações de resposta e do pacote de pesquisa, os indicadores de uso, os blocos de código e diagramas, os parágrafos com LaTeX nas suas mensagens, a barra lateral de Gems, as caixas de mensagens com seus controles e os elementos da página usados pelo recolhimento da caixa de entrada, pelo modo Vim, pelo histórico de prompts, pelos comandos com barra, por Pasta como Projeto e pela atividade das pastas, sem código, CSS ou plugins. Abrir o Gemini ou seu popup pode iniciar uma verificação automática, no máximo uma vez a cada 6 horas desde a última tentativa. Desligar e religar não reinicia esse intervalo. Uma verificação interrompida por uma reinicialização da extensão pode ser repetida. “Verificar agora” ignora apenas o intervalo e só funciona com o interruptor ativado. Para ativar, é preciso ter uma aba do Gemini aberta; para desativar, basta usar o popup em qualquer aba. Ao desativar, todas essas solicitações são bloqueadas, inclusive as manuais, as verificações em andamento são canceladas e os dados baixados são removidos; o horário da última tentativa permanece local. O consentimento e os dados baixados ficam apenas no dispositivo, fora da sincronização do navegador e dos backups de configurações. Novas correções e a desativação entram em vigor quando você recarrega a página; páginas abertas mantêm seu snapshot, sem recarga automática. O GET não envia cookies, referrer, identificadores nem conteúdo de páginas ou conversas. O servidor vê IP, User-Agent e o host solicitado; aplicam-se as políticas de hospedagem acima. O AI Studio continua usando apenas dados incluídos. Atualizações de plugins e anúncios mantêm configurações independentes.

O Voyager não vende dados do usuário nem os transfere para publicidade, avaliação de crédito ou finalidades não relacionadas aos recursos da extensão voltados ao usuário.

## Permissões

- **Storage (armazenamento)**: salva dados e preferências da extensão localmente e, onde há suporte, pela sincronização do navegador. Chrome, Edge e Firefox também concedem `unlimitedStorage`, para que os dados locais não sejam cortados pela cota padrão do navegador; o Voyager ainda aplica o próprio limite de armazenamento. No Safari, essa permissão é opcional.
- **Identity (identidade)**: autentica a sincronização opcional com o Google Drive, depois de uma ação explícita sua. A versão para Safari não a solicita: lá, a sincronização com o Google Drive e o iCloud passa pelo app Voyager para macOS.
- **Scripting (scripts)**: injeta apenas scripts incluídos na própria extensão nos sites compatíveis; nenhum JavaScript ou WebAssembly remoto é executado.
- **Active tab e declarative content (aba ativa e conteúdo declarativo)**: identifica o site compatível aberto por você e exibe os controles específicos desse site. O declarative content é usado apenas no Chrome e no Edge.
- **Alarms (alarmes)**: agenda verificações periódicas de comunicados públicos, além de temporizadores em segundo plano que limpam registros de transferência expirados e executam tarefas adiadas.
- **Notifications (notificações, opcional)**: solicitada somente quando você ativa as notificações de conclusão de resposta ou os alertas do sistema para anúncios remotos. A versão para Safari não a solicita; lá, as notificações de conclusão de resposta são exibidas pelo app Voyager para macOS.
- **Native messaging (mensagens nativas, somente Safari)**: conecta a extensão do Safari ao app Voyager para macOS para a sincronização com o Google Drive e o iCloud e para as notificações de conclusão de resposta.
- **Host permissions (permissões de host)**: concedidas na instalação para Gemini, Gemini Enterprise e AI Studio, além dos domínios do Google necessários para as operações de Google Drive e de imagens que você solicita.
- **Optional host permissions (permissões de host opcionais)**: Claude, ChatGPT, DeepSeek e sites personalizados só são acessados depois que você ativa o Voyager ou um plugin para esse site e aprova o pedido de permissão do navegador. `<all_urls>` também pode ser solicitado temporariamente quando você escolhe uma exportação que captura o conteúdo de interface gerado; se a permissão for negada, a exportação continua sem essa captura.

## Retenção e controle pelo usuário

Os dados locais e os dados de sincronização do navegador permanecem até que você os exclua, limpe o armazenamento da extensão ou desinstale a extensão. As cópias que o Voyager guarda no `localStorage` do próprio site suportado (cópias de segurança das pastas e caches da linha do tempo) não são removidas ao desinstalar; para as apagar, limpe os dados desse site no navegador. Os backups na nuvem permanecem na conta do Google Drive ou do iCloud escolhida até que você os remova dessa conta. Você pode desativar os recursos opcionais e revogar o acesso opcional aos sites ou a autorização do Google pelas configurações do Voyager e do navegador.

## Uso limitado das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google pelo Voyager seguem a Política de Dados do Usuário da Chrome Web Store, incluindo os requisitos de Uso Limitado.

## Alterações a Esta Política

Podemos atualizar a nossa Política de Privacidade ocasionalmente. Iremos notificá-lo de quaisquer alterações publicando a nova Política de Privacidade nesta página.
