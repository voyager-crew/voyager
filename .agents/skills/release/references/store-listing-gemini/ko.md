**Gemini 페이지 인식 온라인 수정(선택 사항, 기본값 꺼짐)**: 일반 설정의 이 별도 스위치를 켠 경우에만 Voyager가 `https://voyager.nagi.fun/catalog/gemini-selectors/v1/hosts/gemini.google.com.json`을 가져올 수 있습니다. 파일에는 대화 메시지, 사이드바 항목과 제목, 폴더 표시 영역, 모델 메뉴 항목, 대화 및 내보내기 메뉴, 내보내기 선택 막대, 사이드바 열기·닫기 버튼의 클릭 영역 및 사이드바의 마우스 오버 영역, 내보내기 및 분기에 쓰이는 메시지 본문, 컨텍스트 이미지, 응답 및 리서치 팩 작업, 사용량 표시, 코드 블록과 다이어그램, 내 메시지에서 LaTeX가 포함된 문단, 내보내기에 포함되는 검색 결과 이미지, 생성 이미지 다운로드 버튼, Canvas 코드 내보내기, Gems 사이드바, 메시지 입력창과 관련 버튼, 입력창 접기·Vim 모드·프롬프트 기록·슬래시 명령·전송한 프롬프트 미리보기·폴더를 프로젝트로 사용·폴더 활동에 쓰이는 페이지 요소를 찾기 위한 검증된 규칙만 포함되며 코드, CSS, 플러그인은 없습니다. Gemini 또는 그 팝업을 열면 자동으로 확인할 수 있지만, 마지막 시도 이후 6시간에 한 번까지만 확인합니다. 스위치를 껐다 켜도 간격은 초기화되지 않습니다. 확장 프로그램 재시작으로 중단된 확인은 다시 시도할 수 있습니다. ‘지금 확인’은 켜져 있을 때만 사용할 수 있으며 시간 간격만 건너뜁니다. 켜려면 Gemini 탭이 열려 있어야 하지만, 끄기는 어느 탭의 팝업에서나 할 수 있습니다. 끄면 수동 확인을 포함한 이러한 요청을 모두 차단하고 진행 중인 확인을 취소하며 다운로드된 데이터를 삭제합니다. 마지막 시도 시각은 로컬에 남습니다. 동의 설정과 다운로드된 데이터는 현재 기기에만 저장되며 브라우저 동기화나 설정 백업에 포함되지 않습니다. 새 수정과 끄기 변경은 직접 페이지를 새로고침한 뒤 적용됩니다. 열린 페이지는 현재 스냅샷을 유지하며 자동으로 새로고침하지 않습니다. GET 요청은 쿠키, Referrer, 식별자, 페이지나 대화 내용을 전송하지 않습니다. 서버에는 IP, User-Agent, 요청한 호스트가 보이며 위의 호스팅 정책이 적용됩니다. AI Studio는 계속 포함된 데이터만 사용합니다. 플러그인 업데이트와 공지 설정은 각각 독립적입니다.
