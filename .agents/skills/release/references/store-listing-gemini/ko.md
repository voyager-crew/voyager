# Gemini page detection listing: 한국어

> Draft for maintainer review; not submitted to a store.

**온라인 카탈로그 업데이트**: “온라인 업데이트”는 기본으로 켜져 있습니다. 지원되는 Gemini(Enterprise 포함), AI Studio, ChatGPT, Claude, DeepSeek, Kimi에서 페이지를 열면 Voyager가 HTTPS로 `https://voyager.nagi.fun/catalog/hosts/<사이트 호스트 이름>.json`을 가져올 수 있습니다. 팝업을 열면 로컬 캐시만 읽으며, 버튼으로 수동 확인을 요청할 수 있습니다. 자동 확인은 마지막 시도부터 선택한 간격(기본 6시간, 1시간·6시간·24시간·수동 전용 중 선택)을 따르며, 실패하면 재시도를 늦춥니다. 켜져 있을 때는 수동 확인으로 간격을 건너뛸 수 있습니다. 끄면 자동 및 수동 카탈로그 요청이 모두 중지됩니다. 스위치와 간격은 브라우저 동기화 및 설정 백업에 포함되고, 다운로드한 카탈로그는 기기에 저장됩니다. 하나의 경로로 각 사이트 전용 페이지 인식 데이터를 제공합니다. 수정 범위는 Gemini의 대화·사이드바·입력·메뉴·내보내기·이미지, AI Studio의 입력·라이브러리 목록·라이브러리 이동 링크, ChatGPT·Claude·Kimi의 입력, ChatGPT·Claude·DeepSeek·Kimi의 내보낼 답변 본문, ChatGPT 로컬 브리지의 답변 본문입니다. Gemini와 AI Studio의 공식 플러그인 및 CSS, 모든 사이트의 식별 규칙·삭제 작업·클릭 및 입력 처리는 확장 프로그램에 포함된 것을 사용합니다. 새 수정, 수정 철회, 업데이트 끄기는 직접 페이지를 새로고침한 후 반영됩니다. 자동 새로고침은 하지 않습니다. 수정을 사용할 수 없거나 독립적으로 확인할 수 없으면 해당 작업 전체에 포함된 데이터를 사용합니다. 카탈로그 요청은 일반 GET이며 쿠키, 계정이나 확장 프로그램 식별자, 페이지나 대화 내용을 보내지 않습니다. 서버는 IP 주소, User-Agent, URL의 사이트 호스트 이름 등 일반 연결 정보를 볼 수 있습니다. CSS와 JSON은 사용 전에 검증하며 원격 JavaScript나 WebAssembly는 실행하지 않습니다. 공지와 선택 사항인 클라우드 동기화는 각각 별도 설정을 따릅니다. voyager.nagi.fun은 Cloudflare 프록시 뒤의 정적 호스팅입니다. Voyager 프로젝트는 이 요청을 기록하거나 보관하지 않으며 호스팅 제공자가 자체 개인정보 처리방침에 따라 연결 정보를 처리합니다.
