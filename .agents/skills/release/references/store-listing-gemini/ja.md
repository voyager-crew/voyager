# Gemini page detection listing: 日本語

> Draft for maintainer review; not submitted to a store. See the [listing reference](../store-listing-plugin-catalog.md) for the separate plugin-catalog paragraph and store-specific notes.

**Gemini ページ認識のオンライン修正（任意・初期設定はオフ）**: 一般設定の独立したスイッチを有効にした場合に限り、Voyager は `https://voyager.nagi.fun/catalog/gemini-selectors/v1/hosts/gemini.google.com.json` を取得することがあります。ファイルには、ページ上の会話のやり取り、サイドバーの項目とタイトル、フォルダーの表示領域、モデルメニューの操作項目、会話・エクスポートメニュー、エクスポートの選択バー、サイドバー開閉ボタンのクリック領域とサイドバーのホバー領域、エクスポートと分岐に使うメッセージ本文、コンテキスト画像、返信とリサーチパックの操作、使用量表示、コードブロックと図、自分のメッセージ内の LaTeX を含む段落、エクスポートに含まれる検索結果の画像、生成画像のダウンロードボタン、Canvas のコードのエクスポート、Gems サイドバー、メッセージ入力欄とその操作項目に加え、入力欄の折りたたみ、Vim モード、プロンプト履歴、スラッシュコマンド、送信済みプロンプトのプレビュー、「フォルダをプロジェクトとして」、フォルダーのアクティビティが使用するページ要素を認識するための検証済みルールのみが含まれます。コード、CSS、プラグインは含みません。Gemini またはそのポップアップを開くと自動確認が行われる場合がありますが、前回の試行から 6 時間に 1 回までです。オフからオンに戻しても間隔はリセットされません。拡張機能の再起動で中断された確認は、再試行される場合があります。「今すぐ確認」はオンのときだけ利用でき、時間間隔のみを省略します。オンにするには Gemini のタブを開いている必要がありますが、オフにするのはどのタブのポップアップからでもできます。オフにすると手動を含むこれらのリクエストをすべて禁止し、進行中の確認をキャンセルしてダウンロード済みデータを削除します。前回の試行時刻はローカルに残ります。同意設定とダウンロード済みデータは端末内のみで、ブラウザ同期や設定バックアップには含まれません。新しい修正とオフへの変更は、自分でページを再読み込みした後に反映されます。開いているページは現在のスナップショットを保持し、自動再読み込みは行いません。GET には Cookie、Referrer、識別子、ページや会話の内容を含めません。サーバーには IP、User-Agent、要求したホスト名が見え、前述のホスティングポリシーが適用されます。AI Studio は引き続き同梱データのみを使用します。プラグイン更新とお知らせの設定は独立しています。
