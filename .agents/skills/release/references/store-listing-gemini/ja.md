# Gemini page detection listing: 日本語

> Draft for maintainer review; not submitted to a store.

**オンラインカタログの更新**：「オンライン更新」は初期設定でオンです。gemini.google.com、またはプラグインを 1 つ以上有効にした他の対応サイトでは、ページを開くと、Voyager が `https://voyager.nagi.fun/catalog/hosts/<サイトのホスト名>.json` を HTTPS で取得することがあります。ポップアップを開いてもローカルキャッシュを読むだけで、ボタンから手動確認を実行できます。自動確認は前回の試行から設定した間隔（既定は 6 時間。1 時間・6 時間・24 時間・手動のみ）で行い、失敗時は再試行までの時間を延ばします。オンの間は手動で間隔を待たずに確認できます。オフにすると自動・手動のカタログリクエストを停止します。スイッチと間隔はブラウザ同期と設定バックアップの対象で、取得したカタログは端末内に保存します。同じ経路で、会話、サイドバー、入力、メニュー、エクスポート、画像などの機能に使う Gemini のページ認識の修正も配信します。Gemini の公式プラグイン、CSS、アカウントやコンテンツの識別ルール、クリックの動作は引き続き拡張機能に同梱します。Gemini Enterprise と AI Studio は同梱データのみを使用します。Gemini の新しい修正、修正の撤回、更新のオフへの切り替えは、自分でページを再読み込みした後に反映されます。開いているページは現在のデータを保持し、自動再読み込みは行いません。有効な修正がなければ同梱データを使います。カタログの取得は通常の GET で、Cookie、アカウントや拡張機能の識別子、ページや会話の内容は送りません。サーバーには IP アドレス、User-Agent、URL 内のサイトのホスト名などの接続情報が見えます。CSS と JSON は使用前に検証し、リモートの JavaScript や WebAssembly は実行しません。お知らせと任意のクラウド同期はそれぞれ別の設定です。voyager.nagi.fun は Cloudflare プロキシ配下の静的ホスティングで、Voyager プロジェクトはこれらのリクエストを記録・保存しません。接続情報はホスティング事業者が各自のプライバシーポリシーに従って扱います。
