**Онлайн-исправления распознавания страниц Gemini (по умолчанию выключены)**: только при включённом отдельном переключателе в общих настройках Voyager не чаще раза в 6 часов загружает `https://voyager.nagi.fun/catalog/gemini-selectors/v1/hosts/gemini.google.com.json`, содержащий проверенные правила поиска реплик, элементов и заголовков боковой панели, областей отображения папок, элементов меню моделей, меню диалогов и экспорта, панели выбора сообщений для экспорта, области нажатия кнопки открытия и закрытия боковой панели и областей наведения на боковой панели, содержимого сообщений для экспорта и ветвления, контекстных изображений, действий с ответами и исследовательским пакетом, показателей использования, блоков кода и диаграмм, абзацев с LaTeX в ваших сообщениях, изображений из результатов поиска в экспорте, кнопок скачивания сгенерированных изображений, экспорта кода Canvas, боковой панели Gems, полей ввода сообщений с их элементами управления и элементов страницы для сворачивания поля ввода, режима Vim, истории промптов, команд через косую черту, предпросмотра отправленных промптов, функции «Папка как Проект» и учёта активности папок, без кода, CSS и плагинов. Включить его можно на вкладке Gemini, выключить можно в окне расширения на любой вкладке. Выключение блокирует такие запросы, включая ручные, и удаляет загруженные данные; повторное включение не сбрасывает интервал. Настройка и данные хранятся только на устройстве. Изменения действуют после того, как вы сами перезагрузите страницу. Запрос не передаёт cookie, идентификаторы и содержимое страниц; сервер видит IP, User-Agent и хост. AI Studio использует только встроенные данные.
