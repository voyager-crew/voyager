# Gemini page detection listing: Русский

> Draft for maintainer review; not submitted to a store.

**Обновления онлайн-каталога**: «Онлайн-обновления» включены по умолчанию. На gemini.google.com или другом поддерживаемом сайте, где включён хотя бы один плагин, Voyager может загружать `https://voyager.nagi.fun/catalog/hosts/<хост сайта>.json` по HTTPS при открытии страницы. Открытие окна расширения только читает локальный кеш; кнопка запускает ручную проверку. Автоматические проверки выполняются с выбранным интервалом от последней попытки (по умолчанию 6 часов; 1 час, 6 часов, 24 часа или только вручную); после ошибок ожидание увеличивается. При включённых обновлениях ручная проверка может пропустить интервал. Выключение блокирует и автоматические, и ручные запросы. Переключатель и интервал синхронизируются браузером и входят в резервную копию настроек; загруженные каталоги остаются на устройстве. Этот же канал может передавать проверенные исправления распознавания элементов Gemini для диалогов, боковой панели, ввода, меню, экспорта и изображений. Официальные плагины Gemini, CSS, правила идентификации аккаунтов и содержимого и поведение при нажатиях остаются в составе расширения. Gemini Enterprise и AI Studio используют только встроенные данные. Новые исправления Gemini, их отзыв и выключение обновлений применяются после ручной перезагрузки страницы; автоматической перезагрузки нет. Без пригодных исправлений используются встроенные данные. GET-запросы не передают cookie, идентификаторы аккаунта или расширения, содержимое страниц или переписки. Сервер видит IP-адрес, User-Agent и хост сайта в URL. CSS и JSON проверяются до использования; удалённые JavaScript и WebAssembly не выполняются. Объявления и необязательная облачная синхронизация имеют отдельные настройки. voyager.nagi.fun использует статический хостинг за прокси Cloudflare; проект Voyager не записывает и не хранит эти запросы. Провайдеры хостинга обрабатывают метаданные соединения по своим политикам конфиденциальности.
