# Online catalog listing: Русский

> Draft for maintainer review; not submitted to a store.

**Обновления онлайн-каталога**: «Онлайн-обновления» включены по умолчанию. На поддерживаемых страницах Gemini (включая Enterprise), AI Studio, ChatGPT, Claude, DeepSeek и Kimi Voyager может загружать `https://voyager.nagi.fun/catalog/hosts/<хост сайта>.json` по HTTPS при открытии страницы. Открытие окна расширения только читает локальный кеш; кнопка запускает ручную проверку. Автоматические проверки выполняются с выбранным интервалом от последней попытки (по умолчанию 6 часов; 1 час, 6 часов, 24 часа или только вручную); после ошибок ожидание увеличивается. Ручные проверки не зависят от интервала и доступны даже при выключенных онлайн-обновлениях. Выключение останавливает автоматические запросы к каталогу. Плагины и существующие настройки сайта из кеша, включая правила распознавания страниц, остаются доступны. После перезагрузки с выключенными обновлениями эти правила работают по-прежнему; для дополнительных данных распознавания страниц используется встроенная версия. Переключатель и интервал синхронизируются браузером и входят в резервную копию настроек; загруженные каталоги остаются на устройстве. Единый канал передаёт собственные данные распознавания страниц каждого сайта. Онлайн-исправления обновляют распознавание страниц для поддерживаемых функций, включая диалоги, ввод, навигацию, меню, экспорт и изображения. Официальные плагины и CSS для Gemini и AI Studio, а также правила идентификации, удаления, нажатий и ввода для всех сайтов остаются в составе расширения. Исправления, их отзыв и выключение обновлений применяются после ручной перезагрузки страницы; автоматической перезагрузки нет. При включённых онлайн-обновлениях, если исправление непригодно или его нельзя независимо проверить, вся операция использует встроенные данные. GET-запросы не передают cookie, идентификаторы аккаунта или расширения, содержимое страниц или переписки. Сервер видит IP-адрес, User-Agent и хост сайта в URL. CSS и JSON проверяются до использования; удалённые JavaScript и WebAssembly не выполняются. Объявления и необязательная облачная синхронизация имеют отдельные настройки. voyager.nagi.fun использует статический хостинг за прокси Cloudflare; проект Voyager не записывает и не хранит эти запросы. Провайдеры хостинга обрабатывают метаданные соединения по своим политикам конфиденциальности.
