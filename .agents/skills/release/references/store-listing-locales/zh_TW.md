# Online catalog listing: 繁體中文

> Draft for maintainer review; not submitted to a store.

**線上目錄更新**：「線上更新」預設開啟。在支援的 Gemini（含 Enterprise）、AI Studio、ChatGPT、Claude、DeepSeek 和 Kimi 頁面，開啟頁面時，Voyager 可能透過 HTTPS 取得 `https://voyager.nagi.fun/catalog/hosts/<網站主機名稱>.json`。開啟擴充功能視窗只讀取本機快取，其中的按鈕可發起手動檢查。自動檢查依上次嘗試時間與所選間隔進行（預設 6 小時，可選 1 小時、6 小時、24 小時或僅手動），失敗後會延後重試。手動檢查可略過間隔，關閉線上更新後仍可使用。關閉後停止自動目錄請求。快取的外掛和原有網站設定（包括其中的頁面辨識規則）仍可使用。關閉更新並重新整理後，這些規則維持原有行為；新增的頁面辨識資料使用隨附版本。開關與間隔保存在瀏覽器同步儲存空間中，並包含在設定備份內；下載的目錄留在本機。同一管道提供各網站自己的頁面辨識資料。線上修復涵蓋支援功能的頁面辨識，包括對話、輸入、導覽、選單、匯出、圖片和 Voyager 控制項配置。Gemini 與 AI Studio 的官方外掛和 CSS，以及所有網站的識別規則、刪除等操作和點擊、輸入協定仍隨擴充功能提供。新修復、撤回和關閉更新在您自行重新整理後生效；已開啟頁面保留目前快照，不自動重新載入。開啟線上更新時，影響網站操作、資料或對話歸屬的修復須通過獨立頁面驗證，否則整個操作使用隨附資料。僅調整 Voyager 控制項位置的修復信任官方目錄；找不到目標，或掛載目標位於可編輯區域內時，使用隨附位置。目錄請求是一般 GET，不攜帶 Cookie、帳戶或擴充功能識別碼、頁面或對話內容。伺服器可見 IP 位址、User-Agent 和網址中的網站主機名稱等一般連線中繼資料。目錄中的 CSS 與 JSON 使用前經過驗證，不執行遠端 JavaScript 或 WebAssembly。公告和選用雲端同步各有開關。voyager.nagi.fun 是由 Cloudflare 代理的靜態託管網站；Voyager 專案不記錄、不保存這些請求，託管方依自身隱私政策處理連線中繼資料。
