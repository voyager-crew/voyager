**تحديثات الكتالوج عبر الإنترنت**: خيار «التحديثات عبر الإنترنت» مفعّل افتراضيًا. عند فتح صفحة مدعومة على Gemini (بما في ذلك Enterprise) أو AI Studio أو ChatGPT أو Claude أو DeepSeek أو Kimi، قد يجلب Voyager الملف `https://voyager.nagi.fun/catalog/hosts/<اسم مضيف الموقع>.json` عبر HTTPS. فتح نافذة الإضافة يقرأ النسخة المحلية فقط؛ ويطلب الزر تحققًا يدويًا. تتبع الفحوص التلقائية المدة المختارة منذ آخر محاولة (6 ساعات افتراضيًا، أو ساعة أو 6 ساعات أو 24 ساعة أو يدويًا فقط)، مع زيادة الانتظار بعد الإخفاقات. يتجاوز التحقق اليدوي المدة ويظل متاحًا عند إيقاف التحديثات عبر الإنترنت. إيقافها يوقف طلبات الكتالوج التلقائية. يتزامن المفتاح والمدة عبر المتصفح ويدخلان في نسخة الإعدادات الاحتياطية؛ وتبقى الكتالوجات المنزّلة على الجهاز. تنقل هذه القناة الواحدة بيانات التعرّف على صفحات كل موقع على حدة. تشمل الإصلاحات عبر الإنترنت التعرّف على الصفحات للميزات المدعومة، بما فيها المحادثات والإدخال والتنقّل والقوائم والتصدير والصور. تبقى الإضافات الرسمية وCSS في Gemini وAI Studio، وقواعد الهوية والحذف وسياسات النقر والإدخال في جميع المواقع، ضمن حزمة الامتداد. تسري الإصلاحات وسحبها وإيقاف التحديثات بعد إعادة تحميل الصفحة يدويًا؛ لا تُحدّث الصفحات المفتوحة تلقائيًا. إذا تعذّر استخدام إصلاح أو إثبات صحته بشكل مستقل، تستخدم العملية كاملةً البيانات المرفقة. لا ترسل طلبات GET ملفات ارتباط أو معرّفات حساب أو امتداد أو محتوى الصفحة أو المحادثة. يرى الخادم عنوان IP وUser-Agent واسم مضيف الموقع في الرابط. يُتحقّق من CSS وJSON قبل الاستخدام، ولا تُنفّذ JavaScript أو WebAssembly عن بُعد. للإعلانات والمزامنة السحابية الاختيارية إعدادات مستقلة. يستخدم voyager.nagi.fun استضافة ثابتة خلف وكيل Cloudflare؛ لا يسجّل مشروع Voyager هذه الطلبات ولا يحتفظ بها، ويتعامل مزوّدو الاستضافة مع بيانات الاتصال الوصفية وفق سياسات الخصوصية الخاصة بهم.
