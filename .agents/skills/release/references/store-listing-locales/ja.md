# Online catalog listing: 日本語

> Draft for maintainer review; not submitted to a store.

**オンラインカタログの更新**：「オンライン更新」は初期設定でオンです。対応する Gemini（Enterprise を含む）、AI Studio、ChatGPT、Claude、DeepSeek、Kimi のページでは、ページを開くと、Voyager が `https://voyager.nagi.fun/catalog/hosts/<サイトのホスト名>.json` を HTTPS で取得することがあります。ポップアップを開いてもローカルキャッシュを読むだけで、ボタンから手動確認を実行できます。自動確認は前回の試行から設定した間隔（既定は 6 時間。1 時間・6 時間・24 時間・手動のみ）で行い、失敗時は再試行までの時間を延ばします。手動確認は間隔を待たずに実行でき、オンライン更新がオフでも利用できます。オフにすると自動のカタログリクエストを停止します。キャッシュ内のプラグインと既存のサイト設定は引き続き使えます。更新をオフにすると、次にページを読み込んだときから、Voyager は拡張機能に同梱されたページ認識ルールを使い、キャッシュ済みのルール更新は適用しません。スイッチと間隔はブラウザ同期と設定バックアップの対象で、取得したカタログは端末内に保存します。この 1 つの経路で、各サイト専用のページ認識データを配信します。オンライン修正は、会話、入力、ナビゲーション、メニュー、エクスポート、画像、Voyager のコントロールの配置など、対応機能で使うページ認識を対象とします。Gemini と AI Studio の公式プラグインと CSS、および全サイトの識別ルール、削除操作、クリックや入力の処理は引き続き同梱します。修正、修正の撤回、更新のオフへの切り替えは、手動でページを再読み込みした後に反映します。自動再読み込みは行いません。オンライン更新がオンのとき、サイトの操作、データ、対象の会話に関わる修正はページ上の独立した情報で検証し、確認できなければ操作全体で同梱データを使います。Voyager のコントロールの配置だけに使う修正は公式カタログを信頼します。対象が見つからない場合や、設置先が編集可能な領域内にある場合は、同梱の配置に戻ります。カタログの取得は通常の GET で、Cookie、アカウントや拡張機能の識別子、ページや会話の内容は送りません。サーバーには IP アドレス、User-Agent、URL 内のサイトのホスト名などの接続情報が見えます。CSS と JSON は使用前に検証し、リモートの JavaScript や WebAssembly は実行しません。お知らせと任意のクラウド同期はそれぞれ別の設定です。voyager.nagi.fun は Cloudflare プロキシ配下の静的ホスティングで、Voyager プロジェクトはこれらのリクエストを記録・保存しません。接続情報はホスティング事業者が各自のプライバシーポリシーに従って扱います。
