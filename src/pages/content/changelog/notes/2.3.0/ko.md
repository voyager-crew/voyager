> _"어제는 역사이고, 내일은 미스터리이며, 오늘은 선물이다." — 우그웨이 대사부, 《쿵푸팬더》 (2008)_

### 주요 변경사항

- 🎛️ **Voyager 패널**: 플로팅 버튼에 마우스를 올리고 나타나는 패널 입구를 클릭하거나 ⌥V / Alt+V를 누르면 페이지에서 바로 패널이 열립니다. 대화를 떠나지 않고 지금 사이트의 기능을 켜고 끄고, 슬라이더를 움직이며 실시간으로 미리 보고, 사이트 접근을 관리하고, 클라우드 동기화까지 실행할 수 있습니다. 입력창에 `/`를 입력해도 열립니다. 이제 플로팅 버튼을 클릭 한 번으로 숨길 수 있고, ⌥V로 다시 불러올 수 있습니다.
- ☁️ **더 안전해진 클라우드 동기화, 다운로드 실행 취소**: 업로드로 클라우드 데이터가 비거나 크게 줄어들 것 같을 때, 또는 클라우드 파일을 읽을 수 없을 때는 병합할지, 그대로 업로드할지, 취소할지 먼저 묻습니다. 클라우드에서 받은 다운로드는 클릭 한 번으로 되돌릴 수 있습니다. 업로드할 때마다 교체되는 버전을 Drive에 최근 3개까지 보관하므로 이전 버전으로 복원할 수 있습니다. 패널의 클라우드 동기화에서는 동기화할 사이트를 고르고 항목별 동기화 상태도 확인할 수 있습니다.
- 🛰️ **사이트 개편 대응이 더 빨라집니다**: 각 사이트의 페이지 요소를 찾는 규칙을 이제 온라인 업데이트로 받습니다. 사이트 개편으로 기능이 멈춰도 스토어 심사를 기다리지 않고 고칠 수 있습니다. **온라인 업데이트** 스위치 옆에 새로고침 버튼이 생겨 직접 한 번 확인할 수 있습니다. 온라인 업데이트를 끄면 내장 버전으로만 동작합니다.

### 새 기능

- **사이트 접근 카드**: 팝업에 새로 생긴 **사이트 접근** 카드에서 사이트마다 접근 상태와 켜 둔 기능을 한눈에 볼 수 있고, 접근을 취소해도 클릭 한 번으로 되돌릴 수 있습니다. :chatgpt: ChatGPT, :claude: Claude, :deepseek: DeepSeek, :kimi: Kimi에서는 프롬프트 관리자가 해당 사이트 기능 목록의 스위치 하나가 됩니다.
- **내보내기 버튼 이동**: 플로팅 내보내기 버튼을 원하는 곳으로 드래그할 수 있습니다. 위치는 사이트마다 기억되고, 기본 위치 근처에 놓으면 제자리로 돌아갑니다.
- **Safari 앱이 Voyager 언어를 따름**: macOS의 Voyager 앱 창, 메뉴, 알림이 Voyager에서 고른 언어로 표시되고, 아랍어에서는 레이아웃도 좌우 반전됩니다.
- **:chatgpt: ChatGPT 내보내기에 업로드한 파일 표시**: 대화에서 업로드한 파일이 내보낸 내용에 "📎 파일 이름" 줄로 표시됩니다.

### 수정

- **내보내기는 전체 선택으로 시작**: 대화 전체를 읽고 나면 모든 메시지가 선택된 상태로 시작되며, 더 이상 "0개 선택됨"에 내보내기 버튼이 비활성화된 채로 남지 않습니다.
- **:chatgpt: ChatGPT PDF 내보내기가 비지 않음**: ChatGPT의 새로운 인쇄 방식에 맞춰, 내보낸 PDF에 대화가 다시 제대로 표시됩니다.
- **:chatgpt: ChatGPT 기록을 읽지 못하면 분명히 알림**: 전체 기록을 읽지 못했을 때는 그 사실을 알리고, 위로 스크롤해 불러온 뒤 다시 시도하라고 안내합니다. 하염없이 기다리게 하지 않습니다.
- **:chatgpt: ChatGPT 폴더 가이드가 반복해서 뜨지 않음**: 접힌 사이드바가 마우스를 올릴 때마다 펼쳐져도 가이드가 매번 뜨지 않고, 사이드바를 고정해 펼친 뒤에만 표시됩니다.
- **내보내기 버튼이 페이지 컨트롤을 가리지 않음**: 내보내기 버튼이 :claude: Claude 상단 바의 공유 버튼처럼 사이트 자체 버튼을 피해 자리를 잡고, 사이트 대화상자가 열리면 그 뒤로 물러납니다.
- **:claude: Claude 다크 모드**: Claude가 다크 모드로 바뀌면 Voyager 화면도 함께 어두워집니다.
- **더 안전한 Mermaid 렌더링**: 다이어그램은 별도의 격리된 페이지에서 렌더링되어 외부 이미지나 글꼴을 불러오지 않으며, 렌더링에 실패하면 자동으로 다시 시도합니다.
- **동기화 실패 시 불완전한 데이터를 올리지 않음**: 클라우드나 로컬 데이터를 읽지 못하면 아무것도 쓰기 전에 업로드를 멈춥니다. 여러 곳에서 동시에 동기화해도 서로 덮어쓰지 않고, 실패 메시지에 이유가 표시됩니다.
- **덮어쓰기 다운로드로 데이터가 지워지지 않음**: 클라우드에 없거나 읽을 수 없는 데이터는 로컬에 그대로 남고, 클라우드의 플러그인 목록이 비어 있어도 플러그인이 지워지지 않습니다.
- **Safari Drive 연결과 계정 전환**: Voyager 앱에서 Google Drive를 연결하면 팝업에도 바로 연결됨으로 표시됩니다. 계정을 바꾸면 동기화가 새 계정을 따르고, 동기화 도중에 바꾸면 두 계정의 데이터가 섞이지 않도록 멈춥니다.
- **백업에는 바꾼 설정만 담김**: 내보낸 설정 파일과 Drive의 설정 파일에는 실제로 바꾼 항목만 들어가므로, 복원해도 다른 기기에서 고른 값이 기본값으로 덮어써지지 않습니다. 패널과 버튼 위치 같은 기기 전용 설정도 더 이상 동기화되지 않습니다.
- **Android에서 플러그인 다시 사용 가능**: Edge 같은 Android 브라우저에서 플러그인에 **휴대폰에서는 아직 사용할 수 없습니다**가 더 이상 표시되지 않고, 폴더 설정과 Google Drive 동기화도 다시 정상 동작합니다.
- **호버 미리보기에 더 쉽게 닿음**: 프롬프트의 호버 미리보기 쪽으로 마우스를 대각선으로 움직여도 지나가는 다른 줄로 미리보기가 바뀌지 않습니다.
- **번역 수정**: 폴더 패널의 동기화 메시지가 더 이상 영어로 표시되지 않고, 러시아어에서 프롬프트 관리자의 클라우드 동기화 버튼이 테두리를 벗어나지 않습니다.
- **메모리 절약**: Voyager가 사용 중인 언어만 불러오므로 페이지마다 쓰는 메모리가 줄었습니다.

계정 분리를 켜 두었다면 이제 Drive에 있는 계정별 파일 이름이 이메일 기준으로 정해집니다. 모든 기기를 이 버전으로 업데이트하세요. 그렇지 않으면 이전 버전 기기에서는 새로 업로드한 내용이 보이지 않습니다.
