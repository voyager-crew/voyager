### 주요 변경사항

- 🎛️ **Voyager 패널**: 플로팅 버튼에 마우스를 올리거나 Alt/⌥+V를 눌러 열고, 페이지에서 바로 기능을 켜고 끄고 슬라이더를 조절하고 클라우드 동기화를 할 수 있습니다.
- ☁️ **더 안전해진 클라우드 동기화**: 클라우드 데이터를 덮어쓸 수 있을 때는 먼저 묻고, 다운로드는 되돌릴 수 있으며, Drive에 최근 3개 이전 버전을 보관합니다.
- 🛰️ **사이트 개편 대응이 더 빨라짐**: 페이지 요소를 찾는 규칙이 온라인 업데이트로 와서 스토어 심사를 기다리지 않아도 됩니다.

### 새 기능

- **사이트 접근 카드**: 팝업에서 사이트별 접근과 기능을 한곳에서 관리합니다.
- **내보내기 버튼 이동**: 사이트마다 둔 위치를 기억합니다.
- **Safari 앱 다국어 지원**: Voyager에서 고른 언어를 따릅니다.

### 수정

- **내보내기**: 처음부터 모두 선택됩니다. :chatgpt: ChatGPT PDF가 더 이상 비어 있지 않고, 업로드한 파일이 목록에 나오며, 기록을 다 읽지 못하면 알려 줍니다.
- **:chatgpt: ChatGPT**: 폴더 안내가 반복해서 뜨지 않고, 로컬 브리지 모델 전환이 더 안정적입니다.
- **:claude: Claude**: 내보내기 버튼이 공유 버튼을 가리지 않고, 다크 모드도 제대로 표시됩니다.
- **클라우드 동기화**: 실패해도 불완전한 데이터를 올리지 않고, 덮어쓰기 다운로드가 로컬 데이터를 지우지 않으며, Safari는 바꾼 계정을 따릅니다.
- **Android**: 플러그인이 다시 작동합니다.
- **기타**: 더 안전한 Mermaid 렌더링, 더 쉽게 닿는 프롬프트 호버 미리보기, 번역 수정, 메모리 사용량 감소.

계정 분리를 켜 두었다면 모든 기기를 이 버전으로 업데이트하세요.
