### Highlights

- 🚀 **:grok: Grok is here**: 12 plugins, including the timeline, export, formula copy and the prompt manager, now work on Grok. They start off, so turn on the ones you want under Plugins.
- 📂 **New chat in a folder**: right-click a folder and pick **New chat in this folder**. Once you send the first message, the chat files itself there.
- 🧮 **Formulas survive copying**: copy part of an answer and its formulas come along as LaTeX, ready to paste into your notes or documents.

### New

- **See where a new chat will go**: a small tag above the input box shows the folder. You can switch it or clear it.
- **Text-only export**: turn on **Text only** when exporting Markdown to get a single .md file without images.
- **Subfolders first**: an open folder now lists its subfolders above its chats. You can switch back to the old order in folder settings.

### Fixes

- **Renaming folders**: pressing Enter while an input method is still composing no longer saves a half-typed name, and Enter finishes a rename on Firefox again.
- **Cloud sync**: uploading no longer fails on ChatGPT or Claude before you've made any folders there.
- **:gemini: Watermark removal**: the star now comes off dark or textured images too.
- **:gemini: Timeline**: prompts that are only an image now show up on the timeline.
- **Other**: the tabs at the top of the popup scroll sideways, quoting several paragraphs no longer adds blank lines, the floating ball's buttons are easier to click, and the What's New title now says it's from Voyager.
