### Highlights

- 🚀 **:grok: Grok support**: Grok gets the timeline, conversation export, formula copy, the prompt manager, quote reply, :kbd:Mod+Enter: to send, draft autosave, a composer character counter, reading width, reading typography, palettes and site check. All 12 plugins are off by default; turn on the ones you want under Plugins.
- 📂 **New chat in a folder**: right-click a folder and pick **New chat in this folder**; once you send the first message, the chat is filed into that folder. Works on :gemini: Gemini, :aistudio: AI Studio, :chatgpt: ChatGPT, :claude: Claude, :deepseek: DeepSeek and :kimi: Kimi.
- 🧮 **Copy keeps formulas**: select part of a reply and press :kbd:Mod+C:; its formulas copy as LaTeX, `$…$` inline and `$$…$$` for display, with the text around them kept. Works on :gemini: Gemini, :aistudio: AI Studio, :claude: Claude, :deepseek: DeepSeek and :grok: Grok.

### New

- **Folder chip on new chats**: a new chat's composer shows which folder the chat will go into. Click the name to pick another, or × to drop it.
- **Text-only Markdown**: turn on **Text only** when exporting Markdown to leave out images and get a single .md file.
- **Subfolders first**: an open folder lists its subfolders above its chats, so they no longer sink below a long list. For the old order, set **Subfolders** to **At bottom** in folder settings.

### Fixes

- **Folder rename**: with an input method, Enter only confirms the candidate instead of submitting a half-typed name; on Firefox, Enter finishes the rename.
- **Cloud sync**: uploading no longer fails with "Couldn't read this device's data" when ChatGPT or Claude has no folders yet.
- **Popup contents bar**: the row of sections at the top of the settings scrolls with arrows or the mouse wheel, and lights up the section you are reading.
- **:gemini: Watermark removal**: the star in the corner comes off dark or textured backgrounds too.
- **:gemini: Timeline**: image-only prompts show up on the timeline, named by the image's description.
- **Floating ball**: its buttons stay clickable when the timeline is dragged next to it.
- **Formula copy and quotes**: display formulas copy as a `$$…$$` block instead of inline.
- **Quote reply**: quoting several paragraphs no longer adds blank lines.
- **Markdown export**: a list right after a paragraph gets a blank line before it, so every Markdown preview shows it as a list.
- **What's New**: the dialog title names Voyager, so it is not mistaken for a notice from the site.
