> _「모험은 저 밖에 있어!」——《업》 (2009)_

### 주요 변경사항

- 🚀 **:grok: Grok 지원**: Grok에서 타임라인, 대화 내보내기, 수식 복사, 프롬프트 관리자, 인용 답장, :kbd:Mod+Enter:로 보내기, 초안 자동 저장, 입력창 글자 수 표시, 읽기 너비, 읽기 타이포그래피, 색상 팔레트, 사이트 점검을 쓸 수 있습니다. 플러그인 12개는 모두 기본으로 꺼져 있으니 플러그인에서 필요한 것만 켜세요.
- 📂 **폴더에서 새 채팅**: 폴더를 우클릭해 **이 폴더에서 새 채팅**을 고르면, 첫 메시지를 보내는 순간 채팅이 그 폴더에 들어갑니다. :gemini: Gemini, :aistudio: AI Studio, :chatgpt: ChatGPT, :claude: Claude, :deepseek: DeepSeek, :kimi: Kimi에서 됩니다.
- 🧮 **복사할 때 수식 유지**: 답변 일부를 선택하고 :kbd:Mod+C:를 누르면 수식이 LaTeX로 복사됩니다. 인라인은 `$…$`, 블록 수식은 `$$…$$`이고 주변 글도 그대로 남습니다. :gemini: Gemini, :aistudio: AI Studio, :claude: Claude, :deepseek: DeepSeek, :grok: Grok에서 됩니다.

### 새 기능

- **새 채팅의 폴더 라벨**: 새 채팅 입력창 위에 이 채팅이 들어갈 폴더가 표시됩니다. 이름을 누르면 다른 폴더로 바꾸고, ×를 누르면 취소합니다.
- **텍스트만 Markdown**: Markdown으로 내보낼 때 **텍스트만**을 켜면 이미지를 빼고 .md 파일 하나로 받습니다.
- **하위 폴더를 위로**: 폴더를 열면 하위 폴더가 채팅보다 위에 나열되어 긴 채팅 목록 아래로 묻히지 않습니다. 예전 순서를 원하면 폴더 설정에서 **하위 폴더**를 **아래에 표시**로 바꾸세요.

### 수정

- **폴더 이름 변경**: 입력기로 입력 중일 때 Enter는 후보만 확정하고, 덜 쓴 이름을 저장하지 않습니다. Firefox에서도 Enter로 이름 변경이 끝납니다.
- **클라우드 동기화**: ChatGPT나 Claude에 아직 폴더가 없을 때 업로드가 "이 기기의 데이터를 읽지 못했습니다"로 실패하지 않습니다.
- **팝업 설정 목차**: 설정 위쪽의 섹션 줄을 화살표나 마우스 휠로 넘길 수 있고, 지금 읽는 섹션이 강조됩니다.
- **:gemini: 워터마크 제거**: 어둡거나 무늬가 있는 배경에서도 모서리의 별 표시가 지워집니다.
- **:gemini: 타임라인**: 이미지만 보낸 질문도 타임라인에 나타나고, 이미지 설명이 이름이 됩니다.
- **플로팅 볼**: 타임라인을 옆으로 끌어와도 주변 버튼을 누를 수 있습니다.
- **수식 복사와 인용**: 블록 수식은 인라인이 아니라 `$$…$$` 블록으로 복사됩니다.
- **인용 답장**: 여러 문단을 인용해도 빈 줄이 더 생기지 않습니다.
- **Markdown 내보내기**: 문단 바로 뒤의 목록 앞에 빈 줄이 들어가, 어떤 Markdown 미리보기에서도 목록으로 보입니다.
- **업데이트 안내**: 창 제목에 Voyager가 표시되어 사이트 공지로 착각하지 않습니다.
