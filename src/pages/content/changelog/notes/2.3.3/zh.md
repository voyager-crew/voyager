> _「去冒险吧！」——《飞屋环游记》（2009）_

### 亮点

- 🚀 **支持 :grok: Grok**：Grok 上可以用时间线、会话导出、公式复制、提示词管理器、引用回复、:kbd:Mod+Enter: 发送、草稿自动保存、输入框字数统计、阅读宽度、阅读排版、配色和站点检查，12 个插件都默认关闭，在插件里按需打开。
- 📂 **在文件夹里开新对话**：右键文件夹选「在此文件夹新建对话」，发出第一条消息后，对话会自动放进这个文件夹。:gemini: Gemini、:aistudio: AI Studio、:chatgpt: ChatGPT、:claude: Claude、:deepseek: DeepSeek 和 :kimi: Kimi 都支持。
- 🧮 **复制时保留公式**：选中一段回复按 :kbd:Mod+C:，里面的公式会复制成 LaTeX，行内是 `$…$`，独立公式是 `$$…$$`，文字照常保留。支持 :gemini: Gemini、:aistudio: AI Studio、:claude: Claude、:deepseek: DeepSeek 和 :grok: Grok。

### 新增

- **新对话的文件夹标签**：新对话的输入框上方会标出这条对话要进哪个文件夹，点名字换一个，点 × 取消。
- **Markdown 只导出文字**：导出 Markdown 时打开「仅文本」，不带图片，直接得到一个 .md 文件。
- **子文件夹排在前面**：打开文件夹时，子文件夹列在对话上方，不再被一长串对话压到底下。想要原来的顺序，在文件夹设置里把「子文件夹」改成「在下方」。

### 修复

- **文件夹重命名**：用输入法打字时按回车只确认候选词，不会把没打完的名字提交；Firefox 上按回车能完成重命名。
- **云同步**：ChatGPT 或 Claude 上还没建过文件夹时，上传不再报「无法读取本机数据」。
- **弹窗设置目录**：设置页顶部那排栏目可以点箭头翻页，也能用滚轮左右滑；往下翻设置时，对应的栏目会亮起来。
- **:gemini: 去水印**：图片背景偏暗或有纹理时，右下角的星标也能去掉。
- **:gemini: 时间线**：只发了图片的提问也会出现在时间线上，用图片描述当名字。
- **悬浮球**：时间线拖到悬浮球旁边时，悬浮球周围的小按钮仍然点得到。
- **公式复制和引用**：独立公式按 `$$…$$` 整块复制，不再变成行内公式。
- **引用回复**：引用多段内容时不再多出空行。
- **Markdown 导出**：段落后面紧跟的列表会空出一行，在各种 Markdown 预览里都能正确显示成列表。
- **更新说明**：弹窗标题写明是 Voyager 的更新，不会被当成网站自己的通知。
